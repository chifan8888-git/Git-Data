# 49. L23302 模型選擇與架構設計（35 分鐘）

> 一句話定位：初級只要你認得「分類用決策樹、迴歸用線性迴歸」這種名詞配對；中級則給你一段**帶限制條件的業務情境**（資料只有 150 筆、監管要求說明拒絕原因、要塞進手機、必須毫秒回應），要你在多個「看起來都對」的模型之間，判斷哪一個限制才是決勝點。這一節官方篇幅最小，卻是整個科目 3「情境 → 選模型」題型的判準來源。

## 學習目標
- 依輸出型態與標籤有無，把任務歸入分類／迴歸／聚類／降維／序列／異常偵測六大族，並配對對應模型家族
- 依資料規模（小／中／大）與維度共線性狀況，判斷該用簡單正則化模型、樹集成，還是深度網路
- 依可解釋性需求區分「白箱模型」與「黑箱模型＋事後解釋技術」，並分辨局部（Local）與全域（Global）解釋
- 依運算資源、推論延遲與維運成本，選出部署可行的模型與壓縮策略（量化／剪枝／蒸餾）

## 49.1 模型選擇的五道判準（總決策樹）

官方指引把模型選擇拆成五項考量因素。實務上它們有**先後順序**：前面的判準不通過，後面再優也沒用。

```
┌──────────────────────────────────────────────────────┐
│  Step 1  任務型態是什麼？                            │
│    有標籤？ → 輸出離散＝分類 / 輸出連續＝迴歸        │
│    無標籤？ → 要分組＝聚類 / 要壓縮＝降維            │
│    有時間順序？ → 序列模型                           │
│    只有正常樣本？ → 非監督／半監督異常偵測           │
│              ↓ 決定「模型家族」                      │
├──────────────────────────────────────────────────────┤
│  Step 2  資料規模與維度？                            │
│    數百～數千   → 簡單模型＋正則化（防過擬合）       │
│    數千～數十萬 → 樹集成（RF、XGBoost、LightGBM）    │
│    百萬級以上   → 深度神經網路（尤其非結構化資料）   │
│              ↓ 決定「模型複雜度上限」                │
├──────────────────────────────────────────────────────┤
│  Step 3  要不要解釋？要解釋到什麼層級？              │
│    醫療／金融／法遵 → 白箱模型，或黑箱＋SHAP/LIME    │
│    個案級說明 → 局部解釋；整體排序 → 全域解釋        │
│              ↓ 可能「推翻」Step 2 的最佳選擇         │
├──────────────────────────────────────────────────────┤
│  Step 4  部署在哪？要多快回應？                      │
│    邊緣／手機／IoT → 小模型＋剪枝／量化              │
│    雲端／資料中心 → 大型模型、集成策略可行           │
│    毫秒級即時     → 推論延遲優先，蒸餾＋快取         │
│              ↓ 決定「模型能不能真的上線」            │
├──────────────────────────────────────────────────────┤
│  Step 5  偏差-變異與開發維運成本能否承擔？           │
│    人力不足、要快速比較多模型 → AutoML               │
│    需精細控制特徵工程 → 人工建模                     │
└──────────────────────────────────────────────────────┘
```

**考試上的用法**：題幹通常同時丟出兩個以上的限制（例如「非線性」＋「須提供特徵重要性供稽核」），正解就是**同時滿足全部限制**的那一個；只滿足一個限制的選項就是誘答。

## 49.2 判準一：任務型態與模型特性配對

### 六大任務族對照

| 任務型態 | 判斷線索 | 典型情境 | 常用模型 | 對應損失函數 |
|---|---|---|---|---|
| **分類（Classification）** | 輸出為離散類別 | 垃圾郵件偵測、疾病診斷、客戶流失 | 決策樹／隨機森林（特徵混合、要解釋）、SVM（邊界清晰、高維小樣本）、神經網路（影像／語音等高度非線性） | 二元交叉熵 BCE／多類別交叉熵 |
| **迴歸（Regression）** | 輸出為連續數值 | 房價預測、能源消耗、業績估算 | 線性迴歸（線性趨勢明顯、高解釋）、決策樹／隨機森林迴歸（非線性與特徵交互）、神經網路（大規模高維） | MSE（放大極端誤差）／MAE（對離群值穩健） |
| **聚類（Clustering）** | 無標籤，要自動分組 | 客戶分群、商圈劃分 | K-means（群數已知、球狀群）、DBSCAN（有雜訊、群大小不均、非凸） | — |
| **降維（Dimensionality Reduction）** | 無標籤，要壓縮表示 | 製程特徵壓縮、嵌入視覺化 | PCA（線性、保留最大變異、可對新資料投影）、自編碼器（非線性重建）、t-SNE（僅視覺化） | — |
| **序列／時間序列** | 資料有時間或先後順序 | 電力需求預測、感測器監控、語音辨識 | RNN／LSTM／GRU（長期依賴）、TCN（長期依賴穩定）、ARIMA（短期、週期明顯、資料量不大） | 依輸出型態 |
| **異常偵測（只有正常樣本）** | 缺乏已確認的異常標註 | 軸承振動監測、設備預防保養 | One-Class SVM、Isolation Forest、自編碼器重建誤差 | 重建誤差／密度分數 |

### 三組最常被混淆的配對

```
「預測未來七天電力需求」  → 時序 → LSTM（不是 CNN，不是聚類）
「把顧客依相似特徵分群」  → 聚類 → K-means / DBSCAN（不是 LSTM）
「把高維感測資料壓成低維」→ 降維 → PCA / Autoencoder（不是 LSTM）
```

**K-means vs DBSCAN 的四點差異**（情境題高頻）：

| | K-means | DBSCAN |
|---|---|---|
| 群數 | 必須事先指定 K | 不需指定，由密度自動決定 |
| 群形狀 | 以歐氏距離最小化群內平方和，偏好球狀（凸）群 | 可處理半月形等非凸群 |
| 離群值 | 群心是平均值，易被離群值拉偏 | 明確定義**雜訊點（Noise Point）**，不歸入任何群 |
| 穩定性 | 隨機初始中心 → 僅保證局部最優，每次結果略不同 | 同參數下結果穩定 |

DBSCAN 的三種點：**核心點**（鄰域樣本數達門檻）、**邊界點**（自己不是核心點，但落在某核心點鄰域內）、**雜訊點**（兩者皆非，也無密度可達關係）。

### PCA vs t-SNE：選型不是「誰比較準」

| | PCA | t-SNE |
|---|---|---|
| 性質 | 線性降維（特徵值分解找最大變異方向） | 非線性、機率式 |
| 保留什麼 | 全域變異結構 | **局部鄰域關係**，不保留全域距離與尺度 |
| 新資料 | 有固定轉換矩陣，可直接投影外推 | 無明確外推函數 |
| 適用 | 作為下游模型（如 XGBoost）的輸入特徵 | **僅適合視覺化探索群集結構** |

## 49.3 判準二：資料規模與維度

| 資料規模 | 樣本量 | 建議模型 | 關鍵理由 | 附帶要求 |
|---|---|---|---|---|
| **小型** | 數百～數千 | 線性／邏輯迴歸、決策樹、Lasso／Ridge 等正則化模型 | 參數少 → 降低過擬合風險 | 特徵工程重要性提高；需以較強先驗假設支撐；評估要用交叉驗證（樣本極不平衡時用分層 K 折） |
| **中型** | 數千～數十萬 | 隨機森林、XGBoost、LightGBM | 表現力與泛化的甜蜜點，可支撐集成與超參數優化 | 計算資源與訓練時間開始成為實務限制 |
| **大型** | 百萬級以上 | 深度神經網路 | 非結構化資料（影像、語音、文字）的表現潛力才發揮得出來 | 需 GPU／多機分散式、具擴展性的架構設計 |

### 維度與共線性的另一條線

- **高維、小樣本、邊界清晰** → SVM（核函數映射至高維空間）或正則化線性模型。
- **特徵高度相關，但要保留全部特徵的解釋能力** → **Ridge（L2）**：平方懲罰把相關特徵的權重平均分攤並同步縮小，估計穩定且**不會歸零**。
- **特徵高度相關，且想自動篩掉不重要特徵** → **Lasso（L1）**：絕對值懲罰產生稀疏模型。但要注意副作用——面對「月收入／年收入／季收入」這類高度相關群，Lasso 每次只留其中一個，**留誰會隨抽樣改變**，導致重要特徵清單反覆跳動、難以向稽核單位交代。
- **Elastic Net（L1+L2）** 兼具兩者，但仍含 L1 成分，部分係數仍可能被壓為 0。

## 49.4 判準三：可解釋性需求

### 白箱與黑箱

| | 高解釋性模型 | 低解釋性模型 |
|---|---|---|
| 代表 | 線性迴歸、邏輯迴歸、淺層決策樹 | 隨機森林、梯度提升樹、深度神經網路 |
| 為何可解釋 | 係數、分割規則可直接視覺化與溝通 | 結構高度非線性、參數量大，決策過程不易直觀理解 |
| 典型場域 | 醫療診斷、信貸評分、法規監管 | 追求預測力且錯誤代價可承受的場景 |
| 補救方式 | — | 搭配 SHAP、LIME、偏依圖（PDP）等事後解釋技術 |

### 事後解釋技術：局部 vs 全域

| 技術 | 解釋層級 | 回答什麼問題 | 適用資料 |
|---|---|---|---|
| **SHAP** | 局部（也可彙總為全域） | 「這一筆申請為何被拒？各特徵各貢獻多少分？」 | 表格、通用 |
| **LIME** | 局部 | 用簡單代理模型近似單筆預測的鄰域行為 | 表格、文字、影像 |
| **偏依圖（PDP）** | 全域 | 「某特徵整體上如何影響預測？」 | 表格 |
| **特徵重要性** | 全域 | 整體特徵影響排序（樹模型原生可輸出） | 表格 |
| **Grad-CAM** | 局部 | 以熱力圖標示影像中影響判斷的區域 | **僅影像／CNN** |

**判準句**：題幹說「每一筆被拒絕的申請須提供可理解的原因」→ 這是**局部可解釋性**，全域特徵重要性與混淆矩陣都不合格；表格資料也套不上 Grad-CAM。題幹說「須提供整體特徵重要性以供稽核」→ 這是**全域**，樹集成模型原生就給得出來。

**解釋性需求強度排序**（官方考過的判斷）：醫療影像判讀腫瘤惡性程度（攸關生命）＞ 信貸／貸款審核（監理要求）＞ 客戶流失預測 ＞ 廣告出價、推播時間最佳化（錯誤代價有限）。

## 49.5 判準四：運算資源、延遲與部署限制

| 部署場景 | 限制 | 模型策略 |
|---|---|---|
| **資源受限**（IoT、手機 App、邊緣裝置） | 記憶體、電力、算力皆有限 | 結構簡單、參數少、推論快：簡單決策樹、邏輯迴歸、壓縮後的小型神經網路；搭配剪枝或量化瘦身 |
| **資源充足**（雲端、資料中心） | 主要成本是費用而非可行性 | 高效能深度模型、模型集成，可支援複雜的前後處理流程 |
| **即時推論**（金融交易、推薦系統） | 秒級／毫秒級回應 | 推論延遲優先於絕對準確率；搭配快取（caching）與知識蒸餾 |

### 四種模型瘦身技術的差異（極易混淆）

| 技術 | 改變什麼 | 要不要重新訓練 |
|---|---|---|
| **量化（Quantization）** | 數值精度，例如 32-bit 浮點 → 8-bit 整數 | 不重訓者即「訓練後量化」 |
| **剪枝（Pruning）** | 參數數量與稀疏度，移除接近零或不重要的連結／通道 | 通常需微調 |
| **知識蒸餾（Distillation）** | 用大模型輸出當軟標籤訓練小的學生模型 | **必然需要訓練** |
| **張量分解（Tensor Decomposition）** | 把大矩陣拆為多個低秩矩陣相乘 | 通常需微調 |

> 官方指引特別提醒：**模型選擇與部署應同步規劃**，避免訓練完成後才發現模型無法實際上線。

## 49.6 判準五：偏差-變異權衡與開發維運成本

### 偏差-變異（Bias-Variance Tradeoff）

```
                偏差   變異   訓練表現  測試表現   症狀
低複雜度模型     高     低      差        差      欠擬合（未捕捉主要趨勢）
剛好             低     低      好        好      泛化良好
高複雜度模型     低     高     極佳       差      過擬合（對雜訊過度敏感）
```

- **低複雜度（如線性迴歸）**：偏差高、變異低，穩定且具解釋性，但無法處理複雜關係。
- **高複雜度（如深度神經網路）**：偏差低、變異高，能擬合複雜模式，但**需要更多資料或額外正則化**來壓住變異。
- 模型複雜度提升 → 偏差降低、變異升高，選模型就是在這條曲線上找平衡點。

### 開發與維運成本：AutoML 的適用邊界

| 適合導入 AutoML | 不適合導入 AutoML |
|---|---|
| 缺乏專職工程師、需在短時間內比較多種候選模型（例如行銷部門的顧客流失預測） | 已有完整 MLOps 平台與資深資料科學團隊，更新採固定流程 |
| 建模任務標準化、追求快速產出基準線 | 模型已長期穩定運作，只需定期微調參數 |
| | 需精細控制特徵工程與演算法細節的高度客製化模型（如財務信用風險） |

**另一個成本考量**：演算法複雜度。若系統需逐一比對每位客戶與其他所有客戶，時間複雜度為 O(n²)，資料量放大十倍運算量放大百倍 —— 這類設計在大規模場景下本身就不可行，屬於架構階段就該排除的選項。

## 49.7 架構設計：深度模型的內部選型

模型家族選定為神經網路之後，還要選架構。官方近兩次都考。

| 架構 | 核心機制 | 擅長 | 已知瓶頸 |
|---|---|---|---|
| **CNN** | 區域感知（Local Receptive Field）＋參數共享 → 大幅降低參數量與運算複雜度 | 影像、具空間局部性的資料 | 不擅長長距離序列依賴 |
| **RNN／LSTM／GRU** | 時間步遞迴、記憶單元 | 時序與中短序列依賴 | 必須逐步遞迴**無法平行**；長文件跨段落關聯會衰減 |
| **Transformer** | 自注意力（Self-Attention）讓任意兩個 token 在同一層直接建立關聯 | 長文件、跨段落語義比對；運算可平行化 | 序列長度的計算成本高 |

### 三個架構層級的陷阱題

1. **CNN 內部分工**：第一層卷積層擷取邊緣、紋理等**低階局部特徵**；降低空間維度、減少參數與計算量是**池化層**的職責；整合特徵輸出分類結果是全連接層與輸出層。三者不可互換。
2. **加深反而變差**：若「訓練損失**反而高於**淺版本且收斂困難」，問題出在**最佳化**（梯度消失）而非泛化，對策是 ResNet 的**殘差連接（Skip Connection）**提供恆等捷徑。若是訓練損失低、驗證損失高，那才是過擬合，要走正則化路線。
3. **BERT vs GPT**：BERT 是雙向編碼器＋遮罩語言模型，目標是產生**理解**用的上下文表示，架構上沒有自迴歸逐字生成機制；GPT 以預測下一個 token 為訓練目標，天生適合續寫。**差異來自架構與預訓練目標，增加訓練資料補不回來。**

### 樹集成的架構差異

XGBoost 相較傳統 GBDT 的改進是「三件事一起」：目標函數加入 **L1／L2 正則化項**抑制過擬合、原生支援**缺失值自動分裂處理**、支援**特徵層級並行化**訓練。它沒有改用隨機森林架構，也沒有用神經網路取代弱學習器，更與批次正規化無關。

決策樹選擇分裂特徵的依據是**資訊增益（Information Gain）**，即熵的減少量 —— 這是樹模型專屬機制，不是 L1 正則化、不是激活函數、也不是核函數 SVM 的做法。

## 49.8 官方考過什麼

**命中率觀察**：114-2 與 115-1 共 100 題中，直接考「情境 → 選模型／選架構」的核心題 **13 題**，另有 5 題考模型特性辨識（本節周邊題），合計 **18 題**。題型幾乎全是情境判斷，純名詞定義題極少。

| 考點 | 官方怎麼問 | 正解思路 |
|---|---|---|
| 任務型態 → 模型 | 「下列哪種應用最適合 LSTM？」（114-2 第 7 題） | 找「有時間順序」的選項：預測未來七天電力需求。物件辨識走 CNN、分群走聚類、壓縮走降維 |
| 任務型態 → 損失函數 | 使用時長（分鐘）與是否流失（是／否）各該用什麼損失？（115-1 第 10 題） | 連續數值＝迴歸＝MSE；二元分類＝BCE。誘答把兩者對調 |
| 只有正常樣本 | 只有正常振動紀錄、無故障標註（115-1 第 29 題） | 標籤前提不成立 → 非監督／半監督異常偵測，不是監督式二元分類 |
| 聚類模型限制 | K-means 遇半月形群、離群值、每次結果不同（115-1 第 15 題） | 要選**同時涵蓋三項限制**的敘述：需指定 K、難處理非凸、對初始化與離群值敏感。只講一項的是誘答 |
| 聚類定義 | DBSCAN 中孤立且密度不足的點屬於哪類？（114-2 第 4 題） | 雜訊點。邊界點必須落在某核心點鄰域內 |
| 降維選型 | t-SNE 與 PCA 該怎麼分工？（115-1 第 6 題） | t-SNE 保留局部鄰域、適合視覺化；不保留全域結構、無外推函數，不能當模型輸入特徵 |
| 非線性＋可稽核 | 50 個特徵、部分非線性、須提供整體特徵重要性（115-1 第 28 題） | 隨機森林迴歸：同時滿足兩項限制。SVR 的支持向量不是特徵重要性；邏輯迴歸是分類模型 |
| 共線性＋不歸零 | 150 特徵高度相關，要控過擬合又不讓係數歸零（115-1 第 33 題） | Ridge（L2）。Lasso 與 Elastic Net 都會產生零係數 |
| 解釋性情境排序 | 哪個情境可解釋性最關鍵？（114-2 第 14 題） | 醫療影像判讀腫瘤惡性程度。行銷推播、廣告出價錯誤代價有限 |
| 局部可解釋性 | 每筆被拒申請須說明原因（115-1 第 37 題） | SHAP。全域特徵重要性與混淆矩陣都是整體層級，Grad-CAM 只適用影像 |
| 監理場域選模型 | 傳統信用評分卡流程，何者**不是**常見步驟？（114-2 第 25 題） | 「使用生成式模型進行特徵學習」缺乏可解釋性，不符評分卡標準化流程 |
| 資源受限部署 | 32-bit 浮點轉 8-bit 整數、不重新訓練（115-1 第 21 題） | 模型量化（訓練後量化）。蒸餾必然要訓練、剪枝改的是參數數量 |
| 長文件架構選型 | BiLSTM 效果不佳，改 Transformer 為何改善？（115-1 第 19 題） | Self-Attention 讓任意 token 直接建立關聯、不受距離限制，且可平行化 |
| 生成任務架構 | BERT 生成效果差、加資料也沒用（115-1 第 23 題） | BERT 無自迴歸逐字生成機制，是架構與預訓練目標的差異 |
| 深度加深反變差 | 3 層 CNN 升 16 層，訓練損失反而更高（115-1 第 17 題） | 梯度消失 → ResNet 殘差連接。關鍵線索是「訓練損失」變差 |
| 架構分工 | 池化層最主要解決什麼？（115-1 第 18 題） | 降低特徵圖空間維度、減少參數與計算量 |
| 樹模型機制 | 資訊增益用於哪類模型？（114-2 第 8 題） | 遞迴分裂建立分類規則的決策樹 |
| 樹集成改進 | XGBoost 相較 GBDT 的主要改進（114-2 第 18 題） | 正則化＋缺失值自動處理＋並行化，三者並列的那個選項 |
| 開發成本 | 哪種情境最適合導入 AutoML？（114-2 第 10 題） | 缺乏專職工程師、要短時間比較多種模型 |

## 49.9 易錯與陷阱

- [ ] **「最準確」不等於「最適合」** —— 情境題問的是限制條件下的最佳解，不是絕對效能榜首。題幹每多一個限制，就多刪掉一批選項。
- [ ] **選項只滿足一半需求就是誘答** —— 題幹同時要「非線性」與「可稽核」，只能建模非線性（SVR）或只能解釋（邏輯迴歸）的都不對。
- [ ] **可解釋性要先分局部還是全域** —— 「每一筆被拒案件的原因」是局部（SHAP／LIME）；「整體特徵排序」是全域（特徵重要性／PDP）。用錯層級一定錯。
- [ ] **Ridge 不歸零，Lasso 會歸零** —— 要「保留全部特徵」選 Ridge；要「自動特徵選擇」選 Lasso。Elastic Net 含 L1 成分，仍會歸零。
- [ ] **Lasso 在高度相關特徵間的選擇不穩定** —— 每次重訓保留的特徵會跳動，這是稀疏性的副作用，不是「沒用正則化」也不是「梯度消失」。
- [ ] **t-SNE 是視覺化工具，不是特徵萃取工具** —— 它沒有可重複套用到新樣本的固定轉換；要當下游模型輸入請用 PCA。
- [ ] **只有正常樣本就不可能做監督式分類** —— 看到「缺乏已確認的故障標註」立刻轉向非監督／半監督異常偵測。
- [ ] **「訓練損失變差」是最佳化問題，「驗證損失變差」才是泛化問題** —— 前者找梯度消失／學習率，後者才找正則化與資料量。
- [ ] **量化改精度、剪枝改參數量、蒸餾要訓練** —— 「不重新訓練」這五個字直接排除知識蒸餾。
- [ ] **CNN 的效率優勢來自區域感知與參數共享**，不是「自動具備旋轉與比例不變性」，也不是「捨棄激活函數」。
- [ ] **池化層降維，卷積層抽特徵，全連接層整合輸出** —— 三者職責在題目中常被互換。
- [ ] **AutoML 不是萬用加速器** —— 團隊成熟、模型已穩定、或需精細控制特徵工程時，導入效益反而有限。
- [ ] **模型選擇必須與部署同步規劃** —— 訓練階段沒考慮延遲與裝置限制，上線時整個模型作廢，是官方明寫的警告。
- [ ] **ARIMA 適合「短期、週期明顯、資料量不大」** —— 資料量大且非線性強時才輪到 LSTM／TCN，不要看到時間序列就直接選深度模型。
