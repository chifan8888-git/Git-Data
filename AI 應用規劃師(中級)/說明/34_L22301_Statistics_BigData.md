## 34.1 大數據破壞了統計學的四個前提

傳統統計的推論效力，建立在四個很少被寫出來、卻一旦失效就全盤崩塌的前提上。官方《學習指引》整章的邏輯就是逐一拆解它們。

```
傳統統計的前提            大數據環境的現實              後果
──────────────            ────────────────              ──────────────
① 隨機抽樣          →   平台自動擷取，誰在裡面由系統決定  →  結構性偏誤，且不隨 n 縮小
② 獨立觀測          →   同一使用者一天數百筆點擊          →  低估變異、信賴區間過窄
③ 固定且可界定的母體 →   跨國、跨時段、持續變動的資料池    →  推論對象模糊、外推錯誤
④ 資料可一次載入計算 →   PB 級、串流、記憶體裝不下        →  精確統計量算不出來，改用近似
```

| 前提 | 被破壞時最典型的錯誤結論 | 中級要求的補救方向 |
|---|---|---|
| 隨機抽樣 | 「我們有全站資料，所以不需要抽樣」 | 界定涵蓋範圍、抽樣加權、分層校正 |
| 獨立觀測 | 「10 億筆點擊 = 10 億個獨立樣本」 | 以使用者為分析單位、群集穩健標準誤、混合效應模型 |
| 固定母體 | 「2023 年交易資料可推論 2024 年新客」 | 明確寫出母體定義與時間界線，禁止跨期外推 |
| 可全量計算 | 「先 collect() 回來再用 Python 算」 | 可合併統計量（mergeable statistics）＋近似演算法 |

**貫穿全節的一句話：資料量大只會讓你「更精準地算出一個偏掉的答案」。** 樣本數 n 只影響隨機誤差（標準誤 SE = σ/√n），對系統性偏誤（Systematic Error）完全無效。

## 34.2 抽樣：資料量大不能取代抽樣設計

### 抽樣方法對照

| 方法 | 作法 | 前提／適用 | 大數據場景的角色 |
|---|---|---|---|
| **簡單隨機抽樣（SRS）** | 每個個體被抽中機率相同 | 母體名冊可列舉 | 基準線，但 PB 級資料難以真正列舉 |
| **系統抽樣（Systematic）** | 每隔 k 個抽一個 | 資料排列與目標變數無週期關聯 | 對按時間排序的 log 危險（會抓到固定時段） |
| **分層抽樣（Stratified）** | 先分層，每層各自抽 | **層內同質、層間異質** | 保障小眾族群（地區、裝置、新客）被抽到 |
| **群集抽樣（Cluster）** | 抽整個群集，群內全查 | **群內異質、群間同質** | 依門市／伺服器分片抽，成本低但變異大 |
| **便利抽樣（Convenience）** | 拿得到什麼算什麼 | 非機率抽樣，無法推論 | 大多數「現成的大數據」其實屬於這類 |
| **水塘抽樣（Reservoir Sampling）** | 串流中維持固定容量 k 的均勻樣本 | 資料總量未知、只能單次掃描 | 串流環境下取得無偏樣本的標準作法 |

**分層與群集最常被寫反：分層抽樣要的是「每一層內部很像」，群集抽樣要的是「每個群集都像縮小版的母體」。**

### 大 n 救不了壞樣本：兩個經典

- **1936 年 Literary Digest 民調**：寄出千萬份、回收約 240 萬份，預測 Landon 勝選；實際是 Roosevelt 壓倒性連任。同期 Gallup 只用約 5 萬份隨機樣本就猜對。名冊來自電話簿與汽車登記（偏向高收入），加上自願回覆造成的**無回應偏誤（Non-response Bias）**，樣本數多了 48 倍也沒用。
- **平台點擊資料**：只有「主動點進去的人」會進資料庫，估出的平均閱讀時間必然高於全體讀者。這是**結構性偏誤（Structural Bias）**——它不會隨資料累積而消失，反而因為信賴區間越來越窄，看起來越來越「穩定可信」。

### 抽樣偏誤的常見型態

| 型態 | 機制 | 情境 |
|---|---|---|
| 涵蓋偏誤（Coverage Bias） | 母體中有人根本進不了資料來源 | 未裝 App 的顧客不在行為資料裡 |
| 自我選擇偏誤（Self-selection） | 是否入樣由個體自行決定 | 評價系統只有極滿意與極不滿意的人會填 |
| 無回應偏誤（Non-response） | 入樣但不回覆，且與目標變數相關 | 高流失風險客戶最不回問卷 |
| 存活者偏誤（Survivorship） | 只看得到留下來的個體 | 只分析仍在使用的帳號來推「留存原因」 |

## 34.3 敘述統計在大數據下的三種變形

### 變形一：長尾與偏態，平均數失去代表性

收入、消費金額、影片觀看數幾乎都是右偏長尾。**mean 遠大於 median 就是右偏的直接訊號**（官方 115-1 第 41 題就是直接給你 mean=223、median=128、max=4500 要你判斷）。

| 情境 | 該用的指標 | 不該用的指標 |
|---|---|---|
| 右偏長尾的中心趨勢 | 中位數、分位數 | 平均數 |
| 右偏資料的缺失值填補 | 中位數填補 | 平均數填補（會把分布整體右推並壓縮變異） |
| 厚尾的極端風險評估 | 分位數迴歸（Quantile Regression）、尾部分位 | 平均數 ± 標準差、裁切到 ±3σ |
| 迴歸前修正右偏＋異質變異 | 對 **Y** 做 Box–Cox／對數轉換 | 對 X 做標準化 |

**裁到 ±3σ 是大數據風險分析的反面教材**：詐欺、當機、極端損失正是你要找的東西，剪掉它等於剪掉題目本身。

### 變形二：算不動，改用可合併統計量與近似演算法

分散式環境的核心判準是「這個統計量可不可以拆開算再合併」。

| 統計量 | 可否分散合併 | 作法 |
|---|---|---|
| count、sum、平方和 | ✓ 可直接相加 | 各節點算局部值 → shuffle 彙總 |
| 平均數、變異數、標準差 | ✓ 由上述三者導出 | `DataFrame.agg({'col':'stddev'})`、`RDD.aggregate()`；串流可用 Welford 線上更新 |
| 最大／最小值 | ✓ 取局部極值再比 | 一次掃描 |
| **中位數、任意分位數** | ✗ 不可直接合併 | 需 **t-digest、GK** 等摘要演算法做近似 |
| 相異值個數 | ✗ | HyperLogLog 近似基數估計 |

**近似分位數（Approximate Quantile）的定義要背準：在可容忍的誤差範圍內，以極低記憶體與運算成本快速估算分位值，以支援即時／串流分析。** 它不是用機器學習去「預測」分位數，也不是只能批次處理。

### 變形三：離群值被稀釋

數千萬筆交易中詐欺佔 0.01%，即使金額異常，對整體平均與變異數的影響幾乎為零。**在大數據裡，彙總統計量對異常事件的敏感度是下降的**，所以異常偵測必須另起爐灶：分群／分時段的基準線、Z 分數、MAD、核密度估計、滑動視窗統計，而不是盯著全域平均。

## 34.4 大樣本下的推論失真

### 失真一：顯著性膨脹（官方稱 p 值膨脹，p-value inflation）

機制只有一行：檢定統計量 ≈ (觀察差異) ÷ (σ/√n)。**n 變大 → 標準誤變小 → 統計量變大 → p 值變小，但分子「觀察差異」完全沒變。**

官方指引的例子：兩版廣告各 50 萬人，點擊率差 0.05%，p 值可以小於 0.0001。統計上「非常顯著」，商業上毫無意義。

| 你想問的問題 | 該看的東西 |
|---|---|
| 差異有沒有可能只是隨機造成？ | p 值 |
| 差異有多大？ | **效果量（Effect Size）** |
| 差異的可能範圍在哪？ | **信賴區間（Confidence Interval）** |
| 這個差異值不值得做？ | 業務上的最小有意義差異（實務顯著性） |

**常見效果量**：兩組平均數用 Cohen's d（慣例參考值 0.2 小／0.5 中／0.8 大，非硬門檻）；比例用相對提升率或勝算比（Odds Ratio）；類別關聯用 Cramér's V；迴歸整體用 R²。

信賴區間之所以比 p 值好用，是因為它同時回答「顯著嗎」與「差多少」：95% CI 若為 [0.02%, 0.08%]，你立刻知道就算是真的，也小到不必理會。

### 失真二：多重比較（Multiple Comparisons）

同時做 m 次檢定，即使每次都控制 α = 0.05，整體出現至少一個偽陽性的機率是 1 − (1−α)^m：做 20 次約 64%，做 1,000 次趨近 100%，且期望會產生約 50 筆假的「顯著」結果。

| 策略 | 控制的錯誤率 | 作法 | 特性 |
|---|---|---|---|
| **整體檢定**（如 One-Way ANOVA） | 族系錯誤率 FWER | 用單一 F 檢定取代多次兩兩 t 檢定 | 比較 3 組以上平均數的首選 |
| **Bonferroni 修正** | **FWER**（至少一個偽陽性的機率） | 門檻改為 α/m | 最嚴格，m 大時幾乎抓不到真效果 |
| **Benjamini–Hochberg** | **FDR**（宣稱顯著者中偽陽性的期望比例） | 排序 p 值後逐級比較 | 較寬鬆，適合大規模篩選（特徵、基因、廣告版位） |

**兩者控制的東西不同，不是「嚴格版與寬鬆版的同一件事」**：Bonferroni 問的是「我會不會冤枉任何一個」，FDR 問的是「我發表的這批結論裡有幾成是假的」。共同代價是檢定力（Power）下降——這就是敏感度與特異度之間的取捨。

### 失真三：觀測不獨立

t 檢定、線性迴歸、卡方檢定都假設樣本互相獨立。一位使用者 24 小時內產生數百筆點擊，這些紀錄高度相關。**若把它們當成獨立樣本，會低估資料真實的變異程度 → 標準誤被算小 → 信賴區間過窄 → 本來不顯著的變成顯著。**（方向要記牢：是變窄、變顯著，不是變寬。）

補救：以「使用者」而非「事件」為分析與隨機化單位、群集穩健標準誤（Cluster-robust SE）、混合效應模型；驗證時用 Group K-Fold 避免同一對象跨越訓練與測試。

### 失真四：母體定義不清與運算限制

推論的對象是誰？某電商 2023 年交易資料能不能代表全體使用者、能不能外推到 2024 年新客？母體界線沒寫清楚，結論就沒有適用範圍。另外，Bootstrap、置換檢定（Permutation Test）、貝氏估計都依賴大量重複抽樣，在 Spark／Hive 這類為批次查詢設計的平台上成本極高——這也是實務上統計推論常被機器學習模型取代的現實原因。

## 34.5 相關、迴歸與因果

### 相關不等於因果：四種替代解釋

觀察到 X 與 Y 相關，在排除以下四者之前不能談因果：

```
X → Y  真正的因果
Y → X  反向因果（用藥量與病情嚴重度相關，是病情決定用藥）
Z → X 且 Z → Y  混淆變數（冰淇淋銷量與溺水數相關，共同原因是氣溫）
X → C ← Y  對撞變數／選擇偏誤（只看錄取者，才會出現能力與背景的負相關）
純屬巧合  虛假相關（大數據中變數一多，高相關必然大量出現）
```

**大數據讓這件事更危險**：變數數量越多，純靠隨機就能撈到的高相關對數量呈平方成長。

### 相關係數的選用

| 係數 | 衡量什麼 | 對離群值的穩健度 | 值域 |
|---|---|---|---|
| **Pearson** | 線性關係的強度與方向 | 最差（差值被平方放大） | [−1, 1] |
| **Spearman** | 單調關係（先轉排名再套 Pearson 公式） | 中 | [−1, 1] |
| **Kendall** | 單調關係（一致對 vs 不一致對的數量差） | **最強** | [−1, 1] |

穩健度順序是 **Kendall > Spearman > Pearson**，官方 115-1 第 24 題的錯誤選項就是把前兩者說反。另外，**r = 0 只排除線性關係，不代表獨立**：y = x² 在對稱區間上的 Pearson r 可以是 0。

### 迴歸分析：大數據下該注意什麼

線性迴歸的假設是模型關係為線性，且誤差項獨立、同質變異、常態，並無完全共線性。**注意假設的對象是「誤差項」，不是特徵或目標變數本身必須常態。**

| 症狀 | 診斷 | 處理 |
|---|---|---|
| Y 右偏且變異隨 X 增大 | 殘差呈喇叭狀擴散＝異質變異 | 對 **Y** 做 Box–Cox／對數轉換 |
| 殘差呈系統性彎曲 | 非線性或有離群值 | 加入非線性項、改用樹模型 |
| 殘差按順序呈週期 | 自相關（時間序列常見） | 差分、加入時間項、改用時序模型 |
| 係數正負與常識相反 | 多重共線性 | 看 VIF、移除或合併變數、改用 Ridge |
| n 極大時幾乎所有係數都顯著 | 顯著性膨脹 | 看係數大小與信賴區間，不看星號 |

考程式碼時只考兩件事，而且兩者順序相反：

```python
# scikit-learn：先特徵後標籤
reg = LinearRegression().fit(X, y)
reg.coef_        # 只有特徵係數，不含截距
reg.intercept_   # 截距在這裡

# statsmodels：先標籤後特徵，且要自己加常數項
X2 = sm.add_constant(X)
model_sm = sm.OLS(y, X2).fit()
model_sm.summary()   # 這裡才看得到各係數的 p 值
```

**迴歸係數顯著，代表「在此模型設定下該變數與 Y 的關聯不太可能為零」，不代表它造成了 Y 的改變。** 遺漏任何一個混淆變數，係數就可能完全改變意義。

### 辛普森悖論（Simpson's Paradox）

分組後每一組都是 A 勝，合併起來卻變成 B 勝。

| 裝置 | 版本 A 轉換率 | 版本 B 轉換率 |
|---|---|---|
| 桌機（易轉換） | 80 / 100 = **80.0%** | 190 / 250 = 76.0% |
| 手機（難轉換） | 90 / 300 = **30.0%** | 40 / 150 = 26.7% |
| **合計** | 170 / 400 = 42.5% | 230 / 400 = **57.5%** |

A 在兩個裝置上都贏，合併卻輸 15 個百分點。原因不是算錯，是**權重**：A 的流量有 75%（300/400）落在低轉換的手機，B 只有 37.5%。裝置同時影響了「被分到哪個版本」與「會不會轉換」，是典型的混淆變數。

**該看分組還是合併？不是一律看分組：**

| 分組變數的角色 | 判準 | 該看 |
|---|---|---|
| **混淆變數**（在處理之前就存在，如裝置、年齡、地區） | 它同時影響分組與結果 | **分組結果**（要控制它） |
| **中介變數**（在處理之後才發生，位於因果路徑上） | 處理 → 中介 → 結果 | **合併結果**（控制它會擋掉部分真實效果） |

實務上的預防：分流時就做**分層隨機化**，並在分析前檢查各組樣本比例是否符合預期（Sample Ratio Mismatch, SRM）。

## 34.6 A/B 測試：把關聯變成因果的工程手段

A/B 測試之所以能談因果，靠的是**隨機分派（Randomization）**——讓所有已知與未知的混淆變數在兩組間期望上相等。**不是因為樣本數大**：觀察性資料再多，也不會自動變成實驗。

### 標準流程

```
① 定義單一主要指標（OEC）與最小可檢測效果 MDE
② 事前算樣本數與實驗天數（先決定，不是邊跑邊看）
③ 以「使用者」為單位隨機分派（不是以事件為單位）
④ A/A 測試驗證分流機制無偏
⑤ 跑滿預定期間 → 才看結果
⑥ 一起報：效果量 + 信賴區間 + p 值
```

### 七個實務錯誤

| 錯誤 | 後果 | 對策 |
|---|---|---|
| **偷看 p 值提早喊停（Peeking）** | 反覆檢定＝多重比較，偽陽性遠高於 5% | 事前定樣本數；要期中分析就用序貫檢定 |
| 只報 p 值不報效果量 | 大樣本下 0.05% 的差也「顯著」 | 三件套一起報 |
| 同時追蹤數十個指標 | 多重比較，總有一個會亮 | 一個主要指標；次要指標做 FDR 校正 |
| 以事件為隨機化單位 | 同一使用者橫跨兩組，觀測不獨立 | 以使用者 ID 雜湊分流 |
| 分流比例失衡 | 觸發辛普森悖論、結論反轉 | 檢查 SRM、分層隨機化 |
| 實驗期太短 | 新奇效應（Novelty Effect）灌水 | 至少涵蓋完整週期（含週末） |
| 使用者之間互相影響 | 違反處理穩定性假設（SUTVA） | 改用叢集隨機化（依地區／社群分組） |

當隨機分派做不到（不能隨機決定誰抽菸、誰用某功能），才退而求其次用準實驗方法：斷點迴歸、差異中的差異（DID）、傾向分數配對、工具變數——**這些是「近似因果」，不是「等同實驗」。**

## 34.8 易錯與陷阱

- [ ] **p 值小代表「這個差異不太可能純粹由隨機造成」，不是「這個差異很大」** —— 50 萬 vs 50 萬的兩組，0.05% 的差距也能做出 p < 0.0001。要判斷值不值得做，看效果量與信賴區間。
- [ ] **增大樣本數縮小的是隨機誤差，不是系統性偏誤** —— SE = σ/√n 只壓得住前者；非隨機抽樣的偏誤不隨 n 消失，反而因為信賴區間變窄而看起來更可信。
- [ ] **Bonferroni 控制的是 FWER（至少出現一個偽陽性的機率），Benjamini–Hochberg 控制的是 FDR（宣稱顯著者中偽陽性的期望比例）** —— 兩者管的是不同的錯誤率，不是同一件事的鬆緊兩檔。
- [ ] **ANOVA 取代多次兩兩 t 檢定，目的是把整體型一錯誤控制在 α，不是因為 ANOVA「比較準」** —— 三組做三次 t 檢定，累積偽陽性機率遠高於 0.05。
- [ ] **相關係數 r = 0 只排除線性關係，不代表兩變數獨立** —— y = x² 在對稱區間上的 Pearson r 可以是 0。
- [ ] **對離群值的穩健度是 Kendall > Spearman > Pearson** —— Pearson 用原始值且差距被平方放大最脆弱；Kendall 只看成對順序最穩。三者值域都是 [−1, 1]。
- [ ] **Spearman 是「把原始值換成排名後代入 Pearson 公式」，不是另一套獨立公式。**
- [ ] **辛普森悖論是分組與合併的結論方向相反，不是資料算錯** —— 成因是各組的樣本權重不同，加上一個同時影響分組與結果的混淆變數。
- [ ] **遇到辛普森悖論不是一律看分組** —— 分組變數若是**混淆變數**（處理之前就存在）就看分組；若是**中介變數**（在因果路徑上）控制它反而會擋掉真實效果，應看合併。
- [ ] **A/B 測試能支持因果推論靠的是隨機分派，不是樣本數大** —— 觀察性大數據累積再多，也不會自動變成實驗。
- [ ] **偷看 p 值提早喊停等同於多重比較** —— 每看一次就多一次檢定機會，實際偽陽性率遠高於名目 α；要期中分析請用序貫檢定。
- [ ] **分層抽樣要層內同質、層間異質；群集抽樣要群內異質、群間同質** —— 這組定義互換是高頻誘答。
- [ ] **平台的「全量資料」不等於母體** —— 只有進得了資料來源的人才在裡面；母體定義寫不清楚，推論對象就是模糊的，跨年度外推尤其危險。
- [ ] **同一使用者的多筆紀錄不是獨立觀測；當成獨立樣本會低估變異，使信賴區間過窄、把不顯著變成顯著** —— 方向是變窄、變顯著，不是變寬。
- [ ] **右偏長尾看中位數與分位數，不看平均數** —— mean ≫ median 就是右偏訊號；用平均數填補缺失會把分布往右推並壓縮變異。
- [ ] **厚尾風險要用分位數迴歸抓尾部，不是把資料裁切到 ±3σ** —— 剪掉的極端事件正是風險分析的標的。
- [ ] **近似分位數是「以可容忍誤差換速度與記憶體」，不是用機器學習預測分位數，也不是只能批次處理** —— t-digest、GK 正是為串流設計。
- [ ] **count、sum、平方和可分散合併，中位數不可** —— 這就是平均數與標準差能直接 `agg` 算出、分位數卻必須近似的原因；`collect()` 回 Driver 在 10 億筆下必然 OOM。
- [ ] **sklearn 是 `fit(X, y)`，statsmodels 是 `sm.OLS(y, X)`，順序相反** —— 而且 `reg.coef_` 只有特徵係數，截距在 `reg.intercept_`；statsmodels 要先 `add_constant` 才有截距。
- [ ] **特徵篩選的相關係數只能用訓練集算** —— 在含測試集的全體資料上算完再刪特徵，就是資料洩漏，測試分數會被高估。
- [ ] **線性迴歸假設的是「誤差項」常態與同質變異，不是特徵或目標變數本身必須常態。**
- [ ] **迴歸係數顯著代表關聯不太可能為零，不代表該變數造成了 Y 的改變** —— 遺漏一個混淆變數，係數的意義就可能整個翻掉。
- [ ] **「不拒絕虛無假設」不等於「接受虛無假設」** —— 可能只是樣本數不足或檢定力不夠。
- [ ] **提升度 Lift > 1 是正向關聯，Lift = 1 才是統計獨立** —— 而且關聯規則描述的是共現，不是因果。
