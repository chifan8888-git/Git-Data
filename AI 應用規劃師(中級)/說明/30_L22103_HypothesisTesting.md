## 30.1 統計推論的兩條分支

統計推論（Statistical Inference）是「根據部分，推論整體」——用樣本資料推估母體特徵。它底下分成兩條分支，考題最愛把兩條分支的產出物互換當誘答。

### 參數估計 vs 假設檢定

| 維度 | 參數估計（Parameter Estimation） | 假設檢定（Hypothesis Testing） |
|---|---|---|
| **目的** | 推測母體參數的「值」或「區間」 | 驗證關於母體參數的「主張」是否成立 |
| **回答的問題** | 這個參數大約是多少？ | 我們有沒有足夠證據拒絕某個假設？ |
| **輸出** | 點估計值 + 信賴區間（如 95% CI） | 檢定統計量 + p 值 + 拒絕／不拒絕的決策 |
| **事前要準備** | 抽樣方法、估計量 | H₀／H₁、顯著水準 α、檢定方法 |
| **典型句子** | 「平均體重 68 公斤，95% CI 為 [66, 70]」 | 「p = 0.03 < 0.05，拒絕 H₀」 |

兩者依賴同一套機率模型，只是把不確定性包裝成不同形式：估計包成區間，檢定包成機率門檻。

### 點估計與區間估計

```
點估計（Point Estimation）
  用一個數字代表母體參數：樣本平均數 x̄ → 母體平均數 μ
  優點：簡潔
  缺點：完全沒有反映「這個數字有多不確定」

區間估計（Interval Estimation）
  給出一段範圍 + 一個信心水準：[66, 70]，95%
  優點：同時交代估計值與不確定性
  實務：點估計與區間估計通常一起報告
```

### 信賴區間怎麼念才對

這是本節第一個高頻誘答來源。95% 信賴區間的正確語句是：

> **若以相同方式重複大量抽樣，並對每個樣本各建一個區間，則這些區間中約有 95% 會涵蓋母體真值。**

錯誤語句是：「母體參數有 95% 的機率落在這個特定區間內」。在頻率學派（Frequentist）框架下，母體參數是固定的未知常數，不是隨機變數，會隨抽樣而變動的是「區間」本身，不是參數。95% 描述的是這套造區間程序的長期表現，不是對眼前這條區間下的機率賭注。

### 信賴區間與假設檢定的對偶關係

在**同一組資料、同一個雙尾檢定**之下，兩者結論必然一致：

| 情況 | 信賴區間的表現 | 假設檢定的表現 |
|---|---|---|
| 假設值 μ₀ **落在** (1−α) 信賴區間內 | 區間涵蓋 μ₀ | p > α，**無法拒絕** H₀ |
| 假設值 μ₀ **落在區間外** | 區間不涵蓋 μ₀ | p ≤ α，**拒絕** H₀ |

前提要寫清楚：要對得上，信賴水準必須等於 1 − α（95% CI 對應 α = 0.05），且是**雙尾**檢定。單尾檢定要對應的是單邊信賴界限，不能直接拿雙尾 CI 去比。

### 什麼會讓信賴區間變寬

區間半寬大致是 `臨界值 × 標準誤`，而標準誤是 `s / √n`。所以寬度同時受三個因素牽動：

| 因素 | 變動方向 | 對區間寬度 |
|---|---|---|
| 信賴水準（90% → 99%） | 提高 | **變寬**（要更有把握，就得畫更大的網） |
| 樣本數 n | 增加 | **變窄**（但只以 √n 的速度收斂，n 要變 4 倍才窄一半） |
| 樣本標準差 s（資料變異） | 增加 | **變寬** |

考題誘答：「信賴區間寬度僅與顯著水準有關」——錯，樣本數與資料變異同樣是決定因素。

## 30.2 假設檢定的五個步驟

```
┌──────────────────────────────────────────────────┐
│ ① 設定 H₀ 與 H₁                                  │
│    H₀ = 現狀／無差異／無效果（要被檢驗的對象）     │
│    H₁ = 研究者想證實的新主張                      │
│    同時決定單尾或雙尾                             │
├──────────────────────────────────────────────────┤
│ ② 選擇檢定方法與檢定統計量                        │
│    看資料型態、組數、是否配對、前提假設是否成立    │
│    → t 值 / Z 值 / F 值 / 卡方值 / U 值           │
├──────────────────────────────────────────────────┤
│ ③ 決定顯著水準 α                                 │
│    事前設定，常見 0.01 / 0.05 / 0.10              │
├──────────────────────────────────────────────────┤
│ ④ 計算檢定統計量，對照理論分佈求出 p 值           │
├──────────────────────────────────────────────────┤
│ ⑤ 比較 p 值與 α，作出結論                        │
│    p ≤ α → 拒絕 H₀（結果達統計顯著）              │
│    p > α → 無法拒絕 H₀（證據不足，非證明 H₀ 為真）│
└──────────────────────────────────────────────────┘
```

### 步驟 ①：H₀ 與 H₁ 的分工

| | 虛無假設 H₀ | 對立假設 H₁ |
|---|---|---|
| **內容** | 現狀、無差異、無效果 | 有差異、有效果、有改變 |
| **角色** | 檢定的基準起點，被檢驗的對象 | 與 H₀ 互斥，H₀ 被拒絕時才間接被支持 |
| **結論邏輯** | 無法拒絕 **≠** 接受，只代表證據不足 | 拒絕 H₀ 才代表支持 H₁ |
| **藥效範例** | 新藥與安慰劑效果相同 | 新藥效果不同於安慰劑 |
| **A/B 測試範例** | 新舊版本轉換率無顯著差異 | 新版本轉換率顯著不同於舊版本 |

假設檢定的邏輯是**反證**，不是證明：資料只能用來「推翻」H₀，不能用來「確立」H₀。

### 單尾與雙尾

| 形式 | H₁ 寫法 | 什麼時候用 |
|---|---|---|
| 雙尾（Two-tailed） | μ ≠ μ₀ | 只想知道有沒有差異，不預設方向 |
| 左尾（Left-tailed） | μ < μ₀ | 只關心是否「變小／變差」（如檢驗降血壓效果） |
| 右尾（Right-tailed） | μ > μ₀ | 只關心是否「變大／改善」（如檢驗良率是否超標） |

**方向必須事前決定。** 先看到資料往哪邊偏再改成單尾，等於偷偷把顯著門檻放寬一倍，是典型的 p-hacking。

### 步驟 ③：顯著水準 α

α 是**事前設定**的決策門檻，其定義就是「在 H₀ 為真的前提下，仍錯誤拒絕 H₀ 的機率上限」，也就是型一錯誤率的上限。

| α | 嚴格度 | 典型情境 |
|---|---|---|
| 0.01 | 最嚴格 | 藥物療效、安全風險、高金額決策——誤判成本極高 |
| 0.05 | 通用標準 | 多數商業與學術分析 |
| 0.10 | 較寬鬆 | 探索性研究、假說生成階段 |

### 步驟 ④：p 值的正確定義

> **p 值 = 在 H₀ 為真的前提下，觀察到「與目前結果相同或更極端」的資料出現的機率。**

把定義拆成三個必要成分，少一個就不對：①前提是 H₀ 為真、②對象是資料（檢定統計量）、③範圍包含「更極端」的情形。

| 常見錯誤說法 | 為什麼錯 |
|---|---|
| 「p 值是 H₀ 為真的機率」 | 方向顛倒。p 值是 P(資料 \| H₀)，不是 P(H₀ \| 資料) |
| 「p 值是犯型一錯誤的機率」 | 型一錯誤率的上限是事前設定的 α；p 值是事後算出的觀察值 |
| 「p = 0.001 代表效果很大」 | p 值同時受效應量與樣本數影響，大樣本會讓微小差異也有極小 p 值 |
| 「1 − p 是 H₁ 為真的機率」 | 同樣是把條件機率反過來念 |

**α 與 p 值的分工**：α 是事前畫的線，p 值是事後量到的位置，結論由「p 值有沒有越線」決定。

### 步驟 ⑤：「無法拒絕」不是「接受」

p > α 時，正確措辭是「**無法拒絕 H₀**」或「證據不足以支持 H₁」，不能寫成「接受 H₀」「證明兩者相同」。因為「沒測到差異」有兩種可能：真的沒差異，或是有差異但**檢定力不足沒測出來**（型二錯誤）。這兩種情形，資料本身分不出來。

## 30.3 型一錯誤、型二錯誤與檢定力

### 決策矩陣

| | **H₀ 實際為真** | **H₀ 實際為假** |
|---|---|---|
| **不拒絕 H₀** | 正確判斷，機率 = 1 − α | **型二錯誤（漏判／偽陰性）**，機率 = β |
| **拒絕 H₀** | **型一錯誤（誤判／偽陽性）**，機率 = α | 正確判斷＝**檢定力（Power）**，機率 = 1 − β |

- **型一錯誤（Type I Error）**：本來沒差異，卻判成有差異。機率由 α 控制。
- **型二錯誤（Type II Error）**：本來有差異，卻沒判出來。機率為 β。
- **檢定力（Statistical Power）= 1 − β**：當 H₁ 為真時，正確拒絕 H₀ 的能力。

### 情境對照（把抽象錯誤變成可判斷的句子）

| 情境 | H₀ | 型一錯誤的樣子 | 型二錯誤的樣子 |
|---|---|---|---|
| 地震預警 | 沒有即將發生的強震 | 發出錯誤警報，實際沒地震 | 未發警報，實際發生強震 |
| 銀行防詐 | 該筆交易為正常行為 | 合法交易被擋 | 詐騙交易被放行 |
| 製造品管 | 出廠產品為合格品 | 良品被判不合格，浪費 | 瑕疵品流入市場 |
| 電商評論過濾 | 評論為正常留言 | 正常評論被誤刪 | 違規內容持續顯示 |
| 新藥審查 | 新藥與安慰劑無差異 | 無效藥被認定有效、獲准上市 | 有效藥被錯過 |

### α 與 β 的蹺蹺板

**在樣本數與效應量固定不變的條件下**，調降 α 會縮小拒絕區，型一錯誤下降、型二錯誤上升、檢定力下降；調高 α 則相反。

```
α 0.05 → 0.01
  ├─ 型一錯誤（偽陽性）↓   ← 這是「直接效果」
  ├─ 型二錯誤 β ↑
  └─ 檢定力 1−β ↓

想同時壓低兩種錯誤，最直接而不必犧牲另一邊的手段是「增加樣本數」
（或降低測量變異、改用更有效率的檢定設計）
```

注意這句話的限定條件：只有在 n 與效應量不變時，α 與 β 才是單純的此消彼長。若同時把樣本數加大，兩者可以一起降低。

### 提高檢定力的途徑

| 做法 | 機制 | 代價 |
|---|---|---|
| **增加樣本數 n** | 標準誤變小，同樣的差異更容易達顯著 | 成本、時間 |
| 降低測量變異 | 標準誤變小 | 需改善實驗控制或量測方法 |
| 效應量本身較大 | 訊號變強 | 不是研究者能決定的 |
| 採用配對／區組設計 | 排除個體間變異 | 需要能合理配對的資料 |
| 前提成立時用參數檢定 | 參數檢定比無母數更有效率 | 前提不成立時反而失真 |
| 提高 α | 拒絕區變大 | 型一錯誤同步上升 |

**檢定力分析（Power Analysis）** 是在研究開始前，依 α、目標檢定力（常設 0.80）與預期效應量反推所需樣本數，屬於事前規劃工具。

### 多重比較：整體型一錯誤率會膨脹

每做一次檢定就有 α 的偽陽性風險。若在同一份資料上獨立做 m 次檢定，整體至少犯一次型一錯誤的機率約為 `1 − (1 − α)^m`：

| 檢定次數 m | α = 0.05 時的整體偽陽性機率 |
|---|---|
| 1 | 5% |
| 3 | 約 14% |
| 10 | 約 40% |
| 20 | 約 64% |

兩種應對方式：
1. **改用一個整體檢定**——三組以上比較平均數時，用單因子 ANOVA 的單一 F 檢定取代三次兩兩 t 檢定，把整體型一錯誤率鎖回 α。
2. **調整門檻**——如 **Bonferroni 校正**，把每次檢定的門檻壓成 α/m（做 10 次就用 0.005）。代價是檢定力下降。

## 30.4 檢定方法選擇：本節最大的考點

### 一張總表

| 想回答的問題 | 資料型態 | 對應檢定 | 關鍵前提 |
|---|---|---|---|
| 一組數值是否與某理論值不同 | 連續，σ **未知** | **單樣本 t 檢定** | 近似常態（n ≥ 30 可依 CLT 放寬） |
| 一組數值是否與某理論值不同 | 連續，σ **已知** | **單樣本 Z 檢定** | 母體標準差已知 |
| 兩組**不同個體**的平均是否不同 | 連續，兩獨立組 | **獨立樣本 t 檢定** | 常態 + 變異數齊一（不齊改 Welch） |
| **同一批人**前後是否變化 | 連續，配對 | **成對樣本 t 檢定** | 差值近似常態 |
| 三組以上平均是否有差異 | 連續，≥ 3 獨立組 | **單因子 ANOVA（F 檢定）** | 常態 + 變異數齊一 + 獨立 |
| 一組比例是否與預期不同 | 二元類別 | **單樣本比例 Z 檢定** | np₀ 與 n(1−p₀) 皆 ≥ 5 |
| 兩組比例是否不同 | 二元類別，兩獨立組 | **雙比例 Z 檢定** | 同上；不足改 Fisher 精確檢定 |
| 兩個類別變數是否相關 | 列聯表 | **卡方獨立性檢定** | 各格期望次數 ≥ 5；用原始次數 |
| 觀察分佈是否符合理論分佈 | 類別次數 | **卡方適合度檢定** | 同上 |
| 兩連續變數是否線性相關 | 連續 × 連續 | **皮爾森相關檢定** | 線性、近似常態、無重大離群值 |
| 兩變數是否單調相關 | 順序或偏態連續 | **斯皮爾曼／肯德爾等級相關** | 可排名、單調關係 |
| 兩獨立組的分佈位置是否不同（非常態） | 順序或非常態連續 | **Mann-Whitney U 檢定** | 兩組分佈形狀相似才可解讀為中位數差 |
| 三組以上分佈位置是否不同（非常態） | 順序或非常態連續 | **Kruskal-Wallis 檢定** | 獨立樣本；事後用 Dunn's test |

### 決策流程

```
Step 1：應變數是什麼型態？
  ├─ 二元／類別 ──────────→ 比例檢定 或 卡方檢定
  ├─ 順序 或 明顯非常態 ──→ 無母數檢定
  └─ 連續且近似常態 ──────→ 往 Step 2

Step 2：要比幾組？
  ├─ 1 組 vs 理論值 ─→ σ 已知？ 是 → Z 檢定 ／ 否 → 單樣本 t 檢定
  ├─ 2 組 ───────────→ 往 Step 3
  └─ 3 組以上 ───────→ 單因子 ANOVA（顯著後做事後檢定）

Step 3：兩組之間有配對關係嗎？
  ├─ 同一批對象前後測、雙胞胎、一對一配對 ─→ 成對樣本 t 檢定
  └─ 不同個體、互不相關 ─────────────────→ 獨立樣本 t 檢定
        └─ 變異數不齊（Levene's test 顯著）→ 改用 Welch's t 檢定

若只是要衡量兩變數的關聯而非比較組別 ──→ 相關分析（Pearson / Spearman / Kendall）
```

**Step 3 是官方最愛設的陷阱**：題幹只要出現「同一批人」「導入前後各測一次」「治療前後」，就是配對資料，用獨立樣本 t 檢定會白白丟掉個體間變異的控制、拉低檢定力。

### t 檢定三兄弟

| | 單樣本 t | 獨立樣本 t | 成對樣本 t |
|---|---|---|---|
| **比較對象** | 樣本平均 vs 已知常數 μ₀ | 兩組獨立樣本的平均 | 同一對象兩次測量的**差值** |
| **H₀** | μ = μ₀ | μ₁ = μ₂ | μ_d = 0 |
| **資料來源** | 一組 | 兩組不同個體 | 一組個體、兩個時點（或配對組） |
| **常態性要求對象** | 原始資料 | 各組原始資料 | **差值** |
| **額外前提** | — | 變異數齊一（否則 Welch） | 配對規則須事先定義清楚 |
| **典型題幹** | 「是否與法規標準 / 宣稱值不同」 | 「男性 vs 女性」「A 產品 vs B 產品」 | 「導入系統前後」「治療前後」 |

### Z 檢定 vs t 檢定

| | Z 檢定 | t 檢定 |
|---|---|---|
| 母體標準差 σ | **已知** | **未知**，用樣本標準差 s 取代 |
| 參照分佈 | 標準常態分佈 | 自由度 n−1 的 t 分佈（尾部較厚） |
| 小樣本 | 不適用（除非 σ 真的已知） | 適用（n < 30 時尤其該用 t） |
| 大樣本 | — | n 增大時 t 分佈趨近標準常態，兩者結果接近 |

**計算示範**（官方 115-1 第 8 題的型態）：已知母體標準差 σ = 16、樣本 n = 9、樣本平均 x̄ = 40、宣稱值 μ₀ = 36，右尾檢定 α = 0.05（臨界值 1.645）。

```
標準誤 SE = σ / √n = 16 / √9 = 16 / 3 ≈ 5.333
Z = (x̄ − μ₀) / SE = (40 − 36) / 5.333 ≈ 0.75
0.75 < 1.645 → 落在不拒絕區 → 不拒絕 H₀
結論：沒有足夠證據認定平均外送時間超過 36 分鐘
```

最常見的算錯點：把 √n 忘掉（直接用 4/16 = 0.25），或多除一次 n。**分母一定是 σ/√n，不是 σ，也不是 σ/n。**

### 三組以上：ANOVA 與事後檢定

- **H₀**：μ₁ = μ₂ = … = μₖ（所有組平均相同）
- **H₁**：**至少有一組**與其他組不同（不是「全部都不同」）
- **統計量**：F 值，概念是「組間變異 ÷ 組內變異」
- **顯著之後**：ANOVA 只告訴你「存在差異」，不指出是哪一組，須再做**事後檢定（Post-hoc test）**，如 Tukey HSD
- **前提**：各組獨立、應變數連續、各組常態、變異數齊一（Levene's test 檢查）
- **應變數與自變數型態**：應變數必須是**連續**，自變數是**類別**（分組）

只有兩組時，官方指引明列「應使用 t 檢定而非 ANOVA」。（數學上兩組的單因子 ANOVA 與雙尾獨立樣本 t 檢定等價，F = t²，結論一致，但作答時依指引選 t 檢定。）

### 比例與類別：比例 Z 檢定 vs 卡方檢定

| | 雙比例 Z 檢定 | 卡方檢定 |
|---|---|---|
| 適用 | 兩組二元比例的差 | 類別變數的關聯／分佈吻合度 |
| 組數 | 恰好兩組 | 兩個以上類別、R×C 列聯表皆可 |
| 方向性 | **可做單尾**（誰高於誰） | 本質上是雙尾的「有無關聯」 |
| 輸入資料 | 各組的成功數與樣本數 | **原始次數**（不可直接餵百分比） |
| 小樣本替代 | Fisher 精確檢定 | 合併類別或 Fisher 精確檢定 |

補充關係：2×2 列聯表上，卡方檢定與雙尾（合併比例）雙比例 Z 檢定在數學上等價（χ² = Z²）。因此題目若強調「新生產線良率是否**提升**」這種方向性比較，雙比例 Z 檢定是更直接的選擇。

### 卡方的兩種用途

| | 獨立性檢定（Test of Independence） | 適合度檢定（Goodness-of-Fit） |
|---|---|---|
| 資料形狀 | 兩個類別變數的交叉表 | 單一類別變數的次數分佈 |
| H₀ | 兩變數彼此獨立、無關聯 | 觀察分佈與理論／預期分佈相同 |
| H₁ | 兩變數有關聯 | 觀察分佈與預期分佈不同 |
| 範例 | 性別 × 投票傾向是否有關 | 骰子是否公平、各月銷量是否均勻 |

共同注意事項：各格**期望次數應 ≥ 5**（低於 5 建議合併類別或改 Fisher 精確檢定）；顯著只代表「有關聯」，關聯**強度**要另外用 Cramér's V 或 Phi 係數衡量；樣本極大時微小差異也會顯著。

### 相關性分析：三個係數的分界

| | 皮爾森 Pearson (r) | 斯皮爾曼 Spearman (rs) | 肯德爾 Kendall (τ) |
|---|---|---|---|
| 衡量什麼 | **線性**關係 | **單調**關係 | **單調**關係 |
| 計算基礎 | 原始數值 | 數值換成**排名**後代入 Pearson 公式 | 一致對與不一致對的**數量差** |
| 資料要求 | 兩連續變數、近似常態 | 順序或可排名的連續資料 | 同左 |
| 對離群值 | **最敏感**（被平方放大） | 較穩健 | **最穩健** |
| 值域 | [−1, 1] | [−1, 1] | [−1, 1] |

穩健度排序是 **Kendall > Spearman > Pearson**，官方考題直接拿「Spearman 比 Kendall 更穩健」當錯誤敘述。三者的值域**都**是 [−1, 1]，這點沒有差別。

不論用哪一個，顯著的相關係數都**只代表關聯，不代表因果**；Pearson 的 r ≈ 0 也只否定了線性關係，資料可能呈拋物線等強烈但非線性的依存。

### 無母數檢定對照表

| 參數檢定（需常態） | 對應的無母數替代 | 適用情境 |
|---|---|---|
| 獨立樣本 t 檢定 | **Mann-Whitney U 檢定** | 兩獨立組、非常態或順序資料 |
| 成對樣本 t 檢定 | **Wilcoxon 符號等級檢定** | 配對兩組、非常態 |
| 單因子 ANOVA | **Kruskal-Wallis 檢定** | 三組以上獨立、非常態 |
| 重複量數 ANOVA | **Friedman 檢定** | 三組以上配對／重複量數 |
| 皮爾森相關 | **Spearman／Kendall 等級相關** | 非線性單調、順序資料 |

兩個共通注意事項：
1. 無母數檢定比較的是**分佈位置／中位數與排名**，不能解讀成「平均數有差異」。
2. 要把結果解讀成「中位數不同」，還需要**各組分佈形狀大致相似**這個前提；形狀差很多時，顯著只代表「分佈不同」。

## 30.5 前提假設與常見誤用

### 前提檢查清單

| 前提 | 適用於 | 怎麼檢查 | 不成立時怎麼辦 |
|---|---|---|---|
| 常態性 | t 檢定、ANOVA、Pearson | Q-Q 圖、Shapiro-Wilk | 改無母數；或 n 夠大時依中央極限定理放寬 |
| 變異數齊一性 | 獨立樣本 t、ANOVA | **Levene's test** | 獨立樣本 t → **Welch's t 檢定**；ANOVA → Welch ANOVA 或無母數 |
| 觀測獨立性 | 幾乎所有檢定 | 看研究設計（有無重複測量、時間序列） | 改用配對／重複量數對應的方法 |
| 期望次數 ≥ 5 | 卡方檢定 | 算列聯表期望值 | 合併類別、Fisher 精確檢定 |
| np ≥ 5 且 n(1−p) ≥ 5 | 比例 Z 檢定 | 直接算（部分教材寫「> 5」） | 二項精確檢定、Fisher 精確檢定 |
| 線性 + 無重大離群值 | Pearson 相關 | 先畫散佈圖 | 改 Spearman／Kendall，或處理離群值 |

**中央極限定理（Central Limit Theorem）講的是「樣本平均數的抽樣分佈」會趨近常態，不是原始資料會變成常態。** 這也是為什麼 n ≥ 30 時可以放寬 t 檢定的常態性要求，卻不能宣稱「資料量夠大，任何資料都服從常態分佈」。

### 統計顯著 ≠ 實質重要

p 值同時被效應量與樣本數推動。當 n 極大時，一個毫無商業意義的差異（例如轉換率從 5.00% 變 5.02%）也能得到 p < 0.001。所以完整的報告應該三樣一起給：

```
① 檢定結果（p 值、是否顯著）
② 效果量（Effect Size）
   平均數差異 → Cohen's d
   列聯表關聯 → Cramér's V / Phi
   無母數     → rank-biserial correlation
③ 信賴區間（差異的可能範圍，直接對應實務決策門檻）
```

反過來也成立：**不顯著不等於沒有效果**，可能只是樣本數不足、變異過大導致檢定力不夠。

### 其他高頻誤用

- **把比例或百分比直接餵進卡方檢定**——卡方統計量依賴原始計數（frequency），用百分比等於把樣本數資訊抹掉。
- **未定義清楚「成功事件」就做比例檢定**——兩組的事件定義必須一致，否則結論無法解釋。
- **H₀ 裡的 p₀ 隨手亂設**——應有依據（歷史數據、業界標準、法規），不能事後配合資料挑一個。
- **看完 p 值再改 α 或改成單尾**——決策門檻與檢定方向都必須事前設定。
- **把 ANOVA 顯著解讀成「所有組都不同」**——只代表至少一組不同，要靠事後檢定指認。

## 30.7 易錯與陷阱

- [ ] **p 值是「H₀ 為真的前提下看到目前或更極端結果的機率」，不是「H₀ 為真的機率」** —— 它是 P(資料 | H₀)，不是 P(H₀ | 資料)；把條件反過來念是本節第一號誘答。
- [ ] **α 是事前設定的決策門檻，p 值是事後算出的觀察值** —— 結論由「p 是否越過 α」決定；看完 p 值再回頭調 α 或改成單尾，是統計上的作弊。
- [ ] **p > α 的正確措辭是「無法拒絕 H₀」，不是「接受 H₀」** —— 證據不足有兩種可能：真的沒差異，或有差異但檢定力不夠（型二錯誤），資料分不出來。
- [ ] **型一錯誤是「沒差異卻判成有差異」（偽陽性，機率 α），型二錯誤是「有差異卻沒判出來」（偽陰性，機率 β）** —— 檢定力是 1 − β，不是 1 − α。
- [ ] **在 n 與效應量不變的條件下，調降 α 會讓型二錯誤上升、檢定力下降，不是兩種錯誤一起下降** —— 要同時壓低兩者，得增加樣本數或降低測量變異。
- [ ] **95% 信賴區間是「重複抽樣時約 95% 的區間會涵蓋真值」，不是「真值有 95% 機率落在這條區間內」** —— 頻率學派下會變動的是區間，不是母體參數。
- [ ] **信賴區間寬度同時受信賴水準、樣本數與樣本標準差影響，不是只受顯著水準影響** —— 半寬 ≈ 臨界值 × s/√n。
- [ ] **信賴區間與檢定的對偶只在「同一資料、雙尾、信賴水準 = 1 − α」時成立，不是任何情況都能直接比對** —— 單尾檢定要對應單邊信賴界限。
- [ ] **同一批人前後測是成對樣本 t 檢定，不是獨立樣本 t 檢定** —— 題幹出現「導入前後」「治療前後」「同一組受試者」就是配對；成對 t 檢定的檢定對象是**差值**的平均是否為 0。
- [ ] **獨立樣本 t 檢定的常態性要求對象是各組原始資料，成對 t 檢定要求的是「差值」近似常態** —— 兩者檢查的東西不同。
- [ ] **變異數不齊時該換 Welch's t 檢定，不是直接放棄 t 檢定改無母數** —— 齊一性用 Levene's test 檢查。
- [ ] **ANOVA 顯著只代表「至少有一組不同」，不是「所有組都彼此不同」** —— 要指認是哪一組，必須再做事後檢定（如 Tukey HSD）。
- [ ] **ANOVA 的應變數必須是連續、自變數是類別，不是反過來** —— 兩個類別變數的關聯要用卡方檢定。
- [ ] **用 ANOVA 取代多次兩兩 t 檢定，是為了控制「整體」型一錯誤率，不是為了提高檢定力** —— 做 10 次 α = 0.05 的檢定，整體偽陽性機率約 40%。
- [ ] **Bonferroni 校正是把每次的門檻壓成 α/m，不是把 α 放大** —— 代價是檢定力下降。
- [ ] **σ 已知用 Z 檢定，σ 未知用樣本標準差時用 t 檢定** —— 不是「小樣本就用 t、大樣本就用 Z」這麼單純；n 大時 t 分佈趨近常態，兩者才接近。
- [ ] **Z 檢定統計量的分母是 σ/√n（標準誤），不是 σ 也不是 σ/n** —— 忘了開根號是官方計算題最主要的誘答來源。
- [ ] **兩組良率／轉換率的比較用雙比例 Z 檢定，不是雙樣本平均數 t 檢定** —— 比例是二元成敗資料，t 檢定處理的是連續變數的平均數。
- [ ] **卡方檢定要餵原始次數，不是百分比或比例** —— 卡方統計量依賴計數規模，用百分比等於抹掉樣本數。
- [ ] **卡方獨立性檢定問「兩個類別變數有沒有關聯」，適合度檢定問「觀察分佈符不符合理論分佈」** —— 兩者的 H₀ 寫法不同，別互換。
- [ ] **卡方顯著只代表「有關聯」，不代表「關聯強」** —— 強度要另外看 Cramér's V 或 Phi 係數；大樣本會讓微小關聯也顯著。
- [ ] **Pearson 衡量線性關係，Spearman 與 Kendall 衡量單調關係** —— 資料呈拋物線時 r 可能接近 0，卻不代表兩變數無關。
- [ ] **對離群值的穩健度是 Kendall > Spearman > Pearson，不是 Spearman 比 Kendall 穩健** —— 這是官方直接拿來當錯誤敘述的方向題。
- [ ] **三種相關係數的值域都是 [−1, 1]，沒有哪一個比較寬** —— 值域不是它們的差別所在。
- [ ] **相關顯著只代表關聯，不代表因果** —— 即使 r 很大、p 很小，也不能宣稱其中一個變數造成另一個變數改變。
- [ ] **Mann-Whitney U 與 Kruskal-Wallis 比較的是分佈位置／中位數與排名，不是平均數** —— 而且要解讀成「中位數不同」，還需各組分佈形狀大致相似。
- [ ] **Mann-Whitney U 對應獨立樣本 t、Wilcoxon 符號等級對應成對 t、Kruskal-Wallis 對應單因子 ANOVA、Friedman 對應重複量數 ANOVA** —— 這四組配對關係是無母數題唯一要背的東西。
- [ ] **比例檢定的常態近似前提是 np 與 n(1−p) 皆 ≥ 5，不是「樣本數大就一定可以近似」** —— 不足時改用二項精確檢定或 Fisher 精確檢定。
- [ ] **中央極限定理說的是「樣本平均數」的抽樣分佈趨近常態，不是原始資料會變成常態** —— 「資料量夠大，任何資料都會呈常態分佈」是標準錯誤敘述。
- [ ] **統計顯著不等於實質重要，不顯著也不等於沒有效果** —— 前者常是樣本數過大所致，後者常是檢定力不足所致；報告時應同時附上效果量與信賴區間。
- [ ] **檢定方向（單尾／雙尾）與 α 都必須事前設定，不能看完結果再選** —— 事後選方向等於偷偷把門檻放寬一倍。
