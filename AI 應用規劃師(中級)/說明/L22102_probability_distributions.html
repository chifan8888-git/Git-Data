機率分佈與資料分佈模型

初級只要求你認得「常態分佈是鐘形」，中級要求你在一段業務敘述裡認出這筆資料背後是哪個機率模型，並說得出它的期望值、變異數、成立前提，以及前提不成立時該換成什麼。本節上接 L22101 敘述性統計（描述手上的樣本），下接 L22103 假設檢定（用分佈當推論的尺）。

學完這一課，你應該能夠

分辨 PMF／PDF／CDF 的定義與適用對象，說得出連續型分佈為何單點機率為 0
背熟並能反向推導七種分佈的期望值與變異數
由情境關鍵字（計數／等待時間／固定次數／獨立／發生率固定）在 30 秒內選出分佈模型
正確敘述中央極限定理與大數法則的作用對象，指出偷換主詞的陷阱

29.1

機率分佈的三個函數：PMF、PDF、CDF

機率分佈（Probability Distribution）是把「隨機變數的所有可能值」對應到「它們的機率」的數學函數。中級考題不會叫你算積分，但會用定義設誘答。

函數全名適用回答的問題關鍵性質
PMFProbability Mass Function（機率質量函數）離散型「恰好等於某個值」的機率 P(X = k)所有可能值的機率總和 = 1
PDFProbability Density Function（機率密度函數）連續型某區間的機率 P(a ≤ X ≤ b) = ∫f(x)dx曲線下總面積 = 1；f(x) 本身不是機率
CDFCumulative Distribution Function（累積分佈函數）兩者皆可「小於或等於某個值」的機率 F(x) = P(X ≤ x)單調不減，由 0 遞增到 1

連續型分佈：常態、指數、卡方

常態分佈 N(μ, σ²)：μ 決定中心、σ 決定胖瘦

經驗法則：

  • 標準化：Z = (X − μ) / σ，轉換後得到標準常態 N(0, 1)。Z 分數表示「偏離平均幾個標準差」，正值在平均之上、負值在平均之下。
  • |Z| ≤ 1 約 68%、|Z| ≤ 2 約 95%、|Z| ≤ 3 約 99.7%。所以 |Z| ≥ 2 約落在雙尾 5%，罕見但仍在常態分佈可解釋的範圍內。
  • 侷限：資料明顯偏態或厚尾時不該硬套常態。應換轉換或換方法（對數轉換、Box–Cox、對數常態、t 分佈、分位數迴歸），而不是把極端值裁掉。

連續型分佈中具備無記憶性的只有指數分佈（離散型對應的是幾何分佈），這是可證明的定理，不是經驗法則。指數分佈是右偏的，且 E(X) = SD(X) = 1/λ（變異係數恆為 1），常被拿來與對稱的常態分佈對比。

29.5

中央極限定理與大數法則

這兩條是敘述陷阱最密集的地方，官方誘答經常偷換主詞。

大數法則 LLN
樣本平均數 X̄ 會收斂到哪個值：n → ∞ 時 X̄ → μ
對原始分佈幾乎不限（需期望值存在）｜「樣本夠多，估計就會準」
中央極限定理 CLT
樣本平均數 X̄ 以什麼形狀圍繞那個值波動：n 夠大時 X̄ ~ 近似 N(μ, σ²/n)
需 i.i.d. 且變異數有限｜「可以用常態的尺做信賴區間與檢定」

  • 標準誤 SE = σ / √n：n 變大 → x̄ 的分佈變窄，但母體標準差 σ 完全沒變。要把 SE 減半，n 要變成 4 倍（分母是 √n），不是 2 倍。

分佈擬合與資料建模
