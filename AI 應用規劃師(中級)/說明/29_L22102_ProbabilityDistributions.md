## 29.1 機率分佈的三個函數：PMF、PDF、CDF

機率分佈（Probability Distribution）是把「隨機變數的所有可能值」對應到「它們的機率」的數學函數。中級考題不會叫你算積分，但會**用定義設誘答**。

| 函數 | 全名 | 適用 | 回答的問題 | 關鍵性質 |
|------|------|------|------------|----------|
| **PMF** | Probability Mass Function（機率質量函數） | 離散型 | 「**恰好**等於某個值」的機率 `P(X = k)` | 所有可能值的機率總和 = 1 |
| **PDF** | Probability Density Function（機率密度函數） | 連續型 | 某**區間**的機率 `P(a ≤ X ≤ b) = ∫f(x)dx` | 曲線下總面積 = 1；`f(x)` 本身**不是**機率 |
| **CDF** | Cumulative Distribution Function（累積分佈函數） | 兩者皆可 | 「**小於或等於**某個值」的機率 `F(x) = P(X ≤ x)` | 單調不減，由 0 遞增到 1 |

### 三個最常被考的細節

```
① CDF 怎麼來的？
   連續型：CDF 是 PDF 從 −∞ 到 x 的「積分」
   離散型：CDF 是 PMF 由小到大的「累加」
   → 官方 114Q2-4 的正解正是「PDF 的積分」；
     誘答把它寫成 PDF 的平均值／標準差／離散總和。

② PDF 的函數值可以大於 1
   例：均勻分佈 U(0, 0.5) 的 f(x) = 1 / (0.5 − 0) = 2
   密度不是機率，只有「密度 × 區間寬度」（面積）才是機率。

③ 連續型的單點機率為 0
   P(X = 5.3) = 0，因為單點的積分區間寬度為 0。
   所以連續型才會用「區間」提問，而離散型可以問「恰好 k 個」。
```

## 29.2 期望值與變異數對照表（必背）

期望值（Expected Value, `E(X)`）是隨機變數的加權平均，代表長期的中心位置；變異數（Variance, `Var(X)`）衡量取值的分散程度，標準差（Standard Deviation）是它的平方根，單位與原始資料相同。

| 分佈 | 參數 | `E(X)` | `Var(X)` | 型態 | 一句話記法 |
|------|------|--------|----------|------|------------|
| **伯努利** Bernoulli | `p` | `p` | `p(1−p)` | 離散 | 單次成敗，`p = 0.5` 時變異數最大（0.25） |
| **二項** Binomial | `n, p` | `np` | `np(1−p)` | 離散 | 伯努利做 `n` 次；`n = 1` 就退回伯努利 |
| **卜瓦松** Poisson | `λ` | `λ` | `λ` | 離散 | **平均等於變異數**，這是它的指紋 |
| **常態** Normal | `μ, σ` | `μ` | `σ²` | 連續 | 參數本身就是答案 |
| **指數** Exponential | `λ` | `1/λ` | `1/λ²` | 連續 | 平均等待時間 = 發生率的倒數 |
| **均勻** Uniform `U(a,b)` | `a, b` | `(a+b)/2` | `(b−a)²/12` | 連續 | 中點；分母 12 是固定的 |
| **卡方** Chi-square | `k`（自由度） | `k` | `2k` | 連續 | 自由度就是期望值，變異數加倍 |

> **均勻分佈不在官方學習指引的條列中**，但它在 114Q2-15 是誘答選項，公式仍建議記住。
>
> **離散度的三檔對照（115Q1-3 的核心）**：二項 `Var = np(1−p) < np = E`（欠離散）；卜瓦松 `Var = λ = E`（等離散）；實際資料若 `Var > E`（過度離散，Overdispersion），卜瓦松就配不上，要換**負二項分佈（Negative Binomial）**。

## 29.3 離散型分佈：伯努利、二項、卜瓦松

### 三者的關係與切換條件

```
伯努利（n = 1）
   │ 重複 n 次獨立試驗、p 固定
   ▼
二項 B(n, p)     P(X=k) = C(n,k) · p^k · (1−p)^(n−k)
   │ n → 很大、p → 很小、np = λ 保持固定
   ▼
卜瓦松 Poisson(λ)   P(X=k) = λ^k · e^(−λ) / k!
   │ 實際資料 Var > Mean（過度離散）
   ▼
負二項 Negative Binomial（多一個離散參數）
```

### 情境關鍵字對照

| 題幹出現 | 指向 | 為什麼不是另一個 |
|----------|------|------------------|
| 「**固定** n 件產品中有幾件合格」「投放 n 則廣告的點擊次數」 | 二項 | 有明確的試驗總次數 `n` |
| 「**每小時／每分鐘**接到幾通電話」「每小時幾個瑕疵品」 | 卜瓦松 | 沒有 `n`，只有單位時間的平均發生率 `λ` |
| 「兩次來電**相隔多久**」「零件撐到故障的時間」 | 指數（連續型） | 問的是**等待時間**，不是次數 |
| 「單一產品合格與否（1/0）」「使用者有沒有點廣告」 | 伯努利 | 只做一次 |

> **卜瓦松與指數是同一枚硬幣的兩面**：若單位時間發生次數服從 `Poisson(λ)`，則相鄰兩次事件的間隔時間服從 `Exponential(λ)`。同一個 `λ`，一個數「幾次」（離散），一個量「多久」（連續）。114Q2-15 就是用指數分佈當誘答來測這件事。

### 成立前提（考「何者不適用」時的答案來源）

| 分佈 | 前提 | 前提被破壞的典型敘述 |
|------|------|----------------------|
| 二項 | 試驗**獨立**、成功機率 `p` **固定**、次數 `n` 固定 | 「促銷活動中途改變了轉換率」→ `p` 不固定，二項失效 |
| 卜瓦松 | 事件**獨立**、平均發生率 `λ` **固定**、發生機率與區間長度成正比 | 「尖峰時段來電暴增」→ `λ` 隨時間變動，需改用非齊次模型 |
| 指數 | 發生率 `λ` **固定**（無記憶性） | 「零件有明顯老化、故障率隨使用時間上升」→ 改用 **Weibull 分佈** |

### scipy 的寫法（官方 114Q2-42 直接考）

```python
from scipy.stats import poisson

lam = 5                      # λ = 平均每小時 5 個瑕疵品（是「平均」，不是「上限」）

poisson.pmf(5, lam)          # P(X = 5)  ← 恰好 5 個，不是「少於 5 個」
poisson.cdf(10, lam)         # P(X ≤ 10) ← 小於或等於 10 個，不是「大於等於 10 個」
1 - poisson.cdf(10, lam)     # P(X ≥ 11) ← 要算右尾得自己補這一步
```

## 29.4 連續型分佈：常態、指數、卡方

### 常態分佈 `N(μ, σ²)`

- PDF 對稱鐘形，由 **`μ` 決定中心位置、`σ` 決定胖瘦**；`E(X) = μ`、`Var(X) = σ²`。
- 標準化：`Z = (X − μ) / σ`，轉換後得到標準常態 `N(0, 1)`。**Z 分數表示「偏離平均幾個標準差」**，正值在平均之上、負值在平均之下。
- 經驗法則：`|Z| ≤ 1` 約涵蓋 68%、`|Z| ≤ 2` 約 95%、`|Z| ≤ 3` 約 99.7%。所以 `|Z| ≥ 2` 約落在雙尾 5%，罕見但**仍在常態分佈可解釋的範圍內**。
- 侷限：資料明顯偏態（Skewed）或厚尾（Heavy-tailed）時不該硬套常態。應對方式是**換轉換或換方法**——對數轉換、Box–Cox 轉換、對數常態分佈、t 分佈、分位數迴歸（Quantile Regression）——而不是把極端值裁掉。

### 指數分佈與無記憶性

無記憶性（Memoryless）：`P(X > s + t | X > s) = P(X > t)`。已經等了 10 分鐘，「再等 5 分鐘」的機率和一開始「等 5 分鐘」完全相同。**連續型分佈中具備無記憶性的只有指數分佈**（離散型對應的是幾何分佈），這是可證明的定理，不是經驗法則。

指數分佈是右偏的，且 `E(X) = SD(X) = 1/λ`（變異係數恆為 1），這一點常被拿來與對稱的常態分佈對比。

### 卡方分佈 `χ²(k)`

- 定義：`k` 個獨立標準常態隨機變數的**平方和**。
- `E(X) = k`、`Var(X) = 2k`；取值只在 `x ≥ 0`。
- **右偏**分佈；自由度 `k` 越小偏態越明顯，`k` 增大才逐漸趨近常態。
- 自由度（Degrees of Freedom, df）＝計算統計量時可自由變動的資料點數量。算樣本標準差時因為用掉了樣本平均數這個已知量，自由度少 1（`n − 1`）。
- 用途：適配度檢定（Goodness of Fit）、列聯表獨立性檢定、齊一性檢定——這些細節屬於 L22103，本節只需記住「卡方是常態平方和、右偏、`E = k`、`Var = 2k`」。

## 29.5 中央極限定理與大數法則

這兩條是**敘述陷阱最密集**的地方，官方誘答經常偷換主詞。

### 兩者在講不同的事

| | 大數法則（Law of Large Numbers, LLN） | 中央極限定理（Central Limit Theorem, CLT） |
|---|---|---|
| 講什麼 | 樣本平均數 `X̄` **會收斂到哪個值** | 樣本平均數 `X̄` **以什麼形狀圍繞那個值波動** |
| 結論 | `n → ∞` 時 `X̄ → μ`（母體平均） | `n` 夠大時 `X̄ ~ 近似 N(μ, σ²/n)` |
| 對原始資料的分佈要求 | 幾乎不限（需期望值存在） | 獨立同分佈（i.i.d.）且**變異數有限** |
| 回答的實務問題 | 「樣本夠多，估計就會準」 | 「我可以用常態的尺去做信賴區間與檢定」 |

### CLT 的主詞是「樣本平均數的抽樣分佈」

```
母體（右偏，例如收入資料）
   │
   │  每次抽 n 筆，算一個平均數 x̄
   │  重複很多次，蒐集這些 x̄
   ▼
x̄ 的分佈（抽樣分佈）→ 趨近常態 N(μ, σ²/n)

★ 趨近常態的是「上面這堆 x̄」，不是母體本身。
★ 收入資料抽 10,000 筆畫直方圖，它仍然是右偏的。
```

- **標準誤（Standard Error, SE）= `σ / √n`**：`n` 變大 → `x̄` 的分佈變窄，但**母體標準差 `σ` 完全沒變**。要把 SE 減半，`n` 要變成 **4 倍**（因為分母是 `√n`），不是 2 倍。
- CLT 需要變異數有限。**柯西分佈（Cauchy Distribution）的變異數不存在**，其樣本平均數再怎麼加大 `n` 也不會趨近常態（仍是柯西）——這就是「無論什麼分佈都適用」這種絕對說法的反例。
- **大數法則不是賭徒謬誤**。LLN 靠的是「後續大量樣本把前期偏差稀釋掉」，而不是「輸太多之後會反向補回來」；每一次獨立試驗的機率並不會因為前面的結果而改變。

### 二項分佈的常態近似（114Q2-31）

| 判準 | 內容 |
|------|------|
| 條件 | `np > 5` **且** `n(1−p) > 5`（部分教科書用 10，官方採 5） |
| 近似後 | `B(n, p) ≈ N(np, np(1−p))` |
| 為什麼不能只看 `n` 大 | `p` 極端時分佈嚴重偏斜。例：`n = 1000`、`p = 0.001` → `np = 1 < 5`，即使 `n` 很大也不該用常態近似（此時該用卜瓦松近似） |
| 為什麼不限 `p = 0.5` | `p` 偏離 0.5 只是需要更大的 `n` 來補償，不是不能近似 |

## 29.6 分佈擬合與資料建模

分佈擬合（Distribution Fitting）是**替資料找一個合適的理論分佈**；資料建模則是**把擬合好的分佈拿去做預測、風險評估與決策**。兩者是前後段關係，不是同義詞。

### 標準流程

```
Step 1  確認資料型態
        計數型（每日故障次數）→ 離散型候選
        測量型（病患等待時間）→ 連續型候選

Step 2  視覺檢查
        直方圖看形狀、盒鬚圖看離群值、Q–Q 圖看是否貼合常態

Step 3  挑候選分佈
        對稱鐘形 → 常態
        右偏、恆正（收入、金額）→ 對數常態
        厚尾、極端事件多 → t 分佈／重尾分佈
        稀少獨立事件的次數 → 卜瓦松
        等待時間 → 指數（故障率會變則改 Weibull）

Step 4  估計參數
        最大概似估計（Maximum Likelihood Estimation, MLE）

Step 5  驗證假設
        獨立性 → 自相關（Autocorrelation）分析
        發生率／成功率是否固定 → 分時段比較
        配適程度 → 卡方適配度檢定
```

### 常見的假設破口

| 情境敘述 | 被破壞的假設 | 該怎麼做 |
|----------|--------------|----------|
| 促銷檔期改變了顧客的購買成功率 | 二項的「`p` 固定」 | 改用可隨時間變動的動態模型 |
| 每小時客服來電數的變異數遠大於平均數 | 卜瓦松的 `Var = E` | 改用負二項分佈 |
| 報酬率非對稱且極端損失頻繁 | 常態的對稱與薄尾 | 分位數迴歸聚焦尾部；**不要**裁掉 ±3σ 以外資料 |
| `Y` 右偏且變異數隨 `X` 增大 | 線性迴歸的常態殘差與等變異 | 對 `Y` 做 Box–Cox 轉換 |
| 零件故障率隨使用時間上升 | 指數的固定 `λ` | 改用 Weibull 分佈 |

### 核心 5 題

| 題號 | 怎麼問 | 正解思路 |
|------|--------|----------|
| 114Q2-4 | CDF 的數學定義為何 | **PDF 的積分**。誘答：PDF 的平均值／標準差／離散總和（離散總和只適用離散型 PMF 累加，非通用定義） |
| 114Q2-15 | 客服中心「每分鐘接到幾通來電」，事件獨立、機率與時間長短成正比 | **卜瓦松**。均勻＝各值等機率不符；**指數是「間隔時間」不是「次數」**；常態是連續對稱，不配計數資料 |
| 114Q2-31 | `p = 0.4`、`n = 5,000`，能否以常態近似二項 | **只有當 `np` 與 `n(1−p)` 皆大於 5 才可近似**。誘答分別是「樣本大就直接近似」（過於武斷）、「只適用 `p = 0.5`」、「永遠不能近似」（違反 CLT） |
| 114Q2-42 | 生產線瑕疵品服從卜瓦松，`λ = 5`，下列敘述何者正確 | **適用條件是事件獨立且平均發生率固定**。誘答三支：`λ` 是上限（錯，是平均）、`pmf(5)` 是「小於 5」（錯，是恰好 5）、`cdf(10)` 是「大於等於 10」（錯，是小於等於 10） |
| 115Q1-3 | 每小時客服來電數該用什麼分佈？變異數明顯大於平均數怎麼辦 | **卜瓦松 → 過度離散時改用負二項**。誘答：改用 t 分佈（t 是小樣本推論，與離散度無關）、「增加樣本數即可修正」（只讓估計更準，不改變資料的離散結構） |

### 外圍 4 題（常態只是前提）

| 題號 | 常態在題目裡的角色 | 真正的考點 |
|------|--------------------|------------|
| 114Q2-33 | 報酬率「非對稱＋極端損失」使常態假設失效 | 分位數迴歸（Quantile Regression）；`±3σ` 裁切反而刪掉要評估的風險 |
| 115Q1-4 | 三組資料「近似常態、變異數相近」 | 單因子變異數分析（One-Way ANOVA），屬 L22103 |
| 115Q1-5 | 特徵「近似常態」，`Z = −2` | Z 分數方向判讀（低於平均 2 個標準差）與資料漂移（Data Drift）告警 |
| 115Q1-7 | 前後測資料「近似常態」 | 成對樣本 t 檢定（Paired t-test），屬 L22103 |

> **命題傾向**：兩次考試都出現卜瓦松（114Q2 兩題、115Q1 一題），且都用「事件獨立＋發生率固定＋計數型」這組關鍵字來鋪陳。分佈選型題是本節 CP 值最高的複習標的。

## 29.8 易錯與陷阱

- [ ] CDF 是 **PDF 的積分**（離散型則是 PMF 的累加），**不是** PDF 的平均值、標準差，也不是通用意義下的「離散總和」。
- [ ] PDF 的函數值是**機率密度**，**不是**機率；它可以大於 1（`U(0, 0.5)` 的 `f(x) = 2`），只有積分出來的面積才是機率。
- [ ] 連續型分佈的單點機率是 **0**，**不是**「很小的某個正值」；所以連續型用區間提問，離散型才問「恰好 k 個」。
- [ ] 卜瓦松算的是**單位時間內發生「幾次」**（離散），**不是**「間隔多久」；問間隔時間的是指數分佈，兩者共用同一個 `λ`。
- [ ] `λ` 是**平均發生率**，**不是**發生次數的上限；`λ = 5` 不代表每小時最多 5 個瑕疵品。
- [ ] `poisson.pmf(5, 5)` 是「**恰好** 5 個」的機率，**不是**「少於 5 個」；`poisson.cdf(10, 5)` 是「**小於或等於** 10 個」，**不是**「大於或等於 10 個」。
- [ ] 卜瓦松的 `Var = E = λ`（等離散），**不是**「變異數永遠比平均小」；二項才是 `Var = np(1−p) < np = E`（欠離散）。
- [ ] 實際資料 `Var > E` 時要**換成負二項分佈**，**不是**「多蒐集一點樣本就會修正」——增加樣本只讓參數估計更準，不改變資料本身的離散結構。
- [ ] 二項可用常態近似的判準是 **`np > 5` 且 `n(1−p) > 5`**，**不是**「只要 `n` 夠大就行」；`n = 1000`、`p = 0.001` 時 `np = 1`，仍不該用常態近似。
- [ ] 常態近似**不限於 `p = 0.5`**，`p` 偏離 0.5 時只需更大的 `n`；「無論多大樣本都不能近似」則違反中央極限定理。
- [ ] 中央極限定理說的是**樣本平均數（或總和）的抽樣分佈**趨近常態，**不是**原始資料的分佈會變成常態；右偏的收入資料抽 10,000 筆，直方圖依然右偏。
- [ ] 增加 `n` 縮小的是**標準誤 `σ/√n`**，**不是**母體標準差 `σ`；要讓標準誤減半，樣本數要變 **4 倍**而非 2 倍。
- [ ] 中央極限定理要求**變異數有限**，**不是**「對任何分佈都成立」；柯西分佈變異數不存在，其樣本平均數不會趨近常態。
- [ ] 大數法則講的是 `X̄` **收斂到 `μ`**，**不是**「連輸之後下一把比較容易贏」；它靠後續樣本稀釋前期偏差，不靠反向修正（賭徒謬誤）。
- [ ] 指數分佈的無記憶性是指「**已等 10 分鐘後再等 5 分鐘**的機率，等於一開始等 5 分鐘的機率」，**不是**「等越久越快發生」；連續型分佈中具此性質的只有指數分佈。
- [ ] 卡方分佈是**右偏**且只取非負值，**不是**對稱分佈；`E(X) = k`、`Var(X) = 2k`，要自由度夠大才逐漸趨近常態。
- [ ] Z 分數表示**偏離平均幾個標準差**，**不是**「是不是異常值」的判定；`|Z| = 2` 算不算異常取決於你設的門檻（常用 3）。
- [ ] Z 分數標準化把資料轉成平均 0、標準差 1，**不會**把偏態資料變成常態；要改善偏態與異質變異請用對數或 Box–Cox 轉換。
- [ ] 資料厚尾時要**換分佈假設或換方法**（對數常態、t 分佈、分位數迴歸），**不是**把 `±3σ` 以外的點裁掉——那正好刪掉要評估的極端風險。
- [ ] 伯努利是 **`n = 1` 的二項特例**，**不是**二項的別名；二項有固定的試驗次數 `n`，卜瓦松沒有 `n`、只有 `λ`。
- [ ] 分佈擬合是**替資料找分佈並估參數**，資料建模是**把擬合結果拿去預測與決策**，**不是**同一件事的兩種說法。

## 延伸練習

- **L22 主題庫（290 題）**：集中刷「機率分佈與資料分佈模型」相關題目。優先練三類——① 給情境選分佈（看關鍵字是「次數」還是「等待時間」、有沒有固定的 `n`）；② 給分佈問期望值／變異數（把 29.2 的表當標準答案自測）；③ 中央極限定理與大數法則的敘述辨析（每個選項都先確認主詞是「原始資料」還是「樣本平均數」）。
- **L22 歷屆 100 題**：把 29.7 列出的 9 題先做一遍，特別留意 114Q2-42 那種「四個敘述選一個正確」的題型——它一次測四個細節（`λ` 的意義、`pmf` 的語意、`cdf` 的方向、適用前提），是本節的濃縮題。
- **跨知識點對照**：本節與 L22101（敘述性統計）共用變異數、標準差、偏態、Z 分數的語彙，但 L22101 描述的是**手上的樣本**、本節描述的是**背後的理論分佈**；與 L22103（假設檢定）則共用常態、卡方、t 這幾個分佈，差別在本節只問「分佈長什麼樣」，L22103 才問「拿它做推論該怎麼判斷」。做題時先判斷題目在問哪一層，選項通常會同時擺上兩層的用語當誘答。
