## 43.1 向量與矩陣表示

### 資料在機器學習裡的四種身分

| 物件 | 數學符號 | NumPy 形狀 | 在模型中的角色 |
|---|---|---|---|
| 樣本向量（Vector） | x ∈ ℝ^d | `(d,)` | 單筆資料的特徵組合 |
| 特徵矩陣（Matrix） | X ∈ ℝ^(n×d) | `(n, d)` | n 筆樣本，**每一列一筆樣本** |
| 參數向量 | θ ∈ ℝ^d | `(d,)` | 線性模型的權重 |
| 權重矩陣 | W ∈ ℝ^(d×k) | `(d, k)` | 把 d 維輸入映射成 k 維輸出 |

線性迴歸的預測寫成 **ŷ = Xθ**；神經網路每一層的前向傳播寫成 **z⁽ˡ⁾ = W⁽ˡ⁾a⁽ˡ⁻¹⁾ + b⁽ˡ⁾**。
兩者本質相同：都是「矩陣乘向量」再加偏差，差別只在後面有沒有接非線性激活函數。

### 三種「乘法」必須分清楚

| 運算 | 寫法 | 形狀變化 | 幾何／實務意義 |
|---|---|---|---|
| **內積（Dot Product）** | `np.dot(v1, v2)`、`v1 @ v2` | `(d,)·(d,)` → **純量** | 投影、相似度，線性模型預測的核心 |
| **逐元素相乘（Hadamard）** | `v1 * v2`、`np.multiply` | `(d,)*(d,)` → `(d,)` | 遮罩、加權、閘門（如 LSTM 的 gate） |
| **矩陣乘法** | `A @ B`、`np.matmul`、`np.dot` | `(m,n)·(n,p)` → `(m,p)` | 批次預測、特徵空間轉換 |
| **外積（Outer Product）** | `np.outer(v1, v2)` | `(d,)·(e,)` → `(d,e)` | 梯度外積、秩一更新 |

> **`np.dot` 的雙重人格**：輸入兩個一維陣列時做內積回傳純量；輸入兩個二維陣列時等同矩陣乘法。
> 二維以上（張量批次）時 `np.matmul`／`@` 是逐批相乘，`np.dot` 則是另一種和乘規則，兩者會不同——
> 實務上**一律用 `@`**，只有考試題目愛寫 `np.dot`。

### NumPy 函式對照表（考試固定班底）

| 寫法 | 做什麼 | 輸入限制 | 回傳型別／形狀 |
|---|---|---|---|
| `np.dot(v1, v2)` | **內積** | 兩個一維向量 | **純量**（如 `np.int64(32)`） |
| `v1 * v2` | **逐元素相乘** | 形狀相同或可廣播 | 與輸入**同形狀的陣列** |
| `np.linalg.inv(A)` | **反矩陣** | **方陣**且 det ≠ 0 | 與 A 同形狀的方陣 |
| `np.linalg.det(A)` | **行列式** | **方陣** | **純量**（float） |
| `np.linalg.eig(A)` | **特徵值分解** | **方陣** | **(特徵值一維陣列, 特徵向量二維陣列)** 兩個東西 |
| `np.linalg.norm(v)` | L2 範數（長度） | 任意 | 純量 |
| `np.linalg.pinv(A)` | 偽逆（Pseudo-Inverse） | 任意形狀 | 轉置形狀的矩陣 |
| `A.T` | 轉置（Transpose） | 任意 | 行列互換 |

**三個 `np.linalg` 函式的張冠李戴是最常見的誘答設計**：把 `inv` 說成算行列式、把 `eig` 說成算反矩陣、
把 `det` 說成回傳矩陣。記憶法：**inv→矩陣、det→數字、eig→一組數字＋一組方向**。

### 判讀範例

```python
import numpy as np

v1 = np.array([1, 2, 3])
v2 = np.array([4, 5, 6])
A  = np.array([[4, 1],
               [2, 3]])

# ① 內積 → 純量
np.dot(v1, v2)      # 1*4 + 2*5 + 3*6 = 32   →  np.int64(32)

# ② 逐元素 → 同形狀陣列（常見誘答寫成 [5, 7, 9]，那是「相加」不是「相乘」）
v1 * v2             # array([ 4, 10, 18])

# ③ 反矩陣 → 方陣（det = 4*3 - 1*2 = 10 ≠ 0，可逆）
np.linalg.inv(A)    # array([[ 0.3, -0.1],
                    #        [-0.2,  0.4]])

# ④ 行列式 → 純量，而且是 float 不是 int
np.linalg.det(A)    # 10.0

# ⑤ 特徵值分解 → 回傳「兩個」物件
w, v = np.linalg.eig(A)
# w = array([5., 2.])           ← 特徵值，順序由 LAPACK 決定，不保證由大到小
# v = 特徵向量，**按「行（column）」存放**，v[:, 0] 才是對應 w[0] 的那一支
#     每支已正規化成單位長度，正負號不唯一
```

三個延伸提醒：

- **向量沒有反矩陣**。`np.linalg.inv` 丟一維陣列進去會直接報 `LinAlgError`，任何說「對向量求反矩陣」的選項必錯。
- **對稱矩陣（如共變異數矩陣）建議用 `np.linalg.eigh`**，保證特徵值為實數且由小到大排序；`eig` 對非對稱矩陣可能回傳複數。
- **判斷矩陣是否奇異不要用 `det(A) == 0`**，浮點誤差會讓它幾乎永遠不等於 0，實務上看條件數或用 `np.linalg.matrix_rank`。

### 矩陣形狀相容性（必考的算式）

```
   (m, n)  @  (n, p)   →   (m, p)
      └───────┘   內側維度必須相等，運算後被「吃掉」
   └──┘       └──┘   外側維度留下來，就是輸出形狀
```

**判讀範例**：Transformer 的 Q 攤平成 `(1, 10)`，Query 投影權重 W_Q 為 `(10, 64)`。
內側都是 10 → 可以相乘 → 輸出 **`(1, 64)`**。

三種標準誘答：`(10, 10)` 是誤把兩個矩陣的第一維相配；`(64, 1)` 是正解的轉置（只有算 W_Qᵀ Qᵀ 才會出現）；
「維度不相容」則是沒看內側維度。

### L2 範數與相似度

- **L2 範數**：‖x‖₂ = √(Σxᵢ²)，`np.linalg.norm(x)`——向量的「長度」，也是歐氏距離與 L2 正則化的基礎。
- **餘弦相似度**：cos(a, b) = (a·b) / (‖a‖·‖b‖)——內積除掉兩邊長度，**只看方向不看大小**，這是向量資料庫語意檢索的預設度量。
- 對照：**內積會被向量長度影響，餘弦不會**。題幹若強調「不受文件長度／熱門度影響」，指向餘弦相似度。

## 43.2 線性變換與特徵空間

### 一次矩陣乘法＝一次幾何操作

向量 x 被矩陣 A 左乘得到 Ax，就是對 x 做一次線性變換。四種基本型態：

| 操作 | 矩陣特徵 | 對長度／方向的影響 | 機器學習中的對應 |
|---|---|---|---|
| **縮放（Scaling）** | 對角矩陣 | 改變尺度，**不改方向** | 特徵標準化、學習率縮放 |
| **旋轉（Rotation）** | 正交矩陣（QᵀQ = I） | 改變方向，**不改長度** | PCA 換基底、特徵對齊 |
| **剪切（Shearing）** | 非對角元素不為零 | 方向傾斜、角度改變 | 一般全連接層的權重 |
| **投影（Projection）** | rank(A) < d | **降維，且不可逆** | PCA、LDA、分類超平面 |

只有**投影**會損失資訊——這正是降維的本質：壓扁之後回不去，所以要挑「壓扁後損失最少」的方向。

### 特徵值與特徵向量的白話定義

> **Av = λv**：向量 v 經過變換 A 之後**方向不變**，只被拉長（或壓縮）λ 倍。

- **特徵向量（Eigenvector）** = 這個變換的「軸」，是變換下不會被轉歪的方向。
- **特徵值（Eigenvalue）** = 那個軸上的縮放倍率，量化該方向的「重要性／變異量」。
- λ = 0 代表某個方向被完全壓扁 → 矩陣不可逆。
- **實對稱矩陣**（共變異數矩陣就是）保證特徵值為實數、特徵向量互相正交——**這是 PCA 能得到一組彼此垂直的主成分的數學保證**。

### det、rank 與可逆性是同一件事

```
det(A) = 0  ⇔  rank(A) < n  ⇔  A 不可逆（奇異矩陣 Singular）
    │
    ├─ 幾何解讀：det 是變換後的「體積縮放倍率」，等於 0 表示空間被壓扁到更低維
    │
    └─ 資料解讀：某一欄特徵是其他欄的線性組合（完全共線）→ XᵀX 不可逆 → OLS 無解
```

### 線性變換在模型裡的出現位置

- **線性／邏輯迴歸**：y = wᵀx + b，把 d 維特徵投影到一條直線上。
- **神經網路前向傳播**：z⁽ˡ⁾ = W⁽ˡ⁾a⁽ˡ⁻¹⁾ + b⁽ˡ⁾，每一層先做線性變換再套非線性激活。
- **嵌入層（Embedding Layer）**：把離散類別索引查表成稠密向量，本質是一組特定矩陣的查詢與轉換；用來避免 One-Hot 的維度爆炸。
- **特徵投影與壓縮**：LDA（線性判別分析）、Autoencoder 的編碼器，都是把高維重構為低維潛在空間。

## 43.3 矩陣分解與維度簡化

### 三種分解對照表

| | **特徵值分解（EVD）** | **奇異值分解（SVD）** | **非負矩陣分解（NMF）** |
|---|---|---|---|
| 形式 | A = QΛQᵀ | X = UΣVᵀ | X ≈ WH |
| 適用矩陣 | **必須是方陣**（實務上用對稱方陣） | **任意 m×n 實數矩陣** | 元素**全非負**的矩陣 |
| 成分意義 | 特徵向量＝軸，特徵值＝該軸變異量 | U＝樣本方向，Σ＝重要性，V＝特徵方向 | W＝潛在基底，H＝組合係數 |
| 結果性質 | 正交基底 | 正交基底、數值穩定性最佳 | 非負、稀疏、**可加疊** |
| 典型應用 | **PCA**、LDA | PCA 的實作、推薦系統、LSA、影像壓縮 | 主題建模、腦波拆解、影像部件分析 |

記憶點：**EVD 挑食（只吃方陣），SVD 來者不拒（任意矩陣），NMF 只吃非負但換來可解釋性**。

### PCA 與共變異數矩陣特徵分解的關係（本節核心）

```
原始資料 X (n×d)
   │  ① 中心化：每一欄減去該特徵的平均值（必做）
   │     各特徵單位不同時，再除以標準差 → 標準化
   ▼
中心化資料 Xc
   │  ② 建共變異數矩陣  C = (1/(n−1)) · Xcᵀ Xc        → d×d 對稱半正定方陣
   ▼
   C
   │  ③ 特徵值分解  C = Q Λ Qᵀ
   ▼
特徵向量 q1 … qd（互相正交）＋ 特徵值 λ1 ≥ λ2 ≥ … ≥ λd
   │  ④ 依 λ 由大到小排序，取前 k 支組成投影矩陣 W (d×k)
   ▼
   ⑤ 投影：Z = Xc · W   →  降維後的資料 (n×k)
```

**一一對應關係**：

| 線性代數物件 | 在 PCA 裡的身分 |
|---|---|
| C 的特徵向量 qᵢ | **第 i 主成分的方向**（載荷 loading） |
| C 的特徵值 λᵢ | 資料在該主成分方向上的**變異量** |
| λᵢ / Σλ | **第 i 主成分的解釋變異比例** |
| Λ 是對角矩陣 | 主成分之間**共變異數為 0**（彼此不相關） |
| Q 是正交矩陣 | 主成分**互相垂直** |

**解釋變異的計算範例**：某製程資料標準化後做共變異數矩陣分解，得 λ₁=6.0、λ₂=3.0、λ₃=1.0。

```
總變異量 = 6 + 3 + 1 = 10
PC1        = 6/10 = 60%
PC1 + PC2  = 9/10 = 90%   ← 已超過 80% 門檻，可安全降到二維
PC3        = 1/10 = 10%   ← 可捨棄
```

三個標準誘答：①「只留 PC1」——只有 60%，不足門檻；②「PC2 貢獻高達 30% 所以不能丟 PC3」——
把**單一成分的貢獻**跟**累積門檻**混為一談，前兩者累積已達 90%；③「特徵值相差不大」——6:3:1 落差明顯，敘述與數據不符。

### SVD 才是實作上的主流

對中心化後的 Xc 直接做 SVD：**Xc = UΣVᵀ**，則

- **V 的各行就是 C 的特徵向量**（＝主成分方向）
- **λᵢ = σᵢ² / (n−1)**（奇異值平方除以自由度）

所以 SVD 與共變異數矩陣特徵分解得到的主成分**完全相同**。scikit-learn 的 `PCA` 內部走 SVD，
因為不必顯式建出 d×d 共變異數矩陣，**數值更穩定、特徵數很大時也省記憶體**。

### 為什麼 PCA 前必須先標準化

共變異數對**尺度**極度敏感。年收入以「元」為單位、年資以「年」為單位時，年收入的變異數可能大上千萬倍，
PC1 幾乎就等於年收入本身，其他特徵完全被稀釋。標準化之後的共變異數矩陣，其實就是**相關係數矩陣**。

同理，**異質的多模態特徵不可直接 concat 後做 PCA**，高維模態的變異會主導所有主成分。

### PCA 降噪的原理與常見錯誤

訊號的能量集中在少數大特徵值方向，雜訊則散布在眾多小特徵值方向。
**保留前 k 個主成分後重建（`inverse_transform`），小特徵值方向的雜訊就被濾掉了。**

> **降噪失效的典型 bug**：`n_components` 設得太大（例如等於原始維度），
> 重建結果＝原圖，雜訊原封不動。要修的永遠是**設定主成分數量那一行**，不是資料載入或繪圖那幾行。

### 降維方法選型對照

| 方法 | 線性？ | 用標籤？ | 能對新資料投影？ | 最適用途 |
|---|---|---|---|---|
| **PCA** | 線性 | 非監督 | **可**（存下 W 即可） | 前處理、當模型輸入特徵 |
| **LDA** | 線性 | **監督** | 可 | 分類前降維、最大化類別間差異 |
| **t-SNE** | 非線性 | 非監督 | **不可**（無固定轉換函數） | **只做視覺化** |
| **Autoencoder** | 非線性 | 非監督 | 可 | 表示學習、非線性壓縮 |
| **NMF** | 線性、非負 | 非監督 | 可 | 主題建模、可解釋的部件分解 |

兩個高頻陷阱：

- **t-SNE 保留的是局部鄰域結構，不保留全局距離與尺度**，也沒有可重複套用到新樣本的轉換，
  因此適合把 512 維詞嵌入投影到二維看群集，**不適合當 XGBoost 的輸入特徵**。反過來說 PCA 才是可外推的那一個。
- **降維器必須放進 Pipeline 裡**。先用**整份資料**做 `lda.fit_transform(X, y)` 再丟去交叉驗證，
  等於每一折的測試資料早就參與過降維擬合，是典型的**資料洩漏（Data Leakage）**，準確率會虛高。

### 維度簡化帶來的四個好處

| 面向 | 效果 |
|---|---|
| 訓練效率 | 參數量與運算量下降，大型資料集特別明顯 |
| 模型穩定 | 去除共線性與雜訊，降低過擬合風險 |
| 解釋性 | 轉換後的成分常具明確幾何或語意意義 |
| 視覺化 | 降到 2～3 維後可直接畫圖做群集判斷與異常偵測 |

## 43.4 最小平方估計與線性迴歸

### 從損失函數到正規方程

```
損失：  J(θ) = ‖y − Xθ‖₂²          （殘差平方和 RSS）
求導：  ∂J/∂θ = −2Xᵀ(y − Xθ) = 0
整理：  XᵀX θ = Xᵀy                 ← 正規方程（Normal Equation）
封閉解：θ̂ = (XᵀX)⁻¹ Xᵀ y
```

### 幾何觀點：迴歸就是正交投影

```
        y  ●
           │ ＼
           │   ＼  殘差 e = y − ŷ   （與 X 的行空間垂直）
           │     ＼
    ───────┴───────●─────────────  col(X)：X 各欄張成的平面
                   ŷ = Xθ̂          （y 在這個平面上的正交投影）
```

「殘差垂直於行空間」寫成數學就是 **Xᵀe = 0** → **Xᵀ(y − Xθ) = 0** → 正是正規方程。
所以**最小平方解＝把觀測值投影到特徵所能張成的空間上最近的那一點**。
投影矩陣 H = X(XᵀX)⁻¹Xᵀ（帽子矩陣），ŷ = Hy。

這也解釋了為什麼**離群點會扭曲擬合平面**：平方損失讓遠離的點取得極大的權重。

### XᵀX 不可逆時怎麼辦

| 情況 | 線性代數原因 | 對策 |
|---|---|---|
| 特徵數 > 樣本數 | rank(X) < d，XᵀX 必奇異 | 偽逆 `pinv`（取最小範數解）、降維、正則化 |
| **完全共線** | 某欄是他欄的線性組合 → det = 0 | 刪除重複特徵 |
| **近似共線** | det 接近 0，(XᵀX)⁻¹ 數值爆大 | **Ridge（L2）** |

**Ridge 的線性代數解釋**：θ̂ = (XᵀX + λI)⁻¹Xᵀy。
λI 把 XᵀX 的每個特徵值整體抬高 λ，**保證可逆且條件數下降**，
於是高度相關特徵的權重被**平均分攤並同步縮小**，估計穩定卻**不會歸零**。

對照 **Lasso（L1）**：絕對值懲罰不可微、沒有封閉解（用座標下降求解），且具稀疏化效果。
面對「月收入／年收入／季收入」這種高度相關的一組特徵，只要留一個就能把損失壓到相近水準，
**留哪一個會隨抽樣與初始化改變**，於是每次重訓的重要特徵清單就在三者間反覆跳動——這是解釋性上的大麻煩，不是梯度消失。

### 封閉解 vs 梯度下降

| | 正規方程（封閉解） | 梯度下降 |
|---|---|---|
| 計算複雜度 | O(nd² + d³)，含矩陣反轉 | 每次迭代 O(nd) |
| 特徵數 d 很大 | 很慢，甚至算不動 | 仍然可行 |
| 需要調超參數 | 不用 | 學習率、迭代次數 |
| 適用場景 | d 小（數百以內） | d 大、資料量大、線上學習 |

### OLS 的假設與殘差圖診斷

| 假設 | 違反時的正式名稱 | 怎麼看出來 |
|---|---|---|
| 誤差**變異數固定** | **異質變異數（Heteroscedasticity）** | 殘差圖隨預測值增大呈**喇叭狀擴散** |
| 誤差**彼此獨立** | 自相關（Autocorrelation） | 殘差依觀測順序呈週期或趨勢（多見於時間序列） |
| 誤差**常態分布** | 非常態 | **Q-Q 圖**、殘差直方圖 |
| 特徵**不共線** | 多重共線性（Multicollinearity） | **VIF、相關矩陣——殘差圖看不出來** |
| 關係**為線性** | 模型設定錯誤 | 殘差對預測值呈系統性彎曲 |

這張表就是殘差圖題型的全部答案：**擴散＝異質變異數、彎曲＝非線性、順序上有規律＝自相關、殘差圖看不到的＝共線性與常態性**。

### 最小平方之外的損失選擇

| 損失 | 懲罰型態 | 對離群值 | 什麼時候選它 |
|---|---|---|---|
| **MSE（最小平方）** | 平方 | **極敏感**，梯度與誤差成正比 | 題幹說「要對極端高值誤差**更敏感**」 |
| MAE | 線性 | 抗離群值，梯度近乎常數 | 題幹說「**不希望**被離群值主導」 |
| Huber | 小誤差平方、大誤差線性 | 折衷 | 想兼顧兩者 |
| 交叉熵 | 機率分布差異 | — | **分類**任務，連續值迴歸不適用 |

## 43.6 易錯與陷阱

- [ ] **`np.dot(v1, v2)` 回傳純量，`v1 * v2` 回傳陣列** —— 前者是內積（1×4+2×5+3×6=32），後者是逐元素（[4,10,18]）；誘答常寫成 [5,7,9]，那是相加不是相乘。
- [ ] **`np.linalg.inv` 算反矩陣，不是行列式** —— 行列式是 `det`，回傳一個 float 純量；反矩陣回傳同形狀方陣。
- [ ] **`np.linalg.eig` 算特徵值分解，不是反矩陣** —— 它回傳「特徵值陣列 + 特徵向量矩陣」**兩個**物件，且特徵向量是**逐行（column）存放**，第 i 個特徵值對應 `eigenvectors[:, i]` 而非 `eigenvectors[i]`，順序也不保證由大到小。
- [ ] **向量沒有反矩陣也沒有行列式** —— 這兩者只對方陣定義，選項若把它們套在一維向量上一定錯。
- [ ] **矩陣相乘看內側維度，輸出取外側** —— (m,n)@(n,p)=(m,p)；把第一維相配得到的 (m,m) 是最常見誘答。
- [ ] **λ 的比例是「累積」門檻，不是單一成分門檻** —— PC2 貢獻 30% 不構成保留 PC3 的理由，只要累積達標就可捨棄後面的。
- [ ] **PCA 做的是共變異數矩陣的特徵分解，不是原始矩陣的特徵分解** —— 要先中心化（通常再標準化），才建 C = XcᵀXc/(n−1)。
- [ ] **PCA 前不標準化，主成分會被「單位大」的特徵綁架** —— 標準化後的共變異數矩陣就是相關係數矩陣。
- [ ] **PCA 是線性降維，t-SNE 才是非線性** —— 說「PCA 能保留複雜流形結構」必錯。
- [ ] **t-SNE 不能外推到新資料，PCA 可以** —— 所以 t-SNE 只做視覺化，PCA 才能當模型輸入特徵。
- [ ] **SVD 適用任意矩陣，EVD 只適用方陣** —— 「用 EVD 分解 m×n 使用者-項目矩陣」是錯的，那是 SVD 的地盤。
- [ ] **NMF 的賣點是非負與可加疊的解釋性，不是數值精度** —— 主題建模、部件分解才是它的場域。
- [ ] **最小平方是投影，殘差垂直於特徵張成的空間** —— 這個垂直條件直接推出正規方程 Xᵀ(y−Xθ)=0。
- [ ] **XᵀX 不可逆的原因是共線或 d>n，不是資料太少沒洗乾淨** —— 對策是偽逆、降維或 Ridge。
- [ ] **Ridge 讓係數縮小但不歸零，Lasso 才會歸零** —— 要求「保留所有特徵的解釋能力」時只能選 Ridge。
- [ ] **殘差圖擴散＝異質變異數，不是共線性也不是非常態** —— 共線性看 VIF、常態性看 Q-Q 圖。
- [ ] **降維步驟必須進 Pipeline** —— 先對全資料 fit 再做交叉驗證，就是資料洩漏，估出來的準確率偏樂觀。
- [ ] **標準化（Z-score）把標準差調成 1，不是把資料壓到 0～1** —— 壓到 0～1 是 Min-Max 正規化；而且標準化屬於特徵縮放，不是特徵選擇。
