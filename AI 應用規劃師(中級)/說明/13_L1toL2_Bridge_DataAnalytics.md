# 13. 初級 → 中級銜接指南：數據分析路線 L21 + L22（40 分鐘）

> 適用對象：已通過 iPAS「AI 應用規劃師」初級，準備報考中級 **科目1（L21）＋ 科目2（L22）** 的考生。
> 通過這兩科取得的是「**AI 應用規劃師（數據分析）**」。
> 若你打算考科目3，請改看 [14. 銜接指南：機器學習路線](14_L1toL2_Bridge_MachineLearning.md)。

## 學習目標
- 判斷自己該走 L22 還是 L23，並看懂兩條路線的難度差在哪
- 釐清初級學過的東西在 L21 + L22 哪裡用得到、哪裡完全接不上
- 掌握中級的考科結構、抵免規則與授證條件
- 建立 L21 + L22 的讀書順序與時間配置，調整答題策略

## 13.1 先選路線：L22 還是 L23

中級的結構是**科目1 必考，科目2 或科目3 擇一**：

```
中級 AI 應用規劃師
├─ 科目1 人工智慧技術應用與規劃（L21）──── 必考
└─ 科目2 或 科目3 ──────────────────── 擇一報考
   ├─ 科目2 大數據處理分析與應用（L22）→ AI 應用規劃師（數據分析）
   └─ 科目3 機器學習技術與應用（L23）  → AI 應用規劃師（機器學習）

及格標準：每科 100 分，單科達 70 分為合格
授證資格：兩科皆達及格標準
```

用官方公告試題實測的差異來選（114-2 + 115-1 各 50 題，共 100 題）：

| 指標 | L22 大數據 | L23 機器學習 | 對你的意義 |
|---|---:|---:|---|
| 含程式語法的題目 | **21%** | 13% | L22 的程式題**比 L23 還多**，主要是 pandas 與 SQL |
| 附圖題 | 23% | 23% | 兩科相同，都要能讀圖表、程式碼截圖 |
| 題組題（多題共用敘述） | 18% | 18% | 兩科相同 |
| 題幹平均字數 | 114 | 106 | L22 情境敘述略長 |

> 這些數字可由 `scripts/exam_style_stats.py` 重跑驗證，指標定義寫在該檔開頭。

**一個常見誤解要先破除**：很多人以為 L22 就是考 Hadoop、Spark 那一套大數據工具。實測 100 題的關鍵詞命中率：

| 主題 | L11 | L12 | **L22** |
|---|---:|---:|---:|
| 敘述統計／機率分佈 | 6% | 0% | **24%** |
| 資料清理／資料品質 | 10% | 4% | **22%** |
| 機器學習原理 | 30% | 6% | 19% |
| 資料視覺化 | 3% | 5% | **13%** |
| 資料庫／儲存架構 | 3% | 12% | 11% |
| 假設檢定／統計推論 | 9% | 4% | 9% |
| 隱私／合規 | 10% | 12% | 5% |
| **分散式處理（Hadoop／Spark／Kafka）** | 2% | 2% | **4%** |
| 大數據 5V 特徵 | 1% | 0% | 1% |

> 由 `scripts/topic_hit_stats.py l22` 重跑驗證。這張表與下方 13.2「證據三」那張**用的是兩套不同的關鍵詞**，數字不可互相比較。

**分散式運算工具只佔 4%，敘述統計卻佔 24%、資料清理 22%。** L22 的真面目是「**統計 + 資料工程 + pandas**」，不是「大數據平台介紹」。把時間押在背 Hadoop 生態系名詞上，會押錯。

### 該選哪一科

| 你的背景 | 建議 |
|---|---|
| 熟 SQL、做過報表與資料清理、統計底子還在 | **L22** —— 統計與 pandas 題有優勢 |
| 寫過 Python、碰過 scikit-learn / PyTorch | L23 —— 演算法原理與模型調校題有優勢 |
| 兩邊都不熟 | L22 的統計計算題需要動筆算，L23 的觀念題比例較高；怕計算選 L23，怕背演算法選 L22 |

選定 L22 之後，本篇後面的規劃都以 **L21 + L22** 為準。

## 13.2 中級不是初級的延伸包

很多人以為「中級科目1 = 初級科目1 + 科目2 的加強版」，**這個假設會害你把時間押錯地方**。三份實證資料：

### 證據一：官方抵免辦法

`抵免辦法.pdf`（115.01 版）明確規定：

| 中級考試科目 | 抵免原則 |
|---|---|
| **科目1 人工智慧技術應用與規劃（L21）** | **無抵免** |
| **科目2 大數據處理分析與應用（L22）** | 原「**巨量資料分析師**」初級科目2 或中級科目1 通過者可抵免 |
| 科目3 機器學習技術與應用（L23） | 原「機器學習工程師」初級科目2 通過者可抵免；原「巨量資料分析師」中級科目1 通過者亦可選擇抵免此科 |

兩個關鍵：

1. **能抵免 L22 的是已停辦的「巨量資料分析師」證照，不是初級 AI 應用規劃師。** 初級證照對中級沒有任何抵免效力。
2. **L21 是唯一一科「無抵免」** —— 官方認定沒有任何既有鑑定項目能對應它的內容。

### 證據二：評鑑範圍對照

初級科目一的內容不是整包升級到 L21，而是**被拆散到中級三科**：

```
初級科目一「人工智慧基礎概論」
├─ AI 定義與分類、AI 治理概念 ──────────→ L21（少部分）
├─ 資料處理與分析概念、資料隱私安全 ────→ L22 ★ 你要考的這科
├─ 機器學習基本原理、常見模型 ──────────→ L23
└─ 鑑別式 / 生成式 AI 概念 ─────────────→ L21 + L22

初級科目二「生成式AI應用與規劃」
├─ No code / Low code 概念 ────────────→ 中級完全沒有
├─ 生成式AI 應用領域與工具使用 ─────────→ L21（改問技術機制而非工具操作）
└─ 導入評估 / 導入規劃 / 風險管理 ───────→ L21 的 L212（範圍擴大為通用 AI）
```

初級「資料處理與分析概念」那一塊確實接得上 L22，但**初級只教到概念層**：知道要清資料、知道有結構化與非結構化之分。L22 要你**動手算、會寫 pandas、能選儲存架構**。

## 13.3 你的初級基礎，哪些還能用

### 能直接接上的

| 初級學過 | 中級怎麼考 |
|---|---|
| 資料清理的基本步驟（缺失值、離群值、重複值） | **L22 考同樣的事，但要選方法、寫程式**：MCAR/MAR/MNAR、中位數 vs 平均補值、Robust Scaling |
| 結構化／半結構化／非結構化資料 | L22 問這三類**該用什麼儲存架構**：關聯式、NoSQL 四型、資料湖 vs 資料倉儲 |
| 導入評估：可行性、ROI、資料就緒度 | L21 一樣考，但情境更複雜、要權衡多個限制條件 |
| 風險管理：偏見、隱私、合規 | L21 + L22 都考，但會問到具體技術（差分隱私、同態加密、K-匿名） |
| 生成式 AI 與鑑別式 AI 的差異 | L22 的 L22402／L22403 直接考「兩者需要什麼樣的資料支撐」 |

### 需要重學一遍的

| 初級的程度 | 中級 L22 要求的程度 |
|---|---|
| 知道要看平均數 | 要能算標準差、四分位數、判斷偏態，並知道右偏時該用中位數補值 |
| 知道資料有離群值 | 要能用 1.5×IQR 或 Z 分數判定，並知道標準化**不會**消除離群值 |
| 知道要畫圖表 | 要能依資料型態選圖表，並辨認截斷 Y 軸這類誤導手法 |
| 知道有資料庫 | 要能分辨 ACID、Sharding、Schema-on-Write vs Schema-on-Read、欄式 vs 列式儲存 |
| 聽過 Python | 要能讀懂 `df.groupby()`、`merge(how=...)`、`chunksize`、`astype('Int64')` 的行為 |

**一句話總結：初級考「知道這是什麼」，L22 考「算給我看、寫給我看、選給我看」。**

## 13.4 命題風格與答題策略

三個實務影響：

1. **L22 有 21% 的題目含程式語法**，比 L23 的 13% 還高。集中在 pandas（`describe`、`groupby`、`merge`、`astype`、`chunksize`）與少量 SQL。**看不懂程式碼會直接失分**，而且這類題通常是整組連考（例如 114-2 第 43～50 題是連續兩組資料處理題組：43～47 題共用 vgsales.csv 情境、48～50 題共用 marketing.csv 情境）。
2. **23% 是附圖題**：盒鬚圖、直方圖、相關係數熱力圖、`describe()` 輸出表、程式碼截圖。讀圖能力要練，不能只背定義。
3. **18% 是題組題**：一段情境敘述帶 2～5 題。讀懂一次可以答多題，但敘述沒讀懂會連錯數題——**先把題組敘述讀完再開始作答**，不要邊讀邊答。

另外一個 L22 特有的陷阱：**官方《學習指引》用了部分大陸用語**。最容易踩的是把 Columnar Storage 寫成「**列式儲存**」，但台灣慣稱「**欄式儲存**」，而「列」在台灣指 row。看到這類字，一律回去確認英文。

## 13.5 讀書路線與時間配置

### 建議順序

```
第 1-2 週  L22 機率統計基礎（L22101 / L22102 / L22103）
           ↓ 敘述統計、機率分佈、假設檢定
           ↓ 官方篇幅最大的一塊，敘述統計相關題也有 24%
           ↓ 統計久沒碰的人，這兩週不要省

第 3-4 週  L22 大數據處理技術（L22201 / L22202 / L22203）
           ↓ 收集清理、儲存管理、處理工具
           ↓ L22203 是全科認領題數最多的知識點，pandas 語法都在這
           ↓ 一邊讀一邊打開 Python 實際跑一次

第 5 週    L22 分析方法與視覺化（L22301 / L22302 / L22303）
           ↓ 統計在大數據的應用、常見分析方法、視覺化
           ↓ L22302 涵蓋分群分類迴歸關聯規則，題數第二多

第 6 週    L22 大數據在 AI 的應用（L22401～L22404）
           ↓ 與機器學習的銜接、鑑別式、生成式、隱私合規
           ↓ 類別不平衡是這一段最穩定的考點

第 7 週    L21 全科（L21101～L21302）
           ↓ 初級底子在這裡最派得上用場，讀起來最快
           ↓ 但 L211 的 NLP／CV／多模態技術原理是全新的，別跳

第 8 週    歷屆試題 + 錯題複習
```

> **為什麼 L21 放在後面？** 因為 L21 是兩條路線共用的必考科，而初級底子對 L21 的幫助最大、對 L22 的幫助最小。先攻陌生度最高的 L22，L21 留在記憶最新的時候讀。

### 時間配置參考（總計約 85～105 小時）

| 區塊 | 建議時數 | 佔比 |
|---|---:|---:|
| L22 機率統計基礎（L22101-103） | 18 h | 19% |
| L22 大數據處理技術（L22201-203） | 22 h | 23% |
| L22 分析方法與視覺化（L22301-303） | 18 h | 19% |
| L22 大數據在 AI 的應用（L22401-404） | 14 h | 15% |
| L21 AI 技術應用（NLP/CV/多模態/生成式） | 12 h | 13% |
| L21 導入評估與規劃 | 6 h | 6% |
| L21 系統部署與整合 | 5 h | 5% |

> 時數比例參照各知識點在官方 100 題中被認領的題數分佈，但**不是等比換算**：
> pandas 語法與統計計算需要動手練，單位時間的吸收率低於純觀念題，所以前四週配得比題數比例更重。

## 13.6 練習資源對照

| 資源 | 題數 | 用途 |
|---|---:|---|
| L22 主題庫 | 290 | 依章節練 L22，弱項可單章反覆做 |
| L21 主題庫 | 311 | 同上 |
| L22 歷屆（114-2、115-1） | 100 | 附圖題與題組題的實戰練習 |
| L21 歷屆（114-2、115-1） | 100 | 熟悉真實命題風格與難度 |
| 初級歷屆（114-4 ~ 115-3） | 400 | 檢驗基礎是否還在，快速暖身用 |

建議的練習節奏：

1. **讀完一章 → 做該章主題庫**，答對率低於 70% 就回頭重讀
2. **程式碼題要自己打一遍**，光看選項判斷對錯，換個寫法就認不出來
3. **全部讀完 → 整卷做歷屆**，模擬考試時間壓力
4. **錯題不要只看答案**，要能說出其他三個選項各錯在哪（中級的誘答選項都寫得很像對的）

## 13.7 銜接檢核表

開始讀 L22 之前，先確認這些觀念還記得。**不確定的先回頭補，不然中級會讀得很痛苦**：

- [ ] 平均數、中位數、眾數的差異，以及右偏資料為何 mean > median
- [ ] 標準差與變異數的關係，以及標準差為何與原資料同單位
- [ ] 結構化／半結構化／非結構化資料的差異與例子
- [ ] 資料清理的基本步驟（缺失值、離群值、重複值）
- [ ] 監督式／非監督式／強化學習的差別與適用情境
- [ ] 過擬合與欠擬合的成因、如何從訓練/驗證曲線判斷
- [ ] 準確率、精確率、召回率、F1 的定義與取捨情境
- [ ] 生成式 AI 與鑑別式 AI 的根本差異
- [ ] 偏見的來源（資料偏誤、標註偏誤、演算法偏誤）
- [ ] 去識別化的基本手法（遮罩、泛化、假名化）
- [ ] Python 基本語法：list / dict、切片、函式呼叫、`import`

最後一項如果不確定，**先花兩小時補 Python 與 pandas 基礎再開始**——L22 有 21% 的題目含程式語法，這是投報率最高的兩小時。
