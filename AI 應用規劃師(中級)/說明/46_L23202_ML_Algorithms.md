## 46.1 全景圖與選型決策樹

### 官方指引的四個區塊

```
機器學習演算法
├── 監督式學習（有標籤）
│   ├── 迴歸（輸出連續值）
│   │   └── 線性迴歸／Ridge／Lasso／SVR／決策樹迴歸／集成式迴歸
│   └── 分類（輸出離散類別）
│       └── 邏輯迴歸／SVM／決策樹分類／KNN／樸素貝氏／集成式分類
└── 非監督式學習（無標籤）
    ├── 分群：K-Means／階層式／DBSCAN
    ├── 降維：PCA／t-SNE／UMAP
    ├── 關聯規則：Apriori／FP-Growth
    └── 異常偵測：Isolation Forest／One-Class SVM
```

### 五步選型決策樹（考場實際用得上的順序）

```
Step 1  有標籤嗎？
        有 → 監督式；無 → 非監督式
        「只有正常樣本、沒有異常標註」→ 非監督／半監督異常偵測

Step 2  輸出是什麼？
        連續數值 → 迴歸（房價、成交價、發電量、耗能）
        離散類別 → 分類（是否購買、是否違約、垃圾信與否）
        找群體   → 分群
        降維度   → PCA / t-SNE / UMAP

Step 3  關係是線性還是非線性？
        近似線性、要係數可解釋 → 線性／邏輯迴歸
        明顯非線性、有特徵交互 → 樹模型、集成樹、核 SVM

Step 4  要哪一種「可解釋」？
        要「係數方向與大小」   → 線性／邏輯迴歸（金融評分卡）
        要「整體特徵重要性」   → 隨機森林、GBDT（可直接輸出排序）
        要「個案級解釋」       → 樹模型 + SHAP／LIME
        注意：SVR 的支援向量「不是」特徵重要性，這是官方誘答

Step 5  資料規模與維度
        小～中、維度高、邊界清楚 → SVM
        中～大、混合型特徵       → 隨機森林、XGBoost／LightGBM
        極大、需要即時預測       → 樸素貝氏、線性模型
        極大 → 避開 SVM／SVR（訓練成本隨樣本數平方成長）與階層式分群
```

## 46.2 監督式學習（一）：迴歸家族

### 線性迴歸與它的五個假設

模型：`y = β₀ + β₁x₁ + … + βₙxₙ + ε`。β₀ 是截距，βᵢ 是各特徵的迴歸係數，ε 是誤差項。

官方指引明列五個假設，考題常以「殘差圖」的形式反過來問：

| 假設 | 白話 | 違反時的徵兆 |
|---|---|---|
| 線性關係（Linearity） | 自變數與應變數呈線性 | 殘差圖出現系統性彎曲（U 形、弧形） |
| 誤差常態性（Normality of Errors） | ε 服從常態分佈 | Q-Q 圖偏離對角線 |
| 變異數齊一性（Homoscedasticity） | 誤差變異在各處相同 | 殘差呈喇叭狀擴散 |
| 誤差獨立性（Independence of Errors） | 觀測值之間誤差無關 | 時間序列殘差自相關 |
| 無多重共線性（No Multicollinearity） | 特徵間不高度相關 | 係數符號怪異、估計不穩定 |

> **殘差圖題型的標準解**：殘差在高值區出現系統性彎曲且誤差極大 → 結論是「存在離群值或非線性關係，違反迴歸假設」，**不是**過擬合（過擬合的徵兆是訓練好、測試差），也不是欠擬合。

評估指標一律是 MSE／RMSE／MAE／R²／調整後 R²。MSE 對誤差取平方，會讓離群值主導梯度更新；MAE 為線性懲罰、對離群值不敏感；Huber 損失則是小誤差用平方、大誤差轉線性。

### 正則化：Ridge 與 Lasso 的分工

| 項目 | Ridge（嶺迴歸） | Lasso |
|---|---|---|
| 懲罰項 | L2：λ·Σβⱼ² | L1：λ·Σ\|βⱼ\| |
| 對係數的效果 | 壓小但**不會歸零** | 可把部分係數**壓到 0** |
| 是否能特徵選擇 | ✗ | ✓（產生稀疏模型 Sparse Model） |
| 高度相關特徵 | 一起縮小、分攤權重 | 傾向只保留其中一個 |
| 全名 | Ridge Regression | Least Absolute Shrinkage and Selection Operator |

> λ 不能拍腦袋決定，必須用交叉驗證挑選。λ 過大 → 係數被壓過頭 → 欠擬合。兩者共通限制：仍然無法建模非線性關係。

### SVR：用 ε-tube 換抗離群值

支援向量迴歸（Support Vector Regression, SVR）不最小化所有點的平方誤差，而是**忽略落在 ε 容忍帶內的誤差**，只懲罰超出帶外的點。三個關鍵超參數：C（懲罰參數）、ε（容忍帶寬）、核函數參數（RBF 核的 γ）。

- 優點：不需線性假設、不需誤差常態、對離群值有抵抗力
- 限制：訓練時間與記憶體隨樣本數**平方成長**，不適合極大資料；用非線性核之後極難解釋

### 決策樹迴歸

從根節點依特徵閾值遞迴切分，葉節點輸出**該節點所有樣本目標值的平均數**。因此預測結果是**分段常數**——這正是「模型不連續、會出現跳躍」這個缺點的來源。它屬於非參數模型，不需要線性、常態、變異數齊一等假設，也對特徵尺度不敏感。缺點是單棵樹極易過擬合、對資料微小變動敏感（樹結構可能整個改變）。

## 46.3 監督式學習（二）：分類家族

### 邏輯迴歸：名為迴歸，實為分類

```
p = 1 / (1 + e^-(β₀ + β₁x₁ + … + βₙxₙ))
```

輸出是「屬於正類的機率 p」，套上門檻後成為類別 → **它是分類演算法**。名稱裡的「迴歸」來自「特徵與對數勝率（Log-Odds）呈線性關係」這個假設：把 [0,1] 的機率透過 log(p/(1−p)) 轉成 (−∞, +∞) 的實數後，再用線性模型去擬合。

- 適用：二元分類、需要可解釋的場域（金融信用評分卡、醫療）
- 限制：無法捕捉複雜非線性邊界、對離群值敏感、多類別需擴展成 One-vs-Rest（OvR）或 Multinomial
- 評估：Accuracy／Precision／Recall／F1-score／ROC-AUC

> 傳統信用評分卡的標準流程是：特徵選擇與多重共線性分析 → 分箱（Binning）與資訊值（Information Value, IV）檢定 → 邏輯迴歸建模 → 以樣本穩定性指標（PSI）監控。**「用生成式模型做特徵學習」不屬於這條流程**（缺乏可解釋性，不符監理要求）。

### 決策樹分類器與不純度指標

分裂準則三選一，考點集中在「pᵢ 到底是什麼」：

| 指標 | 公式 | pᵢ 的定義 | 值域（k 類） |
|---|---|---|---|
| 吉尼不純度 Gini Impurity | `Gini = 1 − Σ pᵢ²` | **該節點內屬於第 i 類的樣本比例** | 0 ～ 1−1/k |
| 熵 Entropy | `Entropy = − Σ pᵢ log₂ pᵢ` | 同上 | 0 ～ log₂k |
| 分類誤差 Classification Error | `1 − max(pᵢ)` | 同上 | 0 ～ 1−1/k |

實際算一次就不會忘：某節點內有 8 個 A、2 個 B，則 p_A = 0.8、p_B = 0.2。

- Gini = 1 − (0.8² + 0.2²) = 1 − 0.68 = **0.32**
- Entropy = −(0.8·log₂0.8 + 0.2·log₂0.2) ≈ **0.722**
- 兩者都是**越小代表節點越純**。若節點全為同一類，pᵢ = 1，Gini = 1 − 1 = 0。

**資訊增益（Information Gain）= 分裂前的熵 − 分裂後各子節點熵的加權平均**，衡量「不確定性降低了多少」。它是**決策樹遞迴分裂時挑選特徵的依據**，不是 L1 正則化的機制、不是神經網路靠激活函數萃取特徵的方式、也不是核函數 SVM 的高維映射。

停止條件通常是：達到 max_depth、節點樣本數低於 min_samples_split、或節點純度已足夠高。

### SVM：最大化間隔

支援向量機（Support Vector Machine, SVM）的決策邊界為 `w·x + b = 0`，目標是**最大化兩類之間的間隔（Margin）**。判斷規則：w·x + b > 0 為正類，< 0 為負類。資料在原空間線性不可分時，用核函數（Kernel Function）映射到高維空間再線性切開。

- 常用核：線性核、多項式核、RBF／高斯核、Sigmoid 核
- 強項：特徵維度高（甚至 n_features > n_samples）、資料量中小、邊界清楚
- 弱點：大資料計算成本高、C 與 γ 調參複雜、非線性核後不易解釋
- **必須做特徵縮放**（以距離／內積為基礎）

### KNN：惰性學習

K 最近鄰（K-Nearest Neighbors, KNN）步驟只有三步：算距離（歐幾里得／曼哈頓）→ 取最近 K 個鄰居 → 多數決投票。

| 特性 | 說明 |
|---|---|
| 訓練階段 | 幾乎不做事，只儲存資料（惰性學習 Lazy Learning） |
| 預測階段 | 要跟**全部**訓練樣本算距離 → 資料大時極慢 |
| 特徵縮放 | **必做**，否則大尺度特徵會主導距離計算 |
| K 太小 | 容易受雜訊影響 |
| K 太大 | 類別邊界被模糊；K 通常用交叉驗證挑 |
| 維度詛咒 | 高維下點距趨於均勻，「最近鄰」失去意義 |
| 多類別 | 可直接處理，無需 OvR 擴展 |

### 樸素貝氏：條件獨立的代價與紅利

`P(C|X) = P(X|C) · P(C) / P(X)`，四項分別是後驗機率（Posterior）、似然度（Likelihood）、先驗機率（Prior）與證據（Evidence）。「樸素」指的是**在給定類別下特徵條件獨立**的假設，於是 `P(X|C) = P(x₁|C)·P(x₂|C)·…·P(xₙ|C)`，計算量大幅下降。

- 適用：文字分類（垃圾信過濾、情感分析、新聞分類）、大規模資料、即時預測、多類別、特徵數多
- 限制：特徵高度相關時失準；**零機率問題**（訓練集沒出現過的特徵值會讓整條後驗歸零）須用**拉普拉斯平滑（Laplace Smoothing）**；只能分類，不能做迴歸
- **不需要特徵標準化**——它算的是詞頻與機率，不是距離。把「做特徵縮放」當成樸素貝氏的改善方案是典型張冠李戴

## 46.4 集成學習：Bagging 對 Boosting

| 維度 | Bagging（Bootstrap Aggregating） | Boosting |
|---|---|---|
| 建模方式 | 各基模型**平行、獨立**訓練 | 各基模型**序列**訓練，後者修正前者的錯誤 |
| 取樣 | Bootstrap 隨機子樣本 + 隨機特徵子集 | 依前一輪的殘差／權重調整 |
| 整合方式 | 多數決投票（分類）／平均（迴歸） | 加權求和 |
| **主要降低** | **變異（Variance）** | **偏差（Bias）** |
| 代表 | Random Forest | Gradient Boosting、XGBoost、LightGBM |
| 過擬合風險 | 較低 | 較高（學習率過高或樹太深時） |
| 訓練速度 | 可平行化、快 | 較慢 |

> 一句話記法：**Bagging 靠「各自獨立再平均」壓住震盪（變異）；Boosting 靠「一輪一輪補課」補足準度（偏差）。**

隨機森林的加值是**特徵重要性（Feature Importance）**：可直接輸出基於不純度下降或排列重要性的排序，這正是「既要建模非線性、又要提供整體特徵重要性供稽核」這類題目的標準答案。它的缺點是模型整體屬黑箱、體積大、預測速度比單棵樹慢，且對極端不平衡資料仍會偏向多數類別。

### 高效梯度提升：XGBoost vs LightGBM

| 項目 | XGBoost | LightGBM |
|---|---|---|
| 生長策略 | **Level-wise**（層級式：同一深度的葉子一起分裂，樹橫向擴展） | **Leaf-wise**（葉子式：優先分裂增益最大的葉，樹垂直生長） |
| 加速機制 | 二階導數（Hessian）資訊、Block 結構 | 直方圖演算法（Histogram-based） |
| 缺失值 | 自動學習分裂方向 | 內建處理 |
| 特有風險 | — | Leaf-wise 若不設 max_depth 易生成不平衡樹而過擬合（小資料尤甚） |

**XGBoost 相對傳統 GBDT 的核心改進**（官方考過兩次）：

1. **目標函數中直接加入正則化項**——葉節點數量 × γ ＋ 葉節點權重的 L2 懲罰，使每次分裂都要在增益與複雜度之間權衡
2. **原生支援缺失值自動處理**
3. **特徵層級的並行化運算**

不是「改用隨機森林架構」、不是「用神經網路取代弱學習器」、也不是「批次正規化（Batch Normalization）」（那是深度學習的技術）。另外，學習率（shrinkage）是使用者設定的固定超參數，**不是目標函數裡的強制衰減機制**；「強制所有樹深度為 1（Decision Stumps）」是 AdaBoost 的常見設定，不是 XGBoost。

## 46.5 非監督式學習（一）：分群

| 演算法 | 需先指定群數？ | 能處理非凸群集？ | 會標記雜訊點？ | 對離群值 | 主要限制 |
|---|---|---|---|---|---|
| **K-Means** | **需要（K）** | ✗ 只適合球形／凸形 | ✗ | 敏感（質心是平均數） | 對初始質心敏感，只保證局部最優 |
| **階層式分群** | **不需要**（可從樹狀圖切） | 視連結方式而定 | ✗ | 敏感 | 計算複雜度高、合併／分裂**不可撤銷** |
| **DBSCAN** | **不需要** | ✓ 任意形狀 | **✓ 會標記雜訊點** | 天生抗離群 | 對 Eps／MinPts 高度敏感、密度不均時失效、高維難定義密度 |

### K-Means 的四個已知限制（官方整段考過）

```
1. 必須預先指定 K
2. 以歐氏距離最小化群內平方和 → 偏好大小相近的球形（凸）群集
   → 遇到半月形（非凸）結構會被橫切錯分
3. 從隨機初始質心出發 → 只保證收斂到局部最優
   → 每次執行結果略有不同
4. 質心是平均值 → 容易被少數離群值拉偏
```

演算法步驟固定四步：初始化 K 個質心 → 把每點分配到最近質心 → 重算各群平均作為新質心 → 重複直到質心不再顯著移動或達最大迭代次數。

兩種常見誘答要認得：「假設群集為高斯分佈」講的是**高斯混合模型（GMM）**，不是 K-Means；「初始化不影響最終結果、演算法保證全域最優」則直接說反了。「維度超過 10 就失效」是過度絕對的敘述——高維確實讓距離鑑別力下降，但沒有這種門檻。

### 階層式分群的兩個方向

- **凝聚式（Agglomerative）**：由下而上（bottom-up），每個點自成一群 → 逐步合併最相似的兩群 → 最後合成一大群
- **分裂式（Divisive）**：由上而下（top-down），全部一群 → 逐步分裂 → 最後每點自成一群
- 產物是**樹狀圖（Dendrogram）**，可在任意高度橫切，取得不同粒度的分群結構——這是它「無須預先指定 K」的原因

### DBSCAN 的點分類（高頻考點）

```
兩個參數：
  Eps（epsilon）：鄰域半徑
  MinPts        ：形成核心點所需的最小點數

核心點（Core Point）  ：Eps 鄰域內點數 ≥ MinPts
邊界點（Border Point）：自己不夠格當核心點，但**落在某個核心點的鄰域內**
雜訊點（Noise Point） ：不是核心點，**也不在任何核心點的鄰域內**，
                        且與任何群集無密度可達（Density Reachability）關係
                        → 不歸入任何群集
```

「鄰近點（Neighbor Point）」與「潛在點（Potential Point）」**不是 DBSCAN 的正式定義**，純屬誘答。

## 46.6 非監督式學習（二）：降維、關聯規則、異常偵測

### PCA 與非線性降維

主成分分析（Principal Component Analysis, PCA）流程：資料標準化 → 計算共變異數矩陣 → 特徵值分解 → 依特徵值由大到小選前 K 個特徵向量作為主成分 → 將資料投影到新空間。

**解釋變異比例 = 該主成分的特徵值 ÷ 所有特徵值總和。** 例如 λ₁=6.0、λ₂=3.0、λ₃=1.0，總和為 10：

- PC1 解釋 6/10 = **60%**
- PC1 + PC2 解釋 9/10 = **90%** → 已超過 80% 門檻，可安全降到二維並保留大部分資訊
- PC3 只剩 10%，可捨棄

| 方法 | 線性？ | 保留的結構 | 能投影新資料？ | 主要用途 |
|---|---|---|---|---|
| **PCA** | 線性 | 全域最大變異方向，主成分彼此正交 | **可**（用既有主成分矩陣直接投影） | 降維、去冗餘、去噪、作為下游模型輸入 |
| **t-SNE** | 非線性 | **局部鄰域**，不保留全域距離與尺度 | **不可**（無明確外推函數） | **只適合視覺化**，不適合當模型輸入特徵 |
| **UMAP** | 非線性 | 局部＋全域兼顧 | 支援增量學習 | 視覺化；比 t-SNE 快，可處理更大資料 |

PCA 的限制：只能捕捉線性關係、主成分是原始特徵的線性組合而缺乏直觀解釋、對離群值敏感（會扭曲共變異數矩陣）。t-SNE 另有計算成本高、受隨機初始化影響（每次結果略有不同）、困惑度（Perplexity）需細調等缺點。

```python
# PCA 去噪的關鍵在 n_components：保留過多成分＝連雜訊一起重建回來
pca = PCA(n_components=0.5).fit(noisy)          # 只保留 50% 變異，濾掉雜訊成分
denoised = pca.inverse_transform(pca.transform(noisy))

# 降維 + 分類必須包成 Pipeline，否則每折的測試資料已參與過降維擬合 → 資料洩漏
pipe = Pipeline([("lda", LDA(n_components=2)), ("knn", KNeighborsClassifier(5))])
scores = cross_val_score(pipe, X, y, cv=StratifiedKFold(n_splits=5, shuffle=True))
```

### 關聯規則：三個衡量標準

| 指標 | 定義 | 判讀 |
|---|---|---|
| 支持度 Support | P(A∩B)，A 與 B 同時出現的交易比例 | 規則的普遍程度 |
| 信賴度 Confidence | P(B\|A) = Support(A∪B) / Support(A) | 規則的可靠程度 |
| 提升度 Lift | Confidence(A⇒B) / P(B) | **>1 正相關；=1 獨立；<1 負相關** |

- **Apriori**：核心是 Apriori 性質——「頻繁項集的所有非空子集必為頻繁；不頻繁項集的任何超集必不頻繁」，用來剪枝縮小搜尋空間。缺點是要**多次掃描資料集**、產生大量候選集，高維稀疏資料下效率低落。
- **FP-Growth**：建立 FP 樹（Frequent Pattern Tree）這個緊湊結構，**不產生候選集**，**只需掃描兩次**資料集，在大型稠密資料上顯著更快；缺點是 FP 樹可能吃掉大量記憶體，極稀疏資料時壓縮優勢減弱。

### 異常偵測

**題型辨識句**：「只有大量正常樣本、缺乏任何已確認的異常標註」→ 答案一定是**非監督／半監督異常偵測**，不是監督式二元分類（沒有異常標註根本無法訓練）、不是強化學習（沒有可互動環境與獎勵訊號）、也不是自監督學習（那是學表示的訓練手段，不是本題所問的任務範疇）。

| 方法 | 原理 | 優勢 | 限制 |
|---|---|---|---|
| **Isolation Forest（孤立森林）** | 隨機選特徵、隨機選分割點遞迴切分；**異常點少數幾刀就被孤立 → 平均路徑長度短 → 異常分數高** | 不需距離度量、高維與大資料高效、直接輸出異常分數便於排序與設閾值、對不平衡資料表現好 | 異常點若緊貼正常群集則難偵測；結果受隨機性影響 |
| **One-Class SVM** | 用核函數把**只有正常資料**映射到高維，找出能把正常樣本與原點最大程度分離的超平面；落在邊界外即判為異常 | 可處理非線性邊界、高維表現好、**只需正常資料**即可訓練 | 對核參數與異常率參數高度敏感、計算成本高、訓練資料若混入異常會汙染邊界 |

（另有基於局部密度比較的 LOF（Local Outlier Factor），思路是「比較一個點與其鄰居的局部密度，密度明顯偏低者判為離群」。官方學習指引未列入，僅作對照認識即可；考場上遇到「只有正常資料」的題幹，優先想 Isolation Forest 與 One-Class SVM。）

以下整理自 114-2 與 115-1 官方公告試題中與本知識點直接相關的題目。

| 考點 | 官方怎麼問 | 正解思路 |
|---|---|---|
| L1 正則化效果（114-2 第 2 題） | Lasso 的主要效果為何 | 產生**稀疏模型**、使部分權重收斂為零 → 自動特徵選擇。誘答用「提高學習率」「穩定梯度」混淆 |
| DBSCAN 點類型（114-2 第 4 題） | 鄰域點數不足、又不在任何核心點鄰域內，歸為哪一類 | **雜訊點**。邊界點必須落在某核心點鄰域內；「鄰近點／潛在點」不是正式定義 |
| 資訊增益歸屬（114-2 第 8 題） | 資訊增益主要應用於哪一類模型架構 | **透過遞迴分裂建立分類規則的決策樹**。不是 L1 線性模型、不是深度神經網路、不是核函數 SVM |
| 特徵縮放（114-2 第 9 題） | 建構 KNN、SVM 等距離型模型時最關鍵的前處理 | **特徵縮放**。缺失值補齊與類別平衡有幫助，但不是距離型模型「最核心」的需求 |
| XGBoost vs GBDT（114-2 第 18 題、115-1 第 16 題） | XGBoost 相對傳統 GBDT 的主要技術改進 | **目標函數加入正則化**（葉節點數 × γ ＋ 葉權重 L2）＋**缺失值自動處理**＋**並行化**。誘答：批次正規化、決策樹樁、改用隨機森林 |
| 貝氏定理運作機制（114-2 第 22 題） | 由行為特徵推估「會購買的機率」屬何種機制 | 以**條件機率**計算樣本屬於各類別的機率（後驗），不是分群、不是 MSE 迴歸、不是強化學習 |
| 演算法排除題（114-2 第 23 題） | 以隨機抽樣模擬情境估算機率分佈與風險區間 | 蒙地卡羅方法。K-Means 是分群、**SVR 只能預測單一數值**、特徵選取是篩選變數 |
| 迴歸假設違反（114-2 第 24 題） | 殘差在高價區出現系統性彎曲 | **存在離群值或非線性關係，違反迴歸假設**，不是過擬合、也不是欠擬合 |
| 評分卡流程（114-2 第 25 題） | 哪一項**不是**傳統信用評分卡的常見步驟 | 用生成式模型做特徵學習。分箱／IV 檢定、多重共線性分析、PSI 監控都是標準流程 |
| PCA 變異解釋（114-2 第 35 題） | λ=6.0/3.0/1.0，要保留 ≥80% 變異 | 總變異 10，PC1=60%、PC1+PC2=**90%** → 可降至二維並保留大部分資訊 |
| PCA 去噪程式碼（114-2 第 46 題） | PCA 沒去成噪，該修改哪一段程式 | 改 **n_components**（主成分數量）。保留全部成分等於原樣重建，雜訊原封不動 |
| KNN + 交叉驗證（114-2 第 47 題） | 哪幾組程式碼能正確跑 KNN 交叉驗證 | 須正確建立 `KNeighborsClassifier` 並以 `cross_val_score` 對完整資料評估 |
| t-SNE vs PCA 選型（115-1 第 6 題） | 512 維詞嵌入視覺化 vs 當 XGBoost 輸入特徵 | t-SNE **保留局部鄰域、不保留全域結構**，適合視覺化、**不適合當模型輸入**；PCA 可對新資料直接投影，t-SNE 不行 |
| 樸素貝氏誤判（115-1 第 14 題） | 正常促銷信常被誤判為垃圾信的成因與改善 | 成因是**訓練資料分布偏斜使類別條件機率偏高** → 補足正常促銷信樣本、重新平衡、調整先驗。誘答：「做特徵標準化」（樸素貝氏根本不需要）、「調整 Epoch」（它沒有 Epoch 概念） |
| K-Means 限制（115-1 第 15 題） | 半月形群集、有離群值、每次執行結果不同 | 完整答案須同時涵蓋：**需預先指定 K ＋ 以歐氏距離難處理非凸群集 ＋ 對初始化與離群值敏感** |
| 模型選型（115-1 第 28 題） | 要建模非線性 ＋ 要提供整體特徵重要性供稽核 | **隨機森林迴歸**。邏輯迴歸是分類模型不能預測成交價；先 K-Means 分群再分別建模產不出統一排序；**SVR 的支援向量不能當特徵重要性** |
| 異常偵測任務範疇（115-1 第 29 題） | 只有正常振動資料、無故障標註 | **非監督／半監督異常偵測**（Isolation Forest、One-Class SVM、自編碼器重建誤差） |
| 網格搜尋成本（115-1 第 34 題） | 3×4×5×3×3 個參數候選 + 5-Fold，共訓練幾個模型 | 笛卡兒積 540 組 × 5 折 = **2,700**。誘答是把「組合」誤算成「相加」 |
| 降維與資料洩漏（115-1 第 44 題） | 先對整體資料做 LDA 再交叉驗證 | **資料洩漏**，準確率被高估。正解是用 **Pipeline** 讓每折只以該折訓練資料擬合降維 |
| 分層交叉驗證（115-1 第 45 題） | 要維持各折的類別比例與原始資料一致 | `StratifiedKFold`、分類器下的 `cv=5`（預設即分層）、`RepeatedStratifiedKFold` 都可；純 `KFold` 不行 |

## 46.9 易錯與陷阱

- [ ] **邏輯迴歸是分類演算法**，不是迴歸演算法；名稱裡的「迴歸」指的是「特徵對**對數勝率**呈線性」，輸出是機率而非連續數值。
- [ ] **吉尼不純度的 pᵢ 是「該節點內第 i 類的樣本比例」**，不是機率密度、不是樣本數。全純時 Gini = 1 − 1² = 0，**越小越純**。
- [ ] **Bagging 降變異、Boosting 降偏差**，別寫反。隨機森林是 Bagging，GBDT／XGBoost／LightGBM 是 Boosting。
- [ ] **Lasso（L1）會把係數壓到 0 並能特徵選擇；Ridge（L2）只會壓小、不會歸零**，因此 Ridge 無法自動簡化模型結構。
- [ ] **KNN、SVM、K-Means、PCA 需要特徵縮放；決策樹、隨機森林、XGBoost、樸素貝氏不需要。** 把「特徵標準化」當成樸素貝氏的改善方案，是官方明點的張冠李戴。
- [ ] **K-Means 必須指定 K；階層式分群與 DBSCAN 不必。** DBSCAN 另外還會**標記雜訊點**，這是三者中唯一具備的能力。
- [ ] **K-Means 只保證局部最優**，會因初始質心不同而每次結果略異；「保證全域最優、初始化不影響結果」是錯的。
- [ ] **「假設群集為高斯分佈」講的是 GMM，不是 K-Means**；K-Means 偏好球形／凸形群集，來自歐氏距離與群內平方和的目標。
- [ ] **DBSCAN 的邊界點必須落在某核心點的鄰域內**；既非核心點、又不在任何核心點鄰域內的，才是雜訊點。
- [ ] **t-SNE 只適合視覺化**，不保留全域結構、也沒有可套用到新資料的轉換函數，因此不能當下游模型的輸入特徵；PCA 則可以直接投影新資料。
- [ ] **PCA 去噪的關鍵是 n_components 設得夠低**；保留全部主成分等於原樣重建，雜訊一點沒少。
- [ ] **SVR 的支援向量不能當作特徵重要性**；要「整體特徵重要性」請用隨機森林或 GBDT。
- [ ] **XGBoost 是 Level-wise（層級式）、LightGBM 是 Leaf-wise（葉子式）**；Leaf-wise 更快，但小資料上不設 max_depth 容易過擬合。
- [ ] **樸素貝氏的零機率問題用拉普拉斯平滑解決**，不是加訓練輪數（它沒有 Epoch），也不是換演算法。
- [ ] **Lift > 1 才是正相關**，Lift = 1 代表獨立、Lift < 1 是負相關；Confidence 高不等於規則有價值。
- [ ] **Apriori 要多次掃描資料並產生大量候選集；FP-Growth 只掃兩次且不產生候選集。**
- [ ] **降維必須放進 Pipeline 再做交叉驗證**；先對整體資料 fit 降維會造成資料洩漏，估計值偏樂觀。
- [ ] **異常偵測題只要出現「只有正常資料、沒有異常標註」，答案就是非監督／半監督**，不可能是監督式二元分類。
- [ ] **決策樹迴歸的葉節點輸出是該節點樣本目標值的平均**，所以預測曲線是分段常數、會有跳躍，不是平滑函數。
