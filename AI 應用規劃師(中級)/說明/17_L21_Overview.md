## 17.4 命題風格與答題策略

| 指標 | L21 | 初級（L11／L12） |
|---|---:|---:|
| 題幹平均字數 | **126** | 105／110 |
| 情境式命題 | **41%** | 29%／36% |
| 含程式碼 | 4% | 0%／10% |
| 附圖題 | 1% | 0% |
| 題組題 | 0% | 0% |

三個實務影響：

1. **題幹長、限制條件多**：一題常帶 2～3 個條件（預算、時效、資料量、法規），
   要**全部滿足**才是正解。讀題時先把限制條件圈出來。
2. **幾乎沒有附圖與題組**：與科目3 不同，L21 是純文字閱讀題，
   時間壓力來自「讀懂長情境」而非「看圖」。
3. **選項都寫得很像對的**：中級誘答會用正確的專業術語描述錯誤的機制。
   檢討錯題時要能說出**其他三個選項各錯在哪**。

### 高頻術語（以題數計）

```
Accuracy 6題   Precision 5題   Recall 4題   Learning Rate 4題
Semantic Segmentation 3題   Instance Segmentation 3題   Object Detection 3題
CNN 3題   PCA 3題   Logistic Regression 3題   Data Drift 3題
```

中文關鍵詞掃描：**延遲／吞吐量相關 18 題、資料漂移／概念漂移 7 題**。

## 17.5 全科易錯總表（考前 10 分鐘掃描）

各知識點的完整陷阱清單在個別講義裡，這裡只列跨知識點最常錯的：

- [ ] 語意分割 vs 實例分割 —— 同類是否分個體
- [ ] MLM 是雙向語境預測，不是由左到右生成
- [ ] 自注意力解決長距離依賴，不是加速訓練
- [ ] LoRA = 凍結原權重 + 低秩矩陣（不是蒸餾）
- [ ] CLIP = 文字 + 影像
- [ ] 模態缺失 → 讓模型具備缺失感知能力，不是補零
- [ ] 導入評估第一步 = 業務痛點與需求辨識
- [ ] 資料隱私 + 本地控制 → 地端私有部署
- [ ] 「輸出不穩定無法解釋」→ 決策透明性風險
- [ ] 資料分佈長期改變 → 概念漂移監控 + 再訓練
- [ ] Z-score 標準化的目的是統一尺度
- [ ] 客戶流失預測 = 分類任務
- [ ] 容器的優點 = 環境一致性與跨平台
- [ ] 邊緣推論在終端裝置本地端
- [ ] 延遲 ≠ 吞吐量 ≠ 穩定度
- [ ] 離線指標好不等於導入成功
