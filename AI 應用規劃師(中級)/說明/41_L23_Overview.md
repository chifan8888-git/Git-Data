## 41.4 L23 特有的題型：附圖與題組

| 指標 | L23 | L21 | 說明 |
|---|---:|---:|---|
| **附圖題** | **23%** | 1% | 程式碼截圖、訓練曲線、混淆矩陣、模型摘要表 |
| **題組題** | **18%** | 0% | 一段情境帶 2～5 題 |
| 含程式碼／語法 | 10% | 4% | scikit-learn、PyTorch、Keras、NumPy |
| 情境式命題 | 27% | 41% | 比 L21 低，較多直接考觀念 |

### 應對策略

**附圖題（四分之一的題目）**

看不懂程式碼就是直接失分。必須熟悉的語法：

```python
# scikit-learn
train_test_split(X, y, test_size=0.2, stratify=y, random_state=42)
cross_val_score(model, X, y, cv=5)
Pipeline([('scaler', StandardScaler()), ('knn', KNeighborsClassifier())])
LinearRegression().fit(X, y)             # 順序是 (X, y) 不是 (y, X)

# NumPy
np.dot(v1, v2)          # 內積（純量）
np.linalg.inv(A)        # 反矩陣
np.linalg.eig(A)        # 特徵值

# Keras
model.add(Dense(10, activation='softmax'))
model.compile(loss='categorical_crossentropy', optimizer='adam')
```

**讀圖順序**：先看題目問什麼 → 再回圖找對應那幾行 → 不要整段逐行讀。

**題組題（18%）**

先把共用敘述讀懂，再一次答完該組所有題，不要讀一題跳一題。
好處是讀懂一次可以答多題，壞處是敘述誤解會連錯數題。

## 41.5 全科易錯總表（考前 10 分鐘掃描）

各知識點的完整陷阱清單在個別講義裡，這裡只列最常錯的：

- [ ] 條件機率分母是條件事件
- [ ] `inv` / `det` / `eig` / `dot` 別搞混
- [ ] 微調用小學習率（保護既有特徵）
- [ ] 過擬合＝訓練好驗證差；欠擬合＝兩者都差
- [ ] L1 稀疏可做特徵選擇、L2 不歸零
- [ ] 邏輯迴歸是分類
- [ ] Bagging 降變異、Boosting 降偏差
- [ ] KNN 要先特徵縮放
- [ ] DBSCAN 孤立點＝雜訊點
- [ ] Softmax 配 categorical_crossentropy
- [ ] 全連接層參數量 >> 卷積層
- [ ] Label Encoding 製造虛假順序
- [ ] 有離群值用 Robust Scaling
- [ ] SMOTE 只對訓練集
- [ ] 前處理要進 Pipeline，否則資料洩漏
- [ ] 測試集只能用一次
- [ ] 類別不平衡用 Stratified K-Fold
- [ ] 零容忍漏抓 → 調低門檻拉高 Recall
- [ ] Early Stopping 看驗證損失
- [ ] 同態加密 ≠ 差分隱私；雜湊不是加密
- [ ] Demographic Parity ≠ Equalized Odds
