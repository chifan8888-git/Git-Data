43.1

向量與矩陣表示

先搞清楚資料在機器學習裡以什麼「形狀」出現，再分清楚三（四）種乘法。這一節是 NumPy 程式碼截圖題的全部底子。

資料在機器學習裡的四種身分

物件數學符號NumPy 形狀在模型中的角色
樣本向量（Vector）x ∈ ℝ^d(d,)單筆資料的特徵組合
特徵矩陣（Matrix）X ∈ ℝ^(n×d)(n, d)n 筆樣本，每一列一筆樣本
參數向量θ ∈ ℝ^d(d,)線性模型的權重
權重矩陣W ∈ ℝ^(d×k)(d, k)把 d 維輸入映射成 k 維輸出

線性迴歸的預測寫成 ŷ = Xθ；神經網路每一層的前向傳播寫成 z⁽ˡ⁾ = W⁽ˡ⁾a⁽ˡ⁻¹⁾ + b⁽ˡ⁾。兩者本質相同：都是「矩陣乘向量」再加偏差，差別只在後面有沒有接非線性激活函數。

三種「乘法」必須分清楚

運算寫法形狀變化幾何／實務意義
內積（Dot Product）np.dot(v1, v2)、v1 @ v2(d,)·(d,) → 純量投影、相似度，線性模型預測的核心
逐元素相乘（Hadamard）v1 * v2、np.multiply(d,)*(d,) → (d,)遮罩、加權、閘門（如 LSTM 的 gate）
矩陣乘法A @ B、np.matmul、np.dot(m,n)·(n,p) → (m,p)批次預測、特徵空間轉換
外積（Outer Product）np.outer(v1, v2)(d,)·(e,) → (d,e)梯度外積、秩一更新
np.dot 的雙重人格：輸入兩個一維陣列時做內積回傳純量；輸入兩個二維陣列時等同矩陣乘法。二維以上（張量批次）時 np.matmul／@ 是逐批相乘，np.dot 則是另一種和乘規則，兩者會不同 —— 實務上一律用 @，只有考試題目愛寫 np.dot。

展開 NumPy 函式對照表（考試固定班底）
寫法做什麼輸入限制回傳型別／形狀
np.dot(v1, v2)內積兩個一維向量純量（如 np.int64(32)）
v1 * v2逐元素相乘形狀相同或可廣播與輸入同形狀的陣列
np.linalg.inv(A)反矩陣方陣且 det ≠ 0與 A 同形狀的方陣

三個 np.linalg 函式的張冠李戴是最常見的誘答設計：把 inv 說成算行列式、把 eig 說成算反矩陣、把 det 說成回傳矩陣。記憶法：inv → 矩陣、det → 數字、eig → 一組數字＋一組方向。

三個延伸提醒：

  • 向量沒有反矩陣。np.linalg.inv 丟一維陣列進去會直接報 LinAlgError，任何說「對向量求反矩陣」的選項必錯。
  • 對稱矩陣（如共變異數矩陣）建議用 np.linalg.eigh，保證特徵值為實數且由小到大排序；eig 對非對稱矩陣可能回傳複數。
  • 判斷矩陣是否奇異不要用 det(A) == 0，浮點誤差會讓它幾乎永遠不等於 0，實務上看條件數或用 np.linalg.matrix_rank。

矩陣形狀相容性模擬器（必考的算式）

(m, n) @ (n, p) → (m, p)：內側維度必須相等，運算後被「吃掉」；外側維度留下來，就是輸出形狀。調整四個維度看看。

判讀範例（115Q1 第 3 題）：Transformer 的 Q 攤平成 (1, 10)，Query 投影權重 W_Q 為 (10, 64)。內側都是 10 → 可以相乘 → 輸出 (1, 64)。三種標準誘答：(10, 10) 是誤把兩個矩陣的第一維相配；(64, 1) 是正解的轉置（只有算 W_Qᵀ Qᵀ 才會出現）；「維度不相容」則是沒看內側維度。

L2 範數與相似度：內積 vs 餘弦

固定向量 a，旋轉或拉長向量 b。注意：拉長 b 時內積跟著變，餘弦相似度不變。

  • L2 範數：‖x‖₂ = √(Σxᵢ²)，np.linalg.norm(x) —— 向量的「長度」，也是歐氏距離與 L2 正則化的基礎。
  • 餘弦相似度：cos(a, b) = (a·b) / (‖a‖·‖b‖) —— 內積除掉兩邊長度，只看方向不看大小，這是向量資料庫語意檢索的預設度量。
  • 對照：內積會被向量長度影響，餘弦不會。題幹若強調「不受文件長度／熱門度影響」，指向餘弦相似度。
43.2

線性變換與特徵空間

向量 x 被矩陣 A 左乘得到 Ax，就是對 x 做一次線性變換。一次矩陣乘法＝一次幾何操作。

線性變換模擬器：四種基本型態

操作矩陣特徵對長度／方向的影響機器學習中的對應
縮放（Scaling）對角矩陣改變尺度，不改方向特徵標準化、學習率縮放
旋轉（Rotation）正交矩陣（QᵀQ = I）改變方向，不改長度PCA 換基底、特徵對齊
剪切（Shearing）非對角元素不為零方向傾斜、角度改變一般全連接層的權重
投影（Projection）rank(A) < d降維，且不可逆PCA、LDA、分類超平面

只有投影會損失資訊 —— 這正是降維的本質：壓扁之後回不去，所以要挑「壓扁後損失最少」的方向。

特徵值與特徵向量（點卡片翻面）

Av = λv：v 經過變換 A 之後方向不變，只被拉長（或壓縮）λ 倍

回到上面的模擬器按「顯示特徵向量」：縮放有兩支、剪切只剩一支、旋轉一支實數特徵向量都沒有、投影有一支 λ = 0 被壓扁。

det、rank 與可逆性是同一件事

矩陣 A 的兩欄 c₁、c₂ 張成一個平行四邊形，它的面積就是 |det(A)|。讓 c₂ 越來越靠近 c₁ 的方向（兩個特徵越來越共線），看看會發生什麼。

det(A) = 0  ⇔  rank(A) < n  ⇔  A 不可逆（奇異矩陣 Singular）
    │
    ├─ 幾何解讀：det 是變換後的「體積縮放倍率」，等於 0 表示空間被壓扁到更低維
    │
    └─ 資料解讀：某一欄特徵是其他欄的線性組合（完全共線）→ XᵀX 不可逆 → OLS 無解

累積門檻：

三個標準誘答：①「只留 PC1」—— 只有 60%，不足門檻；②「PC2 貢獻高達 30% 所以不能丟 PC3」—— 把單一成分的貢獻跟累積門檻混為一談，前兩者累積已達 90%；③「特徵值相差不大」—— 6:3:1 落差明顯，敘述與數據不符。

SVD 才是實作上的主流

共變異數矩陣 EVD
先建出 d×d 的 C，再分解 C = QΛQᵀ。
特徵數很大時，C 本身就很佔記憶體
直接對 Xc 做 SVD
Xc = UΣVᵀ：V 的各行就是 C 的特徵向量，λᵢ = σᵢ² / (n−1)。
scikit-learn 的 PCA 內部走這條

所以 SVD 與共變異數矩陣特徵分解得到的主成分完全相同。走 SVD 是因為不必顯式建出 d×d 共變異數矩陣，數值更穩定、特徵數很大時也省記憶體。

為什麼 PCA 前必須先標準化

示意資料：30 位員工的「年資（年）」與「年收入（元）」。按下按鈕切換標準化前後，看 PC1 被誰綁架。

共變異數對尺度極度敏感。年收入以「元」為單位、年資以「年」為單位時，年收入的變異數可能大上千萬倍，PC1 幾乎就等於年收入本身，其他特徵完全被稀釋。標準化之後的共變異數矩陣，其實就是相關係數矩陣。同理，異質的多模態特徵不可直接 concat 後做 PCA，高維模態的變異會主導所有主成分。

43.4
最小平方估計與線性迴歸

  
從損失函數到正規方程，只有四行；但真正要懂的是它的幾何意義：迴歸就是正交投影。

  
損失：  J(θ) = ‖y − Xθ‖₂²          （殘差平方和 RSS）
求導：  ∂J/∂θ = −2Xᵀ(y − Xθ) = 0
整理：  XᵀX θ = Xᵀy                 ← 正規方程（Normal Equation）
封閉解：θ̂ = (XᵀX)⁻¹ Xᵀ y


  
投影模擬器：殘差什麼時候最短？

  

    
灰線是 col(X)（X 各欄張成的空間，這裡簡化成一條線）。調整 θ 讓 ŷ = Xθ 在線上移動，觀察殘差 e = y − ŷ 的長度，以及它和 col(X) 的夾角。

    
    

      
      
      
    

    

  

  
「殘差垂直於行空間」寫成數學就是 Xᵀe = 0 → Xᵀ(y − Xθ) = 0 → 正是正規方程。所以最小平方解＝把觀測值投影到特徵所能張成的空間上最近的那一點。投影矩陣 H = X(XᵀX)⁻¹Xᵀ（帽子矩陣），ŷ = Hy。這也解釋了為什麼離群點會扭曲擬合平面：平方損失讓遠離的點取得極大的權重。

Ridge 的線性代數解釋：θ̂ = (XᵀX + λI)⁻¹Xᵀy。λI 把 XᵀX 的每個特徵值整體抬高 λ，保證可逆且條件數下降，於是高度相關特徵的權重被平均分攤並同步縮小，估計穩定卻不會歸零。

封閉解 vs 梯度下降

  

    
正規方程（封閉解）
計算複雜度 O(nd² + d³)，含矩陣反轉。
特徵數 d 很大時很慢，甚至算不動。
不用調超參數。
適用：d 小（數百以內）

    
梯度下降
每次迭代 O(nd)。
特徵數 d 很大時仍然可行。
要調學習率、迭代次數。
適用：d 大、資料量大、線上學習
