# 21. L21104 多模態人工智慧應用（40 分鐘）

> 一句話定位：初級只要求你認得「多模態＝同時處理文字＋影像＋語音」，中級則要求你能在情境題裡判斷「該對齊還是該融合」、「早期融合還是晚期融合」、「某個模態壞掉或不見了怎麼辦」。

## 學習目標
- 分辨跨模態對齊（Cross-Modal Alignment）與多模態融合（Multimodal Fusion）解決的是不同問題
- 判讀早期融合、中期融合、晚期融合在強健性與表達力上的取捨
- 說明 CLIP 如何用對比學習把影像與文字放進共同嵌入空間，並據此完成零樣本分類
- 在模態缺失、時間不同步、標註昂貴等實務情境中選出最合理的處理策略

---

## 21.1 模態、編碼器與演進脈絡

### 四種常見模態的性質差異

| 模態 | 資料結構特性 | 常見編碼器 | 典型雜訊來源 |
|---|---|---|---|
| **文字** | 離散、序列、語意密度高 | Transformer（BERT、GPT 類） | 縮寫、口語、描述殘缺 |
| **影像** | 連續、空間局部性、平移不變 | CNN（ResNet）、ViT | 光照、遮擋、解析度 |
| **語音／音訊** | 時間序列、含語調與情緒線索 | Whisper 類 ASR、聲學 Transformer | 環境噪音、口音 |
| **感測器訊號** | 等間隔連續數值、多通道 | LSTM、Temporal CNN | 採樣頻率不一、漂移 |

**這張表就是 115Q1 第 17 題的答案。** 官方直接考「哪一組模型配置最符合三種模態各自的資料特性」，正解是「影像用 CNN、文字用 Transformer、時序用 LSTM 或 Temporal CNN」。誘答會把架構交叉錯置（LSTM 讀影像、CNN 讀文字），或宣稱「Transformer 具通用性，三種模態統一用 BERT 即可」—— 後者最像對的，但原始像素與感測數值仍需各自的前處理與嵌入設計，是錯的。

### 演進三階段

| 階段 | 做法 | 限制 |
|---|---|---|
| **早期：特徵串接** | 各模態特徵向量直接 concat，丟給 SVM／決策樹 | 無法處理語意對齊與模態交互，擴展性差 |
| **深度學習期：模態專屬網路＋融合層** | CNN 讀影像、RNN 讀文字語音，再經 Fusion Layer 整合 | 模組分離，跨模態互動仍淺 |
| **當前：Transformer 統一架構** | 自注意力驅動跨模態注意（M3AE、Flamingo、BLIP-2） | 參數量大、運算成本高 |

**記憶點：** 第一階段只有「拼接」，沒有「對齊」。對齊能力是深度學習之後、尤其是對比學習出現後才成熟的。

## 21.2 對齊 vs 融合（本知識點最高頻考點）

### 一句話區分

```
對齊 Alignment：不同模態的表示「能不能互相比較」
   → 把 CT 影像向量、病歷文字向量、基因序列向量
     投影到同一個語意空間，讓描述同一件事的表示彼此靠近
   → 產物是「共同嵌入空間（Shared Embedding Space）」

融合 Fusion：不同模態的資訊「怎麼合起來做出一個決策」
   → 決定在輸入層、特徵層還是決策層合併
   → 產物是「一個預測結果」
```

| 維度 | 跨模態對齊 | 多模態融合 |
|---|---|---|
| **要解決的問題** | 異質向量空間不可比較 | 多來源資訊如何整合成決策 |
| **典型技術** | 對比學習（CLIP）、共享編碼器、DTW 時序對齊 | 早期／中期／晚期融合、注意力加權 |
| **成本影響** | 通常**增加**訓練開銷 | 依融合層級而異 |
| **官方考法** | 115Q1 第 18 題正解：「將不同模態的資料表示對齊至共同語意空間，使模型能建立跨模態語意關聯」 | 115Q1 第 50 題：晚期融合的強健性來源 |

> **陷阱提醒：** 115Q1 第 18 題的誘答包含「降低多模態資料的儲存與計算成本」。對齊**不是**為了省成本，它反而更貴。另一個誘答「自動生成跨模態配對標註」屬於弱監督議題，也不是對齊的核心目的。

### 融合的三個層級

```
早期融合 Early Fusion（資料／原始特徵層）
  [影像像素]┐
  [文字向量]├→ 合併成單一輸入 → 單一模型 → 預測
  [感測數值]┘
  優點：能學到最細緻的跨模態交互
  缺點：對缺失與雜訊最敏感，某一模態壞掉會在特徵空間被放大

中期融合 Intermediate / Feature Fusion（各自編碼後的特徵層）
  [影像]→CNN ─┐
  [文字]→Trans├→ 特徵串接／注意力加權 → 共同表示層 → 預測
  [時序]→LSTM ┘
  優點：各模態先各自最佳化再整合，實務最常用
  對應 115Q1 第 35 題正解：基因特徵先做特徵選擇、文本先做語意表示，再融合

晚期融合 Late Fusion（決策層）
  [影像]→模型A→分數A ┐
  [文字]→模型B→分數B ├→ 加權／投票 → 預測
  [時序]→模型C→分數C ┘
  優點：強健性最佳，單一模態品質差只小幅影響整體
  缺點：學不到細粒度的跨模態交互
```

**115Q1 第 50 題就是純粹考定義：** 題幹說採晚期融合，問診文字品質差時整體效能只小幅下降，問「何者**最不可能**是原因」。正解是「晚期融合會在**輸入階段**整合多模態特徵」—— 這句話與晚期融合的定義自相矛盾（輸入階段整合是早期融合）。

> 注意：官方《學習指引》內文把 Late Fusion 寫成「特徵層級整合」，但**實際考題採決策層整合的標準定義**。作答以「各模態先各自預測、再於決策層整合分數或投票」為準。

## 21.3 CLIP 與代表性模型

### CLIP 的訓練與推論

```
訓練（約 4 億組網路圖文配對）
  影像 ──→ 影像編碼器（ViT 或 ResNet）──→ 影像向量 ┐
                                                    ├→ 對比損失
  文字 ──→ 文字編碼器（Transformer）    ──→ 文字向量 ┘
  目標：配對的圖文在空間中拉近，不配對的推遠

零樣本推論（不需要任何新標註資料）
  待測影像 → 影像向量
  文字提示「一張貓的照片」「一張狗的照片」… → 各自文字向量
  計算餘弦相似度 → 取最高者為預測類別
```

| CLIP 面向 | 內容 |
|---|---|
| **核心機制** | 對比學習（Contrastive Learning）＋雙塔編碼器 |
| **關鍵產出** | 共同嵌入空間（Shared Embedding Space） |
| **代表能力** | 零樣本分類、圖文匹配、圖文互搜 |
| **限制** | 細節理解有限（手部、文字、標誌顏色）；訓練資料偏見 |

**114Q2 第 35 題**直接考這段：媒體公司要「不新增標註資料、僅用文字提示就能識別影像」，正解是「透過圖文對比式學習將影像與文字映射至共同嵌入空間，可直接以語意相似度進行零樣本分類」。誘答（影像增強、監督式 MLP）都仍需標註資料；「自迴歸生成文字標籤」則是描述生成模型，不是 CLIP 的對比對齊原理。

**114Q2 第 50 題**是同一觀念的反面考法：文生圖時主體與場景正確，但品牌標誌顏色有誤、手部姿勢不自然，問原因。正解是「文字編碼器與影像編碼器在語意嵌入空間**未充分對齊**，導致跨模態理解偏差」。注意誘答「模型未採用對比學習損失函數」太絕對—— CLIP 本來就用對比學習，問題在**對齊程度不足**，不是完全沒有對齊機制。

### 代表性模型速記

| 模型 | 提出者 | 一句話定位 |
|---|---|---|
| **CLIP** | OpenAI | 圖文對比學習，零樣本分類的基礎；DALL·E 的基石 |
| **BLIP / BLIP-2** | Salesforce | 強化圖文問答（VQA）與圖像描述生成，圖文雙向理解 |
| **Flamingo** | DeepMind | 少樣本學習（Few-shot），可快速適應新圖文任務 |
| **M3AE** | 學術界 | 遮罩預訓練的多模態自編碼器，統一編碼器學共享語意結構 |
| **ImageBind** | Meta | 把影像、聲音、深度、紅外線等多模態映射到單一向量空間 |
| **Whisper** | OpenAI | 語音轉文字（ASR），語音模態進入多模態管線的入口 |

### 語音與感測模態的整合鏈路

語音模態不是「直接丟進模型」，而是有一條標準管線；題目常把這條鏈路拆開來問哪一步負責什麼。

```
語音輸入 → ASR（語音辨識，如 Whisper）→ 文字
         → NLU（自然語言理解，如 BERT／GPT）→ 意圖與語意
         → 任務執行 → TTS（語音合成）或 NMT（機器翻譯）→ 語音／多語回應
```

| 環節 | 負責什麼 | 常見誤認 |
|---|---|---|
| **ASR** | 聲學訊號轉文字 | 不負責理解意圖 |
| **NLU** | 解析意圖、擷取語意槽位 | 不負責辨識聲音 |
| **TTS** | 文字轉語音回饋 | 屬輸出端，與 ASR 是不同方向的技術 |
| **NMT** | 跨語言轉換，支撐多語互動 | 需與 ASR／TTS 串接才構成跨語言語音助理 |

感測模態的整合則依賴**感測融合（Sensor Fusion）**：先做資料同步與特徵對齊，再整合至統一模型。自動駕駛整合攝影機、雷達與超音波，智慧城市整合監視影像與空品／車流感測，智慧醫療整合醫學影像與生命徵象，都屬此類。其兩大挑戰固定為：**採樣頻率與時間戳的同步**，以及**融合後暴增的模型複雜度與運算負擔**。

> 官方《學習指引》的示範題問「哪個情境最能展現多模態 AI 的優勢」，正解是**影片自動生成字幕**—— 它同時牽涉聲音（語音辨識）、文字（轉錄）與影像（上下文輔助）。誘答如 SQL 資料查詢、純圖片壓縮、單一感測器故障排除，都只涉及單一模態。

### 生成模型在多模態潛在空間對齊上的差異（114Q2 第 40 題）

| 模型 | 對齊方式 | 特性 |
|---|---|---|
| **VAE** | 顯式潛在變數建模 | 擅長捕捉整體語意結構，但生成解析度有限 |
| **GAN** | 對抗損失學習分佈映射 | 生成品質高，訓練穩定性差 |
| **Diffusion** | 條件化噪聲反推（Conditional Denoising） | 高保真、穩定且多樣性佳 |

誘答手法是「張冠李戴」：把 VAE 說成隱式／對抗式、說 VAE 與 GAN 用馬可夫鏈、或說三者共用同一潛在空間只差解碼器。三種說法都錯。

## 21.4 模態缺失與資料對齊的實務挑戰

### 模態缺失的四種策略（114Q2 第 21 題，務必背下排序）

| 策略 | 評價 | 為什麼 |
|---|---|---|
| **訓練具模態缺失感知能力的模型** | ✓ **最佳** | 學習階段就明確處理缺失情境，動態調整融合權重，推論時少一個模態仍穩健 |
| 用生成模型（GAN、自迴歸）補全缺失模態 | △ 次之 | 可行但補全品質不穩，且增加運算與誤差傳遞風險 |
| 直接捨棄缺少模態的樣本 | ✗ | 浪費資料，且**無法解決推論時**才發生的缺失 |
| 以零向量或固定向量填充 | ✗ **最差** | 引入無意義訊號干擾學習 |

> 這題的關鍵字是「**最有效維持模型效能**」。零向量填充是最直覺、最容易被選的誘答，但它把「沒有資訊」偽裝成「值為 0 的資訊」，模型會把這個假訊號當真。

### 其他實務瓶頸

| 挑戰 | 具體表現 | 對策 |
|---|---|---|
| **時間對齊** | 各感測器採樣頻率與時間戳不一致 | 動態時間規整（DTW）、時間戳重採樣 |
| **語意對齊** | 影像特徵與文字描述不在同一空間 | 對比學習（CLIP 式）、共享編碼器 |
| **標註成本高** | 圖片標物件同時要寫文字描述 | 弱監督學習、生成模型產標註原型、自我監督預訓練 |
| **運算與部署** | 參數量大、邊緣裝置跑不動 | 剪枝、量化、知識蒸餾、LoRA、雲邊混合部署 |
| **隱私與法規** | 臉部影像、聲紋、生理訊號屬敏感個資 | 匿名化、端到端加密、遵循 GDPR／個資法、對抗訓練防 Deepfake |

## 21.5 應用情境與對應評估指標

| 領域 | 整合的模態 | 典型任務 | 常用指標 |
|---|---|---|---|
| **智慧醫療** | CT／MRI／X 光＋電子病歷＋生理訊號 | 病灶判別後自動生成診斷摘要 | 準確率、假陽性率、報告的 ROUGE |
| **零售與顧客分析** | 監視影像＋POS 交易＋評論與社群 | 動線分析搭配銷售資料優化店面 | 推薦 Precision、動線 IoU、情感分析 F1 |
| **虛實整合互動** | 語音＋文字＋表情＋姿勢＋3D | 虛擬人偶依語音與手勢回應 | 回應延遲、語音 WER、姿勢辨識準確率 |
| **自動駕駛／機器人** | 攝影機＋雷達＋超音波 | 障礙物偵測與定位 | 偵測 mAP、定位誤差 |

**指標配對是可能的送分題：** 生成式報告配 ROUGE、空間框選配 IoU、語音辨識配 WER、情感分類配 F1，四組要能反射性對上。

## 21.6 官方考過什麼

本知識點在 114-2 與 115-1 兩份官方公告試題（共 100 題）中，可歸為多模態相關的共 **8 題**。

| # | 考點 | 怎麼問 | 正解思路 |
|---|---|---|---|
| 114Q2-21 | 模態缺失處理 | 只有影像沒有文本，如何維持效能 | **訓練具模態缺失感知能力的模型**；零向量填充是最差解 |
| 114Q2-35 | CLIP 零樣本 | 不加標註、只給文字提示就要辨識影像 | 對比學習映射至**共同嵌入空間**，用語意相似度做零樣本分類 |
| 114Q2-40 | 生成模型的潛在空間對齊 | VAE／GAN／Diffusion 的根本差異 | VAE 顯式潛在變數、GAN 對抗損失不穩、Diffusion 條件化去噪高保真 |
| 114Q2-50 | 對齊不足的症狀 | 文生圖主體正確但標誌顏色、手部有誤 | 文字與影像編碼器**語意嵌入空間未充分對齊** |
| 115Q1-17 | 各模態編碼器選型 | 影像＋病歷文字＋生理時序該配哪些架構 | CNN／Transformer／LSTM 或 Temporal CNN |
| 115Q1-18 | 跨模態對齊的目的 | CT＋病歷＋基因的癌症預測為何要對齊 | 對齊到**共同語意空間**以建立跨模態語意關聯（非省成本、非產標註） |
| 115Q1-35 | 異質特徵融合策略 | 高維基因特徵＋語意文本如何處理 | **分層策略**：各自最佳化後再做特徵融合，不可直接合併做 PCA |
| 115Q1-50 | 晚期融合強健性 | 文字模態品質差卻只小幅掉效能，何者最不可能 | 「晚期融合在輸入階段整合特徵」自相矛盾，為正解 |

**命中率觀察：** 8／100，約 8%。題型以**情境判斷題**為主，幾乎沒有純名詞定義題—— 官方會給一個醫療、電商或設計情境，要你判斷該用哪個技術或哪個敘述錯誤。準備方向是把「對齊 vs 融合」「早期 vs 晚期」「模態缺失四策略」三組對照練到能秒答。

## 21.7 易錯與陷阱

- [ ] **對齊是讓不同模態「可比較」，不是讓模型「更省資源」** —— 對齊通常增加訓練開銷，看到「降低儲存與計算成本」就排除。
- [ ] **早期融合在輸入層合併，晚期融合在決策層合併** —— 晚期融合的強健性正來自「輸入不合併」，任何說晚期融合在輸入階段整合特徵的敘述都是錯的。
- [ ] **模態缺失要用「缺失感知模型」，不是零向量填充** —— 零向量把「無資訊」偽裝成「數值為 0 的資訊」，是干擾而非中性。
- [ ] **CLIP 是對比式對齊模型，不是自迴歸生成模型** —— 它算相似度，不逐字生成描述；生成描述是 BLIP 這類模型的強項。
- [ ] **CLIP 的問題是「對齊程度不足」，不是「沒用對比學習」** —— 選項講得太絕對通常就是誘答。
- [ ] **Transformer 有通用性，但不等於三種模態可直接統一套 BERT** —— 原始像素與感測數值仍需各自的前處理與嵌入。
- [ ] **異質特徵不可直接 concat 後做 PCA** —— 高維模態的變異會主導主成分，稀釋另一模態的語意；要分層處理後再融合。
- [ ] **多模態融合不必然提升效能** —— 若模態間未對齊或某模態雜訊過大，融合反而可能拉低表現，這是情境題常設的反向考點。
- [ ] **感測融合的第一道關卡是時間同步（DTW），不是語意對齊** —— 兩者是不同層次的對齊問題，題幹提到「採樣頻率／時間戳」就走時序對齊。
- [ ] **多模態不等於多任務** —— 多模態指輸入資料型態多；多任務指同時學多個目標，兩者常在選項中被混用。
