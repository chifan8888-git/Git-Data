## 28.1 敘述性統計的座標：它負責什麼、不負責什麼

### 三大面向

| 面向 | 回答什麼問題 | 主要指標 | 對應圖表 |
|---|---|---|---|
| **集中趨勢**（Central Tendency） | 資料的「核心位置」在哪？ | 平均數、中位數、眾數 | 直方圖的峰位 |
| **離散量度**（Variability／Dispersion） | 資料「散得多開」？ | 變異數、標準差、全距、IQR | 箱形圖的盒寬 |
| **分佈形狀**（Shape） | 對不對稱？尾巴厚不厚？ | 偏度（Skewness）、峰度（Kurtosis） | 直方圖、箱形圖 |

### 敘述 vs 推論：界線在哪

| | 敘述性統計（Descriptive Statistics） | 推論統計（Inferential Statistics） |
|---|---|---|
| **對象** | 手上這批資料本身 | 用樣本推論母體 |
| **產出** | 摘要數值與圖表 | p 值、信賴區間、檢定結論 |
| **是否談不確定性** | 不談 | 核心就是不確定性 |
| **典型語句** | 「這批交易的中位數是 128.6 元」 | 「母體平均數與 100 萬無顯著差異」 |
| **對應知識點** | **L22101（本節）** | L22103 假設檢定與統計推論 |

考試上的意義：題目只要在問「這組數字長什麼樣」，答案就在本節；一旦出現顯著水準 α、p 值、檢定力，那是 L22103 的地盤。

## 28.2 集中趨勢：四個「平均」與中位數、眾數

### 指標對照

| 指標 | 公式概念 | 最適用 | 致命弱點 |
|---|---|---|---|
| **算術平均**（Arithmetic Mean） | 總和 ÷ 筆數 | 對稱、無極端值的數量型資料 | 對離群值極敏感 |
| **幾何平均**（Geometric Mean） | n 個值連乘後開 n 次方 | 成長率、報酬率等**連乘**效應 | 資料必須全為正值 |
| **調和平均**（Harmonic Mean） | n ÷（各值倒數之和） | **同距離不同速率**、效率類倒數加權 | 不能有 0 或負值 |
| **中位數**（Median） | 排序後的中間位置值 | 長尾、有離群值（收入、房價） | 不呈現離散程度 |
| **眾數**（Mode） | 出現次數最多的值 | 類別型資料 | 連續資料須先分箱；可能不只一個 |

### 三種平均的大小關係

對全為正數且不全相等的一組資料，恆有：

```
調和平均 (HM)  <  幾何平均 (GM)  <  算術平均 (AM)
（所有數值完全相同時，三者相等）
```

以 {60, 40} 驗證：HM = 2 ÷ (1/60 + 1/40) = **48**；GM = √(60×40) ≈ **48.99**；AM = **50**。

### 為什麼「平均速度」不是算術平均

```
情境：去程 60 km/h、回程 40 km/h，來回同一段路（同距離）
  錯：(60 + 40) / 2 = 50 km/h
  對：調和平均 = 2 / (1/60 + 1/40) = 48 km/h
  理由：慢的那一段花掉更多「時間」，時間才是加權的基礎

但若情境換成「前 1 小時開 60、後 1 小時開 40」（同時間），
平均速度就是算術平均 50 km/h ——前提換了，答案就換了。
```

### 為什麼「平均報酬」要用幾何平均

```
第 1 年 +100%（×2.0），第 2 年 −50%（×0.5）
  算術平均：(100% + (−50%)) / 2 = +25%   ← 與事實不符
  幾何平均：√(2.0 × 0.5) = 1.0 → 年化 0%  ← 本金確實原地踏步
```

### 選用決策

```
┌──────────────────────────────────────────┐
│ 資料是類別型？ ───────── YES → 眾數       │
│      │ NO                                │
│ 是比率／成長率（連乘）？  YES → 幾何平均  │
│      │ NO                                │
│ 是速率且各段距離相同？ ── YES → 調和平均  │
│      │ NO                                │
│ 有明顯離群值或長尾？ ──── YES → 中位數    │
│      │ NO                                │
│      └──────────────────────→ 算術平均    │
└──────────────────────────────────────────┘
```

## 28.3 離散程度：從標準差到 IQR

### 指標與分母陷阱

| 指標 | 定義 | 對離群值 |
|---|---|---|
| **全距**（Range） | 最大值 − 最小值（只用到 2 個點） | 極度敏感 |
| **變異數**（Variance） | 各值與平均數差的平方之平均 | 敏感（差被平方放大） |
| **標準差**（Standard Deviation） | 變異數開根號，單位與原資料相同 | 敏感 |
| **四分位距**（IQR） | Q3 − Q1，涵蓋**中間 50%** 的資料 | 穩健 |
| **MAD**（Median Absolute Deviation） | 各值與中位數之差的絕對值的中位數 | 最穩健 |

**分母要用 N 還是 n−1？**

| | 母體變異數 | 樣本變異數 |
|---|---|---|
| 分母 | N | n − 1（Bessel 校正，無偏估計） |
| NumPy | `np.std(x)` 預設 `ddof=0` ← **除以 N** | `np.std(x, ddof=1)` |
| pandas | `s.std(ddof=0)` | `s.std()` 預設 `ddof=1` ← **除以 n−1** |

兩個套件的預設值剛好相反，這是計算題最容易被扣分的地方。

### 完整算一次

取 8 筆月薪（單位：千元）：`[30, 32, 34, 35, 36, 38, 40, 120]`

```
n = 8，總和 = 365
算術平均  = 365 / 8            = 45.625
中位數    = (35 + 36) / 2      = 35.5        ← 平均數遠大於中位數 ⇒ 右偏
全距      = 120 − 30           = 90
Q1        = 33.5   Q3 = 38.5   IQR = 5.0
標準差 (ddof=0，÷N)            ≈ 28.27
標準差 (ddof=1，÷n−1)          ≈ 30.22       ← 同一批資料，兩個數字

移除 120 之後：平均 = 35.0、中位數 = 35.0、標準差(ddof=1) ≈ 3.42
→ 一筆離群值把標準差從 3.42 拉到 30.22，中位數卻只動了 0.5
```

### Z 分數：把「離平均多遠」標準化

```
Z = (觀測值 − 平均數) / 標準差

意義：正負號 = 方向（正為高於平均、負為低於平均）
      絕對值 = 偏離平均幾個標準差
判定：|Z| ≥ 3 是常見門檻，但門檻由分析者設定，不是固定不變的
```

### 三種縮放方式的分工

| 方法 | 用到的統計量 | 轉換後 | 對離群值 |
|---|---|---|---|
| **Min-Max 正規化** | 最小值、最大值 | 範圍壓到 **[0, 1]** | 最脆弱（被極值主導） |
| **Z-score 標準化** | 平均數、標準差 | 平均 0、標準差 1，**範圍不受限** | 易被拉偏 |
| **Robust Scaling** | **中位數、IQR** | 以中位數為中心、IQR 為尺度 | 穩健 |

這三種都只做平移與縮放，**分佈形狀（偏度、峰度）不會因此改變**——要改變形狀得靠對數或 Box-Cox 轉換。

## 28.4 分佈形狀：偏度與峰度

### 偏度（Skewness）

| 偏度值 | 名稱 | 長尾在 | 分佈主體在 | 典型資料 |
|---|---|---|---|---|
| **> 0** | 正偏態／右偏（Right-skewed） | **右側** | **左側** | 收入、房價、故障時間 |
| **≈ 0** | 對稱 | — | 中央 | 常態分佈、產品重量 |
| **< 0** | 負偏態／左偏（Left-skewed） | **左側** | **右側** | 設備壽命（少數早期故障拉出左尾）、偏高分的考試成績 |

單峰連續分佈下，右偏時**通常**有 `平均數 > 中位數 > 眾數`，左偏時方向相反。這是判題用的經驗法則，不是定理——離散型或多峰資料可以構造出不成立的例子，因此題目若附了直方圖或箱形圖，以圖形為準。

### 峰度（Kurtosis）：兩套基準值

| 定義 | 常態分佈的基準 | 高峰厚尾 | 扁平輕尾 |
|---|---|---|---|
| **Pearson 峰度**（官方指引採用） | **3** | Kurtosis > 3（Leptokurtic） | Kurtosis < 3（Platykurtic） |
| **超額峰度**（Excess／Fisher） | **0** | Excess > 0 | Excess < 0 |

`scipy.stats.kurtosis()`（預設 `fisher=True`）與 `pandas.Series.kurt()` 回傳的都是**超額峰度**，基準是 0。看到「峰度 = 0」不代表沒有峰態，而代表接近常態。

延續 28.3 的 8 筆月薪：Pearson 峰度 ≈ 6.02（> 3，高峰厚尾），對應超額峰度 ≈ 3.02；`pandas.Series.kurt()` 另做了小樣本校正，同一批資料會回傳 ≈ 7.74。**先確認用的是哪個定義，再談數值大小。**

### 形狀 → 決策

| 觀察到 | 合理的後續動作 | 官方題對應 |
|---|---|---|
| 右偏且有離群值，要補缺失值 | 用**中位數**補，不用平均數 | 115-1 第 41 題 |
| 應變數 Y 右偏且變異數隨 X 增大 | **Box-Cox／對數轉換** Y | 114-2 第 36 題 |
| 報酬率非對稱且厚尾，要評估極端風險 | **分位數迴歸**聚焦尾部分位 | 114-2 第 33 題 |
| 長尾資料要在圖上分層 | 改用**對數刻度**，而非刪掉離群值 | 114-2 第 25 題 |

## 28.5 箱形圖與離群值判定

### 五數綜合與圍籬

```
    30      33.5     35.5     38.5     40                    120
     │       ┌────────┼────────┐        │                     ●
     ├───────┤        │        ├────────┤                  離群值
     │       └────────┼────────┘        │
    下鬚     Q1     中位數      Q3      上鬚
             └────── IQR = 5.0 ──────┘

  圍籬下界 = Q1 − 1.5 × IQR = 33.5 − 7.5 = 26.0
  圍籬上界 = Q3 + 1.5 × IQR = 38.5 + 7.5 = 46.0
  120 > 46.0 → 標記為離群值
  上鬚只畫到圍籬內最遠的實際資料點 40，不是資料集最大值 120
```

官方指引把上／下鬚直接寫成 `Q3 + 1.5×IQR` 與 `Q1 − 1.5×IQR`，那是**圍籬（fence）**的位置；matplotlib、seaborn 實際畫出的鬚線則延伸到圍籬內最遠的資料點。兩種說法在考題中都收斂到同一個考點：**鬚端不等於資料集的最大／最小值**。

### 由箱形圖判讀形狀

| 圖形特徵 | 代表什麼 |
|---|---|
| 盒子短、鬚很長 | 中段高度集中，但存在偏離中段甚遠的極端值 |
| 盒子長且上下對稱 | 變異大且分佈接近對稱 |
| **中位數貼近盒子下緣** | 上半段被拉長 → **右偏**（Right-skewed） |
| **中位數貼近盒子上緣** | 下半段被拉長 → **左偏**（Left-skewed） |
| 盒外有大量點 | 離群值多，需檢查來源（量測錯誤 vs 真實極端事件） |

**箱形圖看不到什麼**：多峰（Bimodal）結構。兩個峰的資料仍可能畫出一個看似正常的盒子，要看峰數必須搭配直方圖或核密度圖。

## 28.6 資料摘要的實作：pandas／NumPy 與大數據下的近似摘要

### `describe()` 輸出的八個橫列

```python
df['sales'].describe()
# count  筆數（不含 NaN）
# mean   平均數
# std    標準差（pandas 預設 ddof=1，除以 n−1）
# min    最小值
# 25%    Q1
# 50%    中位數（Q2）
# 75%    Q3
# max    最大值
```

輸出**不含**眾數、偏度、峰度；那三個要另外呼叫 `.mode()`、`.skew()`、`.kurt()`。對文字欄位呼叫 `describe()` 回傳的是 `count / unique / top / freq`；要一次看所有欄位用 `df.describe(include='all')`。

### 常用語法速查

```python
import numpy as np, pandas as pd

df['x'].mean()      df['x'].median()    df['x'].mode()      # 集中趨勢
df['x'].std()       # ddof=1（樣本）    np.std(a)           # ddof=0（母體）
df['x'].var()       df['x'].quantile([0.25, 0.75])
df['x'].skew()      df['x'].kurt()      # kurt 回傳超額峰度

# IQR 與離群值遮罩
q1, q3 = df['x'].quantile(0.25), df['x'].quantile(0.75)
iqr = q3 - q1
mask = (df['x'] < q1 - 1.5 * iqr) | (df['x'] > q3 + 1.5 * iqr)

# Z 分數（母體定義）
z = (df['x'] - df['x'].mean()) / df['x'].std(ddof=0)

# 分組摘要
df.groupby('Platform')['Global_Sales'].sum()           # 各組總額
df.groupby('Platform')['Global_Sales'].agg(['mean', 'median', 'std'])
df.groupby('CustomerID')['Revenue'].sum().nlargest(3)  # 總額前三名

# 先條件篩選再統計：比較運算要寫在中括號外側，產生布林遮罩
df[df['Category'] == 'Electronics']['Revenue'].mean()
```

### 讀 `describe()` 推形狀

```
mean = 223.41    50% = 128.55    max = 4500.00
       ↓
平均數約為中位數的 1.7 倍，且 max 遠離中位數
  ⇒ 右偏長尾且含離群值
  ⇒ 補缺失值改用 median()；若硬用 mean() 會把分佈整體右推並縮小變異
```

### 上億筆資料怎麼摘要

| 需求 | 單機做法 | 大數據做法 | 為什麼 |
|---|---|---|---|
| 分位數／中位數 | 全量排序後取位置 | **近似分位數**（t-digest、Greenwald-Khanna）；Spark `approxQuantile()` | 精確分位數要全域排序，成本極高；近似法**在可容忍誤差內**換取速度與記憶體，且適用於串流 |
| 標準差 | `np.std()` | `DataFrame.agg({'col': 'stddev'})` 或 `RDD.aggregate()` | 各 Executor 先在自己分區算出**局部統計量**（筆數、總和、平方和），再彙總成全域值；只掃一次資料、網路傳輸量極小 |

反面做法要能一眼認出：`collect()` 把十億筆拉回 Driver 幾乎必然 OOM；為了算標準差先做全域 `sortBy` 是白付一次昂貴的 shuffle（標準差根本不需要排序）；匯出 CSV 用 Excel 算則超過列數上限。

| 箱形圖判讀 | 三城市的盒長、鬚長、中位數位置組合判斷（115-1 #1） | 盒短鬚長＝中段集中但有極端值；**中位數偏下 = 右偏** |
| 長尾資料的視覺化 | IQR 極小但上鬚長、高金額多離群值，如何分層（114-2 #25） | 改**對數刻度**；刪離群值等於刪掉關鍵客群，等距分箱在偏態下失效 |
| 近似分位數 | 上億筆資料用 Approximate Quantile 的核心目的（114-2 #27） | **在可容忍誤差內快速估算**以支援即時分析；不是追求完全精確，也不是用 ML 預測 |
| 分散式統計 | Spark 上十億筆算標準差的正確策略（115-1 #21） | `agg({'col':'stddev'})` ／ `RDD.aggregate()`，局部統計量再彙總；不可 `collect()` |
| 由摘要決定補值 | mean 遠大於 median、max 極大，5% 缺失怎麼補（115-1 #41） | 右偏含離群值 → 用 **median** 補；用 mean 會右推分佈、用 max 是製造離群值 |
| Z 分數意義 | Z = 2 或 Z = −2 代表什麼（114-2 #1、115-1 #5） | 正負是方向、絕對值是幾個標準差；**Z = 2 不等於「必為離群值」**，要看門檻 |
| Z 分數計算 | 平均 2000、標準差 400、金額 3200，門檻 \|Z\| ≥ 3（114-2 #16） | (3200 − 2000) / 400 = 3，恰達門檻 → 標記為異常 |
| 相關係數選用 | 線性趨勢明顯、無離群值，量測關聯強度與方向（114-2 #30） | **Pearson**。共變異數受單位影響無法直接判強度，RMSE／MAE 是預測誤差指標 |
| 三種相關係數 | Pearson／Spearman／Kendall 的特性比較（115-1 #24） | 三者值域都在 [−1, 1]；Spearman 等於把值換成排名再代入 Pearson；**Kendall 比 Spearman 更穩健** |
| 偏態驅動的轉換 | Y 右偏且變異數隨 X 增大（114-2 #36） | **Box-Cox**，同時改善偏態與異質變異；標準化 X 解決不了 Y 的問題 |
| 厚尾風險建模 | 報酬率非對稱、多次極端損失（114-2 #33） | **分位數迴歸**；裁到 ±3σ 等於刪掉要評估的風險事件 |

**相鄰題可一併掃過**：114-2 第 9 題（有離群值時用 **Robust Scaling**，因為它以中位數與 IQR 為基準）、第 6 題（標準化是平均 0、標準差 1，**壓到 [0,1] 的是 Min-Max**）——這兩題主場在 L22201／L22301，但判斷依據全在本節。

## 28.8 易錯與陷阱

- [ ] `np.std()` 預設 `ddof=0`（除以 N，母體），**不是**除以 n−1；`pandas.Series.std()` 預設 `ddof=1`（除以 n−1，樣本）。同一批資料兩者數值不同（本節範例：28.27 vs 30.22）。
- [ ] IQR 涵蓋的是**中間 50%** 的資料，**不是**全部資料的範圍；涵蓋全部範圍、只用到最大與最小兩個點的是全距。
- [ ] 箱形圖的上鬚是「圍籬內最遠的實際資料點」，**不是**資料集的最大值；`Q3 + 1.5×IQR` 是**圍籬**位置，而非鬚端的資料值。
- [ ] 中位數貼近盒子**下緣**代表**右偏**（上半段被拉長），**不是**左偏。
- [ ] 右偏（正偏）的**長尾在右側、分佈主體在左側**，**不是**主體在右側。
- [ ] 「右偏 ⇒ 平均數 > 中位數」是**單峰連續分佈下的經驗法則**，**不是**放諸四海皆準的定理；離散或多峰資料可構造反例，題目附圖時以圖為準。
- [ ] 峰度基準要先確認定義：Pearson 定義下常態 = **3**，超額峰度（Fisher）下常態 = **0**。`scipy.stats.kurtosis()` 與 `pandas.Series.kurt()` 預設回傳**超額**峰度，值為 0 是代表接近常態，**不是**代表沒有峰態。
- [ ] Z-score 標準化讓平均 0、標準差 1，**不會**把數值壓進 [0, 1]；壓進 [0, 1] 的是 **Min-Max 正規化**。
- [ ] 標準化只做平移與縮放，偏度與峰度不變，**不是**「標準化之後資料就變成常態分佈」。
- [ ] Z = 2 表示**高於平均 2 個標準差**，**不是**原始值等於 2；是否判為離群值取決於設定的門檻——在 |Z| ≥ 3 的規則下 Z = 2 不算異常，在 |Z| ≥ 2 的規則下才算。
- [ ] 幾何平均適用於**連乘**型的成長率與報酬率，**不是**任何百分比資料都能套；調和平均適用於**同距離不同速率**，若是**同時間不同速率**該用算術平均。
- [ ] Robust Scaling 用**中位數與 IQR**，**不是**用平均數與標準差；後者是 Z-score 標準化。
- [ ] 右偏且含離群值的欄位，補值該用**中位數**，**不是**「數值型欄位一律用平均數補」，也**不是**「數值型欄位不能補值、只能刪列」。
- [ ] 近似分位數是**以可容忍誤差換取記憶體與速度**，**不是**用機器學習模型預測分位數位置，也**不是**只能對結構化資料做批次處理（它正好適用於串流）。
- [ ] 分散式算標準差要讓各 Executor 先算**局部統計量**再彙總，**不是**用 `collect()` 把資料搬回 Driver，也**不需要**先做全域排序。
- [ ] `describe()` 回傳 count／mean／std／min／25%／50%／75%／max，**不含**眾數、偏度、峰度；那三者要用 `.mode()`、`.skew()`、`.kurt()` 另外取。
- [ ] 四分位數的實際數值會隨**插值方法**而異（NumPy／pandas 預設 `linear`，Excel 的 `QUARTILE.INC` 與 `QUARTILE.EXC` 又各自不同），跨工具比對數字前先確認定義一致。
