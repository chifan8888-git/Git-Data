46.1

全景圖與選型決策樹

官方指引把演算法拆成監督式（迴歸＋分類）與非監督式（分群、降維、關聯規則、異常偵測）兩大塊。先看全景，再練「五步選型」。

官方指引的四個區塊（點區塊看成員）

五步選型精靈：照考場順序回答

每一步選一個條件，最後會得到建議演算法與「其他為什麼不行」。隨時可按「重來」。

展開五步選型的完整文字版

Step 1 有標籤嗎？有 → 監督式；無 → 非監督式。「只有正常樣本、沒有異常標註」→ 非監督／半監督異常偵測。

Step 2 輸出是什麼？連續數值 → 迴歸（房價、成交價、發電量、耗能）；離散類別 → 分類（是否購買、是否違約、垃圾信與否）；找群體 → 分群；降維度 → PCA／t-SNE／UMAP。

Step 3 線性還是非線性？近似線性、要係數可解釋 → 線性／邏輯迴歸；明顯非線性、有特徵交互 → 樹模型、集成樹、核 SVM。

Step 4 要哪一種「可解釋」？係數方向與大小 → 線性／邏輯迴歸（金融評分卡）；整體特徵重要性 → 隨機森林、GBDT；個案級解釋 → 樹模型＋SHAP／LIME。注意：SVR 的支援向量「不是」特徵重要性，這是官方誘答。

Step 5 資料規模與維度：小～中、維度高、邊界清楚 → SVM；中～大、混合型特徵 → 隨機森林、XGBoost／LightGBM；極大、需即時預測 → 樸素貝氏、線性模型；極大 → 避開 SVM／SVR（訓練成本隨樣本數平方成長）與階層式分群。

46.2

監督式學習（一）：迴歸家族

模型：y = β₀ + β₁x₁ + … + βₙxₙ + ε。β₀ 是截距，βᵢ 是各特徵的迴歸係數，ε 是誤差項。

線性迴歸的五個假設：看殘差圖認徵兆

官方常用「殘差圖」反過來問。點選每個假設，看違反時圖會長什麼樣（圖形為示意）。

殘差圖題型的標準解（114-2 第 24 題）：殘差在高值區出現系統性彎曲且誤差極大 → 結論是「存在離群值或非線性關係，違反迴歸假設」。不是過擬合（過擬合的徵兆是訓練好、測試差），也不是欠擬合。

評估指標一律是 MSE／RMSE／MAE／R²／調整後 R²。MSE 對誤差取平方，會讓離群值主導梯度更新；MAE 為線性懲罰、對離群值不敏感；Huber 損失則是小誤差用平方、大誤差轉線性。

正則化模擬器：Ridge 壓小、Lasso 歸零

拖動 λ，看五個係數怎麼變。（示意：假設特徵彼此正交時的解析解，原始係數為虛構值）

Ridge（L2：λ·Σβⱼ²）

λ 不能拍腦袋決定，必須用交叉驗證挑選。λ 過大 → 係數被壓過頭 → 欠擬合。兩者共通限制：仍然無法建模非線性關係。

SVR：用 ε-tube 換抗離群值

SVR 不最小化所有點的平方誤差，而是忽略落在 ε 容忍帶內的誤差，只懲罰帶外的點。拖動 ε 看看（資料為示意）。

三個關鍵超參數：C（懲罰參數）、ε（容忍帶寬）、核函數參數（RBF 核的 γ）。
優點：不需線性假設、不需誤差常態、對離群值有抵抗力。
限制：訓練時間與記憶體隨樣本數平方成長，不適合極大資料；用非線性核之後極難解釋。

決策樹迴歸：預測是「分段常數」

葉節點輸出該節點所有樣本目標值的平均數，所以預測曲線是一階一階的台階。加深樹看看會發生什麼（資料為示意，模型是真的在瀏覽器裡擬合）。

決策樹屬於非參數模型，不需要線性、常態、變異數齊一等假設，也對特徵尺度不敏感。缺點是單棵樹極易過擬合、對資料微小變動敏感（樹結構可能整個改變）；預測「不連續、會出現跳躍」也正是來自分段常數。

46.3

監督式學習（二）：分類家族

邏輯迴歸：名為迴歸，實為分類

p = 1 / (1 + e^-(β₀ + β₁x₁ + … + βₙxₙ))。拖動「線性部分 z」，看機率 p 與對數勝率 log(p/(1−p)) 的對應；再拖動門檻決定類別。

名稱裡的「迴歸」來自「特徵與對數勝率（Log-Odds）呈線性關係」這個假設：把 [0,1] 的機率透過 log(p/(1−p)) 轉成 (−∞,+∞) 的實數後，再用線性模型擬合。輸出套上門檻成為類別 → 它是分類演算法。
適用：二元分類、需要可解釋的場域（金融信用評分卡、醫療）。限制：無法捕捉複雜非線性邊界、對離群值敏感、多類別需擴展成 One-vs-Rest（OvR）或 Multinomial。評估：Accuracy／Precision／Recall／F1-score／ROC-AUC。

樸素貝氏：零機率問題與拉普拉斯平滑

P(C|X) = P(X|C)·P(C) / P(X)；「樸素」＝給定類別下特徵條件獨立，所以 P(X|C) 變成各字詞機率連乘。下面的詞頻是示意數字：垃圾信訓練集裡從沒出現過「會議」。

適用：文字分類（垃圾信過濾、情感分析、新聞分類）、大規模資料、即時預測、多類別、特徵數多。限制：特徵高度相關時失準；零機率問題須用拉普拉斯平滑；只能分類，不能做迴歸。
不需要特徵標準化——它算的是詞頻與機率，不是距離。把「做特徵縮放」當成樸素貝氏的改善方案是典型張冠李戴。

集成學習：Bagging 對 Boosting

Bagging
各基模型平行、獨立訓練，再投票／平均。
主要降低：變異（Variance）
代表：Random Forest
Boosting
各基模型序列訓練，後者修正前者的錯誤，加權求和。
主要降低：偏差（Bias）
代表：Gradient Boosting、XGBoost、LightGBM

一句話記法：Bagging 靠「各自獨立再平均」壓住震盪（變異）；Boosting 靠「一輪一輪補課」補足準度（偏差）。

非監督式學習（一）：分群

演算法需先指定群數？能處理非凸群集？會標記雜訊點？對離群值主要限制
K-Means需要（K）✗ 只適合球形／凸形✗敏感（質心是平均數）對初始質心敏感，只保證局部最優

分群實驗室：K-Means vs DBSCAN

先選資料形狀，再選演算法。試試「半月形」用 K-Means 會怎樣；多按幾次「重新初始化」看每次結果是否相同。（資料為隨機產生的示意點）

K-Means 的四個已知限制（115-1 第 15 題整段考過）

演算法步驟固定四步：初始化 K 個質心 → 把每點分配到最近質心 → 重算各群平均作為新質心 → 重複直到質心不再顯著移動或達最大迭代次數。

兩種常見誘答：「假設群集為高斯分佈」講的是高斯混合模型（GMM），不是 K-Means；「初始化不影響最終結果、演算法保證全域最優」直接說反了。「維度超過 10 就失效」是過度絕對的敘述——高維確實讓距離鑑別力下降，但沒有這種門檻。

階層式分群：在樹狀圖上橫切

樹狀圖（Dendrogram）可在任意高度橫切，取得不同粒度的分群 —— 這就是它「無須預先指定 K」的原因。拖動切割高度（合併高度為示意）。

凝聚式 Agglomerative
由下而上（bottom-up）：每個點自成一群 → 逐步合併最相似的兩群 → 最後合成一大群
分裂式 Divisive
由上而下（top-down）：全部一群 → 逐步分裂 → 最後每點自成一群

46.6

非監督式學習（二）：降維、關聯規則、異常偵測

PCA 流程：資料標準化 → 計算共變異數矩陣 → 特徵值分解 → 依特徵值由大到小選前 K 個特徵向量作為主成分 → 將資料投影到新空間。

PCA 解釋變異計算器（114-2 第 35 題）

解釋變異比例＝該主成分的特徵值 ÷ 所有特徵值總和。預設是考題數字 λ=6.0／3.0／1.0；拖動看看要保留幾個主成分才達 80%。

方法線性？保留的結構能投影新資料？主要用途
PCA線性全域最大變異方向，主成分彼此正交可（用既有主成分矩陣直接投影）降維、去冗餘、去噪、作為下游模型輸入
t-SNE非線性局部鄰域，不保留全域距離與尺度不可（無明確外推函數）只適合視覺化，不適合當模型輸入特徵
UMAP非線性局部＋全域兼顧支援增量學習視覺化；比 t-SNE 快，可處理更大資料

PCA 的限制：只能捕捉線性關係、主成分是原始特徵的線性組合而缺乏直觀解釋、對離群值敏感（會扭曲共變異數矩陣）。t-SNE 另有計算成本高、受隨機初始化影響（每次結果略有不同）、困惑度（Perplexity）需細調等缺點。

Apriori
核心是 Apriori 性質：「頻繁項集的所有非空子集必為頻繁；不頻繁項集的任何超集必不頻繁」，用來剪枝。

孤立森林：異常點幾刀就被孤立

隨機選特徵、隨機選分割點遞迴切分，直到目標點獨自一格。異常點少數幾刀就被孤立 → 平均路徑長度短 → 異常分數高。選一個目標點，按「切一刀」或直接跑 50 次比平均。

方法原理優勢限制
Isolation Forest隨機選特徵、隨機選分割點遞迴切分；異常點路徑短 → 異常分數高不需距離度量、高維與大資料高效、直接輸出異常分數便於排序與設閾值、對不平衡資料表現好異常點若緊貼正常群集則難偵測；結果受隨機性影響
One-Class SVM用核函數把只有正常資料映射到高維，找出能把正常樣本與原點最大程度分離的超平面；落在邊界外即判為異常可處理非線性邊界、高維表現好、只需正常資料即可訓練對核參數與異常率參數高度敏感、計算成本高、訓練資料若混入異常會汙染邊界

另有基於局部密度比較的 LOF（Local Outlier Factor）：比較一個點與其鄰居的局部密度，密度明顯偏低者判為離群。官方學習指引未列入，僅作對照認識；考場上遇到「只有正常資料」的題幹，優先想 Isolation Forest 與 One-Class SVM。
