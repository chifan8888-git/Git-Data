## 42.1 資料與隨機變數的機率表示

### 機器學習的機率本質

官方指引開宗明義：機器學習模型學的不是唯一解，而是**條件機率分佈** P(Y|X)——X 是輸入特徵（Feature），Y 是目標變數（Label）。

```
確定性思維                    機率思維（中級要求）
─────────────                 ─────────────────────
「這封信是垃圾郵件」    →     「P(垃圾|詞彙組合) = 0.93」
輸出：類別                     輸出：分佈 + 信心程度
用途：直接判斷                 用途：可調門檻、可做風險控管
```

兩層意涵：**預測導向**（輸出機率而非硬類別）與**不確定性評估**（機率反映模型信心，支撐風險控制與決策）。這也是為什麼分類題常出現「調整決策門檻」的選項——有機率輸出，門檻才調得動。

### 離散型 vs 連續型

| 維度 | 離散型（Discrete） | 連續型（Continuous） |
|---|---|---|
| 取值 | 有限或可數（骰子點數、每日訂單數） | 無限不可數（身高、等待時間、溫度） |
| 描述工具 | **機率質量函數 PMF** | **機率密度函數 PDF** |
| 意義 | P(X = xᵢ)，**單點就有機率** | 面積才是機率，**單點機率為 0** |
| 歸一條件 | ΣP(X = xᵢ) = 1 | ∫f(x)dx = 1（全域） |
| 區間機率 | 逐點相加 | P(a ≤ X ≤ b) = ∫ᵃᵇ f(x)dx |

**高頻陷阱：PDF 的函數值不是機率，可以大於 1。** 只有積分出來的面積才是機率。看到「PDF 直接給出某個取值的機率」這種敘述就排除。

### 常見分佈速查表（背熟 E 與 Var 這兩欄）

| 分佈 | 型態 | 描述什麼 | 期望值 E(X) | 變異數 Var(X) | ML 中的角色 |
|---|---|---|---|---|---|
| **伯努利** Bernoulli(p) | 離散 | 單次二元試驗（成功／失敗、點擊／未點擊） | p | p(1−p) | **邏輯迴歸的目標變數假設** |
| **二項** Binomial(n, p) | 離散 | n 次獨立試驗中成功的**次數** | np | np(1−p) | A/B 測試轉換數 |
| **卜瓦松** Poisson(λ) | 離散 | 固定時間／空間內事件發生**次數**（稀有事件） | **λ** | **λ** | 客服來電數、伺服器請求數 |
| **均勻** Uniform(a, b) | 連續 | 區間內等機率 | (a+b)/2 | (b−a)²/12 | 參數初始化、隨機抽樣 |
| **常態** Normal(μ, σ²) | 連續 | 對稱鐘形 | μ | σ² | **線性迴歸的誤差項假設**、標準化 |
| **指數** Exponential(λ) | 連續 | 事件**間隔時間**／等待時間 | 1/λ | 1/λ² | 故障時間、來電間隔；**無記憶性** |
| **卡方** Chi-square(k) | 連續 | k 個獨立標準常態變數的**平方和** | k | 2k | 卡方檢定、列聯表獨立性 |

**三組最常被混淆的配對：**

- **卜瓦松 vs 指數**：同一個隨機過程的兩面。卜瓦松數「單位時間內發生幾次」（離散），指數量「兩次之間隔多久」（連續）。題幹出現「每小時平均幾件」走卜瓦松，「平均等待多久」走指數。
- **二項 vs 卜瓦松**：二項有明確的試驗次數 n 與固定機率 p；卜瓦松沒有 n，只有平均發生率 λ，用於「次數無上限的稀有事件」。
- **卜瓦松的 E = Var = λ**：這是常考分佈中唯一期望值等於變異數的，也最容易被單獨拉出來問。實務上若觀測到 Var 遠大於 E，稱為過度離散（Overdispersion），代表卜瓦松假設不成立。

### 分佈是「對資料生成機制的先驗假設」

| 模型 | 隱含的分佈假設 | 違反時會怎樣 |
|---|---|---|
| 邏輯迴歸（Logistic Regression） | 目標變數服從伯努利分佈 | 多類別需改用 Softmax／多項分佈 |
| 線性迴歸（Linear Regression） | **誤差項**服從常態分佈、等變異 | 係數標準誤與顯著性檢定失真（見 42.4 殘差診斷） |
| 樸素貝氏（Naive Bayes） | 特徵在給定類別下條件獨立 | 高度相關的特徵會被重複計票 |
| 變分自編碼器（VAE） | 潛在變數服從指定的先驗分佈 | 生成品質與潛在空間結構劣化 |

注意：線性迴歸假設的是**誤差項**常態，不是「特徵必須常態」，也不是「目標變數必須常態」。這是選項裡最常見的偷換。

## 42.2 條件機率與貝氏推論

### 條件機率：分母永遠是「條件事件」

```
P(A | B) = P(A ∩ B) / P(B)
                        ↑
              分母是「給定的那個條件」B，不是 A
```

讀法：「在 B 已經發生的前提下，A 發生的機率」。把樣本空間從「全部」縮小成「只有 B 的那塊」，再看 A 佔多少比例。

**Monte Carlo 模擬題的標準寫法（114Q2 第 41 題原型）：**

```python
import numpy as np

rolls = np.random.randint(1, 7, size=100000)   # 擲骰子模擬
A = (rolls % 2 == 0)          # 事件 A：擲出偶數 → {2, 4, 6}
B = (rolls > 3)               # 事件 B：擲出大於 3 → {4, 5, 6}
A_and_B = A & B               # A ∩ B → {4, 6}

p_A_given_B = A_and_B.sum() / B.sum()   # ✔ 正解：分母是 B
# A_and_B.sum() / A.sum()               # ✘ 這是 P(B|A)
# A_and_B.sum() / (A.sum() * B.sum())   # ✘ 相乘沒有機率意義
# A_and_B.sum() / (A.sum() + B.sum())   # ✘ 相加沒有機率意義
```

**這題的狠處在於：以公正骰子計算，P(A|B) = 2/3，而 P(B|A) 也剛好等於 2/3。** 你沒辦法靠代數字驗算來排除誘答，只能靠定義判斷分母該放誰。所以答題時務必先把 P(A|B) 的 A、B 對號入座，再看程式碼分母是哪個布林陣列的 `.sum()`。

四種應用場景（官方指引點名）：分類任務的 P(Y|X) 條件預測、生醫與金融風控的風險預估、生成模型（VAE、隱馬可夫模型 HMM）中潛在變數與觀察變數的依存建構。

### 貝氏定理：四個元素一個都不能錯位

```
              P(B|A) · P(A)
P(A|B)  =  ───────────────────
                   P(B)

後驗 Posterior = 似然 Likelihood × 先驗 Prior ÷ 邊際 Marginal
```

| 元素 | 名稱 | 中級定義（官方用語） |
|---|---|---|
| P(A) | **先驗機率** Prior | 尚未觀察 B 之前，對 A 的初始信念 |
| P(B\|A) | **似然** Likelihood（條件機率） | 在 A 成立的前提下，觀察到 B 的可能性 |
| P(B) | **邊際機率** Marginal | B 發生的整體機率＝ΣP(B\|Aᵢ)P(Aᵢ)（全機率定理） |
| P(A\|B) | **後驗機率** Posterior | 看到 B 之後重新估計的 A 機率；**這是貝氏定理的輸出** |

**數值感受（基本率謬誤 Base Rate Fallacy）：** 某疾病盛行率 1%，檢驗靈敏度 99%，偽陽性率 5%。檢驗呈陽性時真的患病的機率是多少？

```
P(病|陽) = (0.99 × 0.01) / (0.99 × 0.01 + 0.05 × 0.99)
         = 0.0099 / 0.0594
         ≈ 16.7%      ← 不是 99%
```

靈敏度再高，只要先驗（盛行率）很低，後驗仍然偏低。這解釋了為什麼極度不平衡資料上「準確率 99%」毫無意義，也是類別不平衡章節的機率根源。

### 樸素貝氏與先驗的實務陷阱（115Q1 第 14 題）

樸素貝氏分類器以訓練資料估計**類別條件機率** P(詞|類別)。若「限時優惠」「立即下單享折扣」這些詞在訓練集幾乎只出現在垃圾信中，其類別條件機率自然偏向垃圾類，正常促銷信就被誤判。

| 錯誤診斷 | 為什麼錯 |
|---|---|
| 「改用更先進演算法」 | 沒回應成因；樸素貝氏在文字分類仍很有效 |
| 「過擬合，增加 Epoch」 | 樸素貝氏是一次性機率估計，**沒有 Epoch 的概念** |
| 「未做特徵標準化」 | 樸素貝氏處理詞頻與機率，**不需要特徵縮放**（張冠李戴） |
| ✔ **類別條件機率受訓練資料分佈影響** | 對策：補足正常促銷信樣本、重新平衡資料、調整先驗機率 |

另外記住：Naive Bayes 的「Naive（樸素）」指的是**特徵之間條件獨立的假設**，不是指模型簡單或不準。

### 蒙地卡羅方法：無法解析求解時的隨機抽樣

| 技術 | 何時用 | 題幹關鍵字 |
|---|---|---|
| **蒙地卡羅法**（Monte Carlo） | 模型太複雜、**無法求得解析解**，需以大量隨機抽樣逼近機率分佈或數值結果 | 「隨機模擬大量情境」「估計損失分佈」「風險區間」 |
| **貝氏推論**（Bayesian Inference） | 有明確先驗，要用新資料更新後驗 | 「先驗」「更新信念」「後驗」 |
| **馬可夫鏈**（Markov Chain） | 描述狀態之間的轉移機率結構 | 「狀態」「轉移矩陣」 |
| **梯度下降**（Gradient Descent） | 迭代調參最小化損失函數 | 「學習率」「收斂」 |

官方兩次都考這條分界（114Q2-23 太陽能發電量風險區間、115Q1-1 投資組合風險值），正解都是蒙地卡羅。**判準：題幹有沒有出現「先驗／後驗」？沒有就不是貝氏推論；有「隨機抽樣模擬大量情境」就是蒙地卡羅。**

## 42.3 假設檢定與統計推論

### 統計推論的兩大分支（官方對照表）

| 項目 | 參數估計（Parameter Estimation） | 假設檢定（Hypothesis Testing） |
|---|---|---|
| 目的 | 推測母體參數的「值」或「區間」 | 驗證關於母體參數的「主張」是否成立 |
| 問題型態 | 這個參數大約是多少？ | 是否有足夠證據拒絕某個假設？ |
| 輸出 | 點估計值＋信賴區間（如 95% CI） | 檢定統計量＋p 值，對照 α 做決策 |
| 例子 | 平均體重估計 68 公斤，95% CI = [66, 70] | p = 0.03 < α = 0.05，拒絕虛無假設 |

### 假設檢定五步驟

```
A. 設定虛無假設 H₀ 與對立假設 H₁
B. 選擇適當的檢定方法與檢定統計量
C. 決定顯著水準 α（事前決定，不能看完資料才改）
D. 計算檢定統計量與 p 值
E. 比較 p 值與 α → 決策
      p ≤ α  → 拒絕 H₀（結果「統計上顯著」）
      p > α  → 不拒絕 H₀（注意：是「證據不足」，不是「證明 H₀ 為真」）
```

### α、p 值與兩型錯誤

| 概念 | 定義 | 常見誤解（選項最愛的寫法） |
|---|---|---|
| **顯著水準 α** | **事前**設定的型一錯誤機率上限（常用 0.05） | 誤說成「結論正確的機率」 |
| **p 值** | 在 H₀ 為真的前提下，**觀察到目前或更極端結果**的機率 | 誤說成「H₀ 為真的機率」或「效果大小」 |
| **型一錯誤（Type I）** | H₀ 為真卻被拒絕＝**偽陽性**，機率＝α | 與型二錯誤方向搞反 |
| **型二錯誤（Type II）** | H₀ 為假卻未被拒絕＝**偽陰性**，機率＝β | — |
| **檢定力 Power** | 1 − β，正確拒絕假 H₀ 的能力 | 誤以為與 α 無關（把 α 訂得更嚴會犧牲檢定力） |

**p 值小 ≠ 效果大。** 樣本數夠大時，微不足道的差異也能做出 p < 0.05。中級題會用「統計顯著但商業上無意義」的情境來考這一點。

### 常見檢定方法用途對照（誘答池就是這張表）

| 檢定 | 用途 | 典型 ML 場景 |
|---|---|---|
| **單樣本 t 檢定** | 樣本平均 vs 已知標準值 | 模型平均延遲是否達 SLA |
| **配對樣本 t 檢定**（Paired t-test） | 兩**相關**組別的平均差異 | 兩模型在**同一批 CV 折**上的成對表現比較 |
| **獨立樣本 t 檢定** | 兩獨立組別的平均差異 | A/B 測試兩群使用者 |
| **F 檢定 / ANOVA** | 比較變異數；迴歸整體顯著性；三組以上平均 | 迴歸模型整體檢定、多組比較 |
| **卡方檢定**（Chi-square） | **類別變數**間的關聯性、適合度檢定 | 類別特徵與標籤是否獨立（特徵選擇） |
| **Shapiro-Wilk／K-S 檢定** | 常態性檢定 | 殘差是否符合常態假設 |

**114Q2 第 1 題的關鍵切分：** 想評估模型「在未觀察資料上的泛化能力與表現穩定性」，答案是**交叉驗證（Cross-Validation）**，不是任何一種假設檢定。F 檢定、配對 t 檢定、卡方檢定都屬統計假設檢定，處理的是「參數主張是否成立」，不是「模型對新資料的適應能力」。配對 t 檢定可以拿來比較**兩個模型**的成對差異，但不能用來衡量**單一模型**的泛化能力——這條界線務必分清。

### 中央極限定理與大數法則

| 定理 | 說什麼 | 常考陷阱 |
|---|---|---|
| **大數法則**（LLN） | 樣本數越多，**樣本平均**越接近母體平均 | 與 CLT 混用 |
| **中央極限定理**（CLT） | n 夠大時，**樣本平均數的抽樣分佈**趨近常態，**與母體原本是什麼分佈無關** | 誤以為「原始資料會變常態」 |
| **標準誤**（Standard Error） | SE = σ/√n，是**樣本平均數**的標準差 | 與資料本身的標準差 σ 混淆 |

CLT 是信賴區間與 t 檢定能成立的理論基礎，也解釋了為什麼樣本數要增加四倍，誤差區間才縮一半（√n 效應）。**它描述的對象是統計量（平均數），不是原始觀測值。**

## 42.4 統計量與機器學習中的應用

### 五個核心統計量

| 統計量 | 衡量什麼 | 單位 | ML 中的用途 |
|---|---|---|---|
| **期望值** E(X) | 平均趨勢；離散型 E(X) = Σxᵢ·P(xᵢ) | **與原資料相同** | 預測基準、迴歸截距項 |
| **變異數** Var(X) | 離散程度＝E[(X−μ)²] | **原單位的平方** | 判斷是否需標準化；偏差-變異拆解 |
| **標準差** SD(X) | √Var(X) | **與原資料相同** | 與平均數同尺度比較、z-score 的分母 |
| **偏態** Skewness | 分佈是否對稱 | 無單位 | 決定是否做對數／Box-Cox 轉換 |
| **峰度** Kurtosis | 是否尖峰厚尾 | 無單位 | 離群值密度與風險擴散的參考 |

**單位陷阱（必考）：** 若身高單位是公分，變異數的單位是**平方公分**，標準差才是**公分**。所以要跟平均數放在一起討論離散程度、或畫在同一張圖上時，用的是標準差而不是變異數。選項若寫「變異數與原資料同單位」就是錯的。

### 標準化（Z-score）與縮放的分界

```python
X_train -= X_train.mean(axis=0)   # 各特徵平均 → 0
X_train /= X_train.std(axis=0)    # 各特徵標準差 → 1
```

114Q2 第 48 題把四種錯誤說法一次擺出來，逐條記：

| 敘述 | 對錯 | 理由 |
|---|---|---|
| 減去平均後各特徵平均為 0 | ✔ | z-score 第一步 |
| 標準化有助穩定梯度、避免梯度爆炸或消失 | ✔ | 尺度一致化的主要效益 |
| 除以標準差是把標準差調為 **0** | ✘ | 是調為 **1** |
| 標準化會把資料壓到 0～1 之間 | ✘ | 那是 Min-Max 正規化；z-score **有負值也無上界** |
| 標準化屬於特徵選擇（Feature Selection） | ✘ | 屬於**特徵縮放**（Feature Scaling） |

延伸（115Q1 第 46 題）：影像除以 255.0 只是線性縮放到 0～1，**不等於 z-score 標準化**；z-score 必須減平均再除標準差。

### 偏態處理：轉換不是越多越好（115Q1 第 25 題）

| 情況 | 該做什麼 | 為什麼 |
|---|---|---|
| 特徵嚴重**右偏**（長尾在右，如距離、金額） | 對數（Log）或 Box-Cox 轉換 | 壓縮長尾、把乘性關係轉成加性關係，貼近線性假設 |
| 特徵原本就與目標近似**線性**（如屋齡） | **不要**轉換 | Log 會把線性結構扭曲成非線性，表現反而下降 |
| 有離群值但要保留樣本 | Robust Scaling（用中位數與 IQR） | 不被極端值拉偏 |

正解邏輯：**轉換要依各特徵自己的分佈個別判斷**，不是整張表套同一招；尺度差異另以標準化處理即可。

### 殘差診斷：三種圖形三種病

| 殘差圖樣態 | 診斷 | 正確術語 |
|---|---|---|
| 隨預測值增大呈**喇叭狀擴散** | 誤差變異數不是常數 | **異質變異數**（Heteroscedasticity），違反等變異假設（115Q1-5） |
| 出現**系統性彎曲**、高值區殘差極大 | 存在離群值或非線性關係 | 違反線性假設（114Q2-24） |
| 依觀測**順序**呈現週期或趨勢 | 殘差彼此相關 | **自相關**（Autocorrelation），常見於時間序列 |
| 隨機散佈無結構 | 假設成立 | 模型 OK |

注意分工：**常態性看 Q-Q 圖或殘差直方圖**，不是看擴散型態；**多元共線性用 VIF 或相關矩陣**診斷，殘差圖看不出來。異質變異數的實際危害是「係數的標準誤與顯著性檢定失真」——又繞回 42.3 的假設檢定。

### 統計量在模型評估中的兩個高頻讀數

| 指標 | 正確解讀 | 誘答 |
|---|---|---|
| **R²（決定係數）= 0.85** | 應變數總變異中有 **85% 可被模型解釋** | 「準確率 85%」「誤差 15%」「信心水準 85%」全錯 |
| **PCA 特徵值 λ = 6, 3, 1** | 總變異 = 10；PC1 解釋 60%，前兩者合計 **90%**，已過 80% 門檻可降至二維 | 「三者差不多所以不能降維」「只留一維即可」 |

**視覺化工具對照：** 直方圖看分佈形狀與偏態、箱型圖看中位數與離群值（IQR 1.5 倍法則）、Q-Q plot 看常態性、殘差圖看迴歸假設。官方指引明確把這組視覺化列為統計量的輔助解釋工具。

## 42.6 易錯與陷阱

- [ ] **條件機率的分母是「條件事件」** —— P(A|B) 的分母是 P(B)。Monte Carlo 題把分母換成 `A.sum()` 求到的是 P(B|A)；而且公正骰子那題兩者數值剛好都是 2/3，**代數字驗算救不了你**，只能靠定義。
- [ ] **卜瓦松的期望值等於變異數等於 λ** —— 二項是 E = np、Var = np(1−p)，兩者不相等，別混。
- [ ] **變異數的單位是原單位的平方，標準差才與原資料同單位** —— 要與平均數並列討論離散程度時用標準差。
- [ ] **卜瓦松數「次數」、指數量「間隔時間」** —— 同一個過程的兩面；題幹問「每小時幾件」走卜瓦松，「平均等多久」走指數（且指數具無記憶性）。
- [ ] **PDF 的函數值不是機率，可以大於 1** —— 連續型只有面積（積分）才是機率，單點機率為 0；PMF 才是單點就有機率。
- [ ] **中央極限定理講的是「樣本平均數」的分佈趨近常態，不是原始資料變常態** —— 而且**在母體變異數有限的前提下**與母體原本是什麼分佈無關（柯西分佈變異數不存在，是課本級的反例）。
- [ ] **p 值不是「虛無假設為真的機率」** —— 它是「在 H₀ 為真的前提下，看到目前或更極端結果的機率」；p 值小也不等於效果大。
- [ ] **α 是型一錯誤（偽陽性）機率的上限，且必須事前設定** —— 看完 p 值再改 α 是統計上的作弊。
- [ ] **交叉驗證不是假設檢定** —— 要評估「對未見資料的泛化能力」一律選交叉驗證；F／t／卡方檢定回答的是參數主張。
- [ ] **配對 t 檢定比較的是兩個相關組別（兩模型在同一批折上）** —— 不能拿來衡量單一模型的泛化能力。
- [ ] **卡方檢定處理類別變數的關聯，t 檢定處理平均數，F 檢定處理變異數與迴歸整體顯著性** —— 三者被大量互換當誘答。
- [ ] **Naive Bayes 的「Naive」是特徵條件獨立假設** —— 不是「模型簡單」；它也沒有 Epoch，更不需要特徵標準化。
- [ ] **蒙地卡羅是隨機抽樣逼近，貝氏推論是先驗更新後驗** —— 題幹沒提到先驗／後驗就不要選貝氏推論。
- [ ] **z-score 標準化把標準差調為 1（不是 0），且不會壓到 0～1** —— 壓到 0～1 是 Min-Max 正規化；除以 255 也只是線性縮放，不是標準化。
- [ ] **標準化屬於特徵縮放（Feature Scaling），不是特徵選擇（Feature Selection）** —— 這組中文只差一個字，選項最愛換。
- [ ] **殘差喇叭狀擴散＝異質變異數；系統性彎曲＝非線性或離群值；依順序呈週期＝自相關** —— 常態性請改看 Q-Q 圖，共線性請改看 VIF。
- [ ] **線性迴歸假設的是「誤差項」常態，不是特徵或目標變數必須常態。**
- [ ] **R² 是「被解釋的變異比例」，不是準確率、誤差率或信心水準。**
- [ ] **Log 轉換是為了修正右偏，不是萬用招** —— 原本就線性的特徵取對數會破壞結構，轉換要逐特徵決定。
- [ ] **先驗機率低時，再高的靈敏度也撐不起後驗** —— 基本率謬誤，也是不平衡資料上「準確率 99%」無意義的機率根源。
