> 一句話定位：初級的 L112 只要求你認得「缺失值要補、類別要編碼、數值要縮放」這些名詞；中級則要求你在情境題裡判斷**這個步驟該用哪一種、放在流程的哪個位置**—— 而「位置放錯」正是本知識點最致命也最常考的失分點：**資料洩漏（Data Leakage）**。

## 48.1 資料清理

### 缺失值處理：五種手段與適用條件

| 方法 | 做法 | 適用條件 | 副作用 |
|---|---|---|---|
| **刪除法（Deletion）** | 直接丟掉含缺值的列或欄 | 缺失比例極低、樣本充足、缺失分佈無偏 | 缺失若有系統性（非隨機），刪除就等於製造取樣偏差 |
| **統計量填補** | 均值／中位數／眾數 | 快速基線；偏態資料用中位數優於均值 | **壓縮變異數**，人為拉高集中趨勢 |
| **相似樣本填補** | Hot Deck、KNN Imputer | 特徵間有鄰近結構 | 需先做尺度調整，否則距離被大數值欄位主導 |
| **預測模型填補** | 用迴歸／分類模型預測缺值 | 特徵間高度相關 | 最容易夾帶洩漏：若拿目標變數去填補特徵，就是目標洩漏 |
| **缺失指標編碼** | 新增 `is_missing` 欄位 | 缺失本身帶訊息（沒填收入 vs 收入為 0） | 增加維度；對樹模型效益最明顯 |

**模型對缺值的容忍度不一樣，這點官方考過：**

```
樹模型（XGBoost、LightGBM、Random Forest）
  → XGBoost 原生支援缺失值：訓練時為每個分裂學一個「預設方向」，
    缺值樣本直接走預設分支，不必事先填補
  → 114Q2 第 18 題正解就把「支援缺失值自動處理」列為 XGBoost 相對 GBDT 的改進之一

線性模型 / SVM / KNN / 神經網路
  → 不接受 NaN，必須填補；且對填補品質與尺度都敏感
```

### 異常值偵測與處理

| 層次 | 手段 | 判準／說明 |
|---|---|---|
| **統計法** | Z 分數（Z-score） | 常見取 \|z\| > 3；前提是資料近似常態 |
| | 四分位距（IQR） | 落在 Q1 − 1.5×IQR 與 Q3 + 1.5×IQR 之外 |
| **視覺化** | 箱型圖、散佈圖、殘差圖 | 迴歸的殘差圖是高頻考點，見下方 |
| **機器學習法** | Isolation Forest、LOF、One-Class SVM、自編碼器重建誤差 | 適合高維、無標註的場景 |

**處理策略三選一：**

| 策略 | 何時採用 |
|---|---|
| **移除** | 可確認是輸入錯誤（年齡 256 歲、負數金額） |
| **截尾（Winsorize）或轉換** | 值本身合理但尾巴太長 → 限制在上下界內，或取對數／Box-Cox |
| **標記保留** | 異常值本身就是預測目標時（詐欺偵測、AOI 瑕疵、設備故障）——**刪掉等於刪掉答案** |

> **殘差圖的兩個經典判讀（各考一題）：**
> - 殘差在高值區出現**系統性彎曲**、少數點誤差極大 → **異常值或非線性關係**，違反迴歸假設（114Q2 第 24 題正解）。誘答「過度擬合」不對，過擬合的症狀是訓練好、測試差，不是殘差呈結構性偏差。
> - 殘差隨預測值增大而**呈喇叭狀擴散** → **異質變異數（Heteroscedasticity）**，等變異假設被違反（115Q1 第 5 題正解）。這題的誘答「特徵高度相關」是多重共線性，要用 VIF 診斷，殘差圖看不出來。

### 重複樣本、一致性與型別轉換

- **重複偵測**：主鍵比對或欄位相似度；重複樣本會讓特定樣本在訓練時被加權放大。
- **單位與格式標準化**：公克 vs 公斤、`2026/3/14` vs `2026-03-14`、`male` vs `男`。
- **型別轉換**：數值型與類別型要正確標示，否則後續編碼與縮放全錯。
- **資料血緣（Data Lineage）**：每個清理動作（填補方法、異常值判準、欄位邏輯）都要留紀錄，才能重現、稽核與符合治理要求。這是中級才強調的治理面，初級不考。

## 48.2 特徵選擇與降維

### 先分清楚：選擇 ≠ 降維

```
特徵選擇 Feature Selection
  從 200 個原始欄位中「挑出」30 個
  → 保留的是原始欄位，可解釋性完整（審查單位看得懂「月收入」）

降維 Dimensionality Reduction
  把 200 個欄位「壓成」30 個新座標軸
  → 新軸是原始欄位的線性（或非線性）組合，不再對應任何業務意義
```

### 特徵選擇三大類

| 類型 | 代表方法 | 是否需要訓練模型 | 優點 | 限制 |
|---|---|---|---|---|
| **Filter（過濾法）** | 皮爾森相關係數、卡方檢定、ANOVA、互資訊 | 否 | 速度快、與模型無關 | **無法考慮特徵間交互作用** |
| **Wrapper（包裝法）** | 遞迴特徵消除（RFE）、前向／後向選擇 | 是，反覆訓練 | 精確考量特徵互動 | 計算成本高、**容易過擬合** |
| **Embedded（嵌入法）** | Lasso（L1）、決策樹／隨機森林特徵重要性、資訊增益 | 是，一次訓練即完成 | 建模與選擇同時完成 | 受模型與超參數影響 |

**Embedded 法是官方最愛考的一類，考了四題：**

- **114Q2 第 2 題／第 32 題**：L1 正則化（Lasso）在損失函數加上**權重絕對值**懲罰，會把不重要特徵的係數壓成 **0**，產生稀疏模型 → 達成自動特徵選擇。L2（Ridge）只把權重**同步縮小但不歸零**，保留全部特徵。
- **114Q2 第 8 題**：資訊增益（Information Gain）以熵的下降量衡量特徵貢獻，是**決策樹**在每個節點挑分裂特徵的依據 —— 不是 L1、不是核函數 SVM、不是深度網路。
- **115Q1 第 33 題**：150 個特徵、高度共線（建坪 vs 總面積），要求「控制過擬合、共線性下穩定、**不讓任何係數歸零**」→ 正解是 **Ridge（L2）**。Elastic Net 含 L1 成分仍會歸零，不符。
- **115Q1 第 7 題**：同樣是共線特徵（月收入／年收入／季收入），但問的是**為什麼每次重訓的重要特徵清單都在跳動** → 正解是 **L1 的稀疏性**：三個高度相關的特徵留哪一個都能把損失壓到相近水準，留誰受抽樣與初始化影響。

> **這兩題放在一起看就是完整的對照：L1 幫你挑特徵但不穩定；L2 不挑特徵但穩定。**

### 降維方法對照

| 方法 | 線性？ | 用到標籤？ | 可轉換新資料？ | 典型用途 | 上限 |
|---|---|---|---|---|---|
| **PCA（主成分分析）** | 線性 | 否（無監督） | 可（用既有主成分矩陣投影） | 視覺化、雜訊過濾、建模加速 | 最多 min(樣本數, 特徵數) |
| **LDA（線性判別分析）** | 線性 | **是（監督式）** | 可 | 分類前降維，最大化類間／類內變異比 | **最多「類別數 − 1」維** |
| **t-SNE** | 非線性 | 否 | **不可**（無外推函數） | **只用於視覺化探索** | 2～3 維 |
| **UMAP** | 非線性 | 可選 | 可 | 視覺化為主 | — |
| **SVD（奇異值分解）** | 線性 | 否 | 可 | 文字分析（LSA）、推薦系統 | — |

**115Q1 第 6 題整題就是這張表：** 512 維詞嵌入要視覺化 → t-SNE；200 個製程特徵要當 XGBoost 輸入 → PCA。正解是「t-SNE 保留**局部鄰域**結構適合視覺化，但不保留全局結構，**不適合作為模型輸入特徵**」。三個誘答分別把 t-SNE 說成保留全局線性（顛倒）、把 PCA 說成非線性（錯）、說兩者都可對新資料線性外推（t-SNE 做不到）。

**PCA 的兩個計算型考法：**

```
解釋變異量（114Q2 第 35 題）
  特徵值 λ1=6.0, λ2=3.0, λ3=1.0，總變異量 = 10
  PC1 = 6/10 = 60%
  PC1+PC2 = 9/10 = 90%  ← 已超過 80% 門檻，可安全降到二維
  第三主成分僅 10%，可捨

PCA 降噪（114Q2 第 46 題）
  降噪的關鍵在 n_components 設得夠低：
  保留主要變異方向、把雜訊留在被丟棄的成分裡，再 inverse_transform 重建
  若 n_components 設太高（等於全部保留），重建後雜訊原封不動 → 完全沒降噪
```

## 48.3 特徵轉換與資料標準化

### 尺度調整三選一

| 方法 | 公式 | 輸出 | 對離群值 | 適用情境 |
|---|---|---|---|---|
| **Min-Max Normalization** | (x − min) / (max − min) | [0, 1] | **極敏感**（一個極端值會把其餘全部壓扁） | 分佈有界、需要固定範圍（影像像素、部分神經網路輸入） |
| **Z-score Standardization** | (x − μ) / σ | 均值 0、標準差 1（**不是 0～1**） | 敏感 | 近似常態的資料；線性模型、SVM、PCA 的標準搭配 |
| **Robust Scaling** | (x − 中位數) / IQR | 不固定 | **抵抗力最強** | **分佈偏態或含離群值時的首選** |

> **「有離群值 → Robust Scaling」是可以直接反射的配對。** Min-Max 與 Z-score 都用到會被極端值污染的統計量（min／max／μ／σ），Robust Scaling 改用中位數與 IQR，天生不受尾端影響。代價是轉換後不保證符合任何標準分佈。

### 哪些模型需要縮放？

| 一定要縮放 | 不需要縮放 |
|---|---|
| KNN、SVM、K-means（**距離導向**） | 決策樹、隨機森林、XGBoost／LightGBM（**分裂是比大小，與單位無關**） |
| 線性／邏輯迴歸（尤其加了正則化時，懲罰項對尺度敏感） | 樸素貝氏（處理的是詞頻與機率） |
| PCA、LDA（變異量會被大量級欄位主導） | |
| 神經網路（穩定梯度、加速收斂） | |

**114Q2 第 9 題**直接考這個：建構 KNN、SVM 這類距離型模型時，**最關鍵**的前處理是**特徵縮放**。誘答「缺失值補齊」「平衡資料筆數」雖然也有幫助，但不是距離型模型的**核心**需求。
**115Q1 第 14 題**則是反面：樸素貝氏誤判促銷信，原因是類別條件機率受訓練分佈影響，不是「未做特徵標準化」—— 樸素貝氏根本不需要標準化。

**114Q2 第 48 題與 115Q1 第 46 題考同一組觀念的兩面，務必分清楚：**

```python
# 114Q2-48：這是 Z-score 標準化
X_train -= X_train.mean(axis=0)   # 各特徵均值調成 0        ✔
X_train /= X_train.std(axis=0)    # 各特徵標準差調成 1（不是 0！）
# 正確敘述：均值變 0、有助穩定梯度避免梯度爆炸/消失
# 錯誤敘述：「壓縮到 0 和 1 之間」（那是 Min-Max）
#           「標準化屬於特徵選擇」（標準化是特徵縮放，不是選擇）

# 115Q1-46：這是線性縮放，不是 Z-score
x_train = x_train / 255.0         # 像素 0~255 → 0~1，上界是 1 不是 31
# 除以固定常數 ≠ z-score（z-score 必須減平均再除以標準差）
y_train = to_categorical(y_train, 10)   # 整數標籤 → 10 維獨熱編碼
# 獨熱標籤 → 輸出層 softmax + categorical_crossentropy
```

### 分佈轉換

| 轉換 | 適用 | 限制 |
|---|---|---|
| **對數（Log）** | 右偏長尾（收入、銷售額、距離） | 只能用於正值；把乘性關係轉成加性 |
| **平方根／立方根** | 中度偏態 | 壓縮較溫和 |
| **Box-Cox** | 自動找最適指數 λ | **只能用於正值**；λ 是估出來的參數 |
| **Yeo-Johnson** | 同上，但**可含 0 與負值** | — |

**115Q1 第 25 題是這一節最需要理解而非背誦的一題：** 距捷運站距離嚴重右偏，取 log 後模型改善；同樣的 log 套到屋齡卻變差。正解是「**屋齡與房價若原本就呈線性關係，Log 轉換反而破壞此結構**」。

> **記憶點：轉換要依「每個特徵自己的分佈」個別決定，不是全表一起套。** 誘答「兩特徵須套用相同轉換否則尺度不一致」是錯的 —— 尺度問題用標準化解決，不是靠統一轉換。

### 類別資料編碼

| 編碼 | 做法 | 適用 | 主要風險 |
|---|---|---|---|
| **Label Encoding** | 類別 → 整數（小學 0／高中 1／大學 2） | **有序類別（Ordinal）**：教育程度、Basic／Premium／VIP | 誤用於**無序類別**時，線性模型與距離模型會讀成「紅 < 藍 < 綠」的**虛假順序**與虛假間距 |
| **One-Hot Encoding** | 每個類別開一欄，是 1 否 0 | 無序類別、基數低 | **高基數（High Cardinality）時維度爆炸** |
| **Target Encoding** | 用該類別在目標變數上的統計量取代 | 高基數且與目標高度關聯 | **目標洩漏**（見 48.5），必須用 out-of-fold 或加平滑 |
| **Frequency Encoding** | 用出現次數／頻率取代 | 高基數、快速基線 | 不同類別頻率相同時會被混淆 |
| **Categorical Embedding** | 映射到固定長度稠密向量（如 32／64 維） | 超高基數、深度模型 | 需要訓練，小資料易過擬合 |

**115Q1 第 24 題**：3,000 種商品項目，問**哪一種最容易造成維度爆炸** → **One-Hot**（直接生出 3,000 個稀疏欄位）。三個誘答的正確定位要一併記住：Target Encoding 的風險是**目標洩漏不是維度**；Label Encoding 的缺點是**硬塞順序不是維度**；Embedding 正是為了避開維度爆炸而設計。

> **官方《學習指引》明確寫道：「樹模型對類別編碼敏感，避免使用標籤編碼造成誤解。」** 作答時請以指引口徑為準：**標籤編碼只給有序類別用**，不論下游是什麼模型。

### 時間與週期性特徵

```
拆解：時間戳 → 年、月、日、星期幾、時段、是否假日
週期編碼：直接用「小時 = 0～23」會讓 23 點與 0 點相隔 23，語意上卻相鄰
          → 用 sin/cos 成對編碼：
            hour_sin = sin(2π × hour / 24)
            hour_cos = cos(2π × hour / 24)
          兩欄一起用，才能把「首尾相接」的圓周關係保住
序列特徵：滯後值（lag）、移動平均（rolling mean）、時間間隔、事件次數
```

**115Q1 第 26 題**：滑動窗口（Sliding Window）把 t−1 到 t−k 的觀測值攤平成同一筆樣本的多個欄位，主要目的是**建立滯後特徵（Lag Features）**。三個誘答都要能否掉：它**不是**資料增強（只是重組既有觀測，沒有產生新資訊）、**不是**去雜訊（沒有做平滑或濾波）、更**不是**降維（維度是**增加** k 倍）。

## 48.4 資料增強

| 資料型態 | 常見手法 | 典型應用 |
|---|---|---|
| **影像** | 隨機翻轉、旋轉、裁剪、縮放、色彩變換 | 人臉辨識、醫學影像、AOI 瑕疵檢測 |
| **文字** | 同義字替換、隨機插入／刪除／交換、回譯 | 情感分析、主題分類 |
| **時序** | 加噪、Jittering、Scaling、窗口裁切 | 設備故障預測、股市趨勢 |
| **表格** | **SMOTE**（在少數類樣本與其 k 近鄰間**線性插值**產生新樣本） | 詐欺偵測、疾病診斷等不平衡問題 |

### 資料增強最重要的鐵律：不可改變標籤語意

官方在 114-2 與 115-1 **各考一題水平翻轉**，且都是同一個陷阱：

| 題號 | 情境 | 為什麼翻轉會出事 |
|---|---|---|
| **115Q1-4** | 多個影像任務統一加隨機水平翻轉，部分任務表現下降 | **手寫數字辨識**：字形方向本身就是辨識依據，鏡像後標籤沒跟著改，等於餵錯誤標註。貓狗分類、車型分類、行人偵測都與左右無關，是安全的 |
| **115Q1-41** | OCR 訓練，驗證損失持續下降但部署後 **b/d/p/q** 錯誤率暴增 | `RandomHorizontalFlip(p=0.5)` 讓 b 變成 d、p 變成 q，標籤不變。**因為訓練與驗證套用同一組轉換，驗證損失看起來正常**，問題要到部署才爆發 |

> **「驗證集看起來沒事」正是這類題的殺傷力來源。** 只要增強是在訓練與驗證上同時施加，錯誤標註會被一起學進去、也被一起「驗證」通過。**增強應只對訓練集施加**，驗證與測試集維持原樣（推論階段的 TTA 是另一回事，屬於推論技巧）。

### 不平衡資料的四種手段與一個陷阱

```
資料層：SMOTE 過採樣 / 欠採樣多數類 / SMOTE-NC（含類別欄位）
演算法層：class_weight 類別權重、focal loss
決策層：調整分類門檻（不用預設 0.5）
評估層：改用 Recall、F1、PR-AUC —— 絕不能只看 Accuracy
```

**114Q2 第 19 題**（正樣本僅 3%）與 **115Q1 第 12 題**（陽性僅 1%、Accuracy 99.1%）考的是同一件事：**在極度不平衡下，Accuracy 幾乎完全由多數類決定**，全部預測為多數類就能拿高分，漏診風險被徹底掩蓋。SMOTE、類別權重、欠採樣都是適當手段，**「用 Accuracy 當評估指標」才是最不適合的那一個**。

## 48.5 資料洩漏（本知識點的頭號考點）

**定義：** 模型在訓練或評估階段用到了**推論時不可能取得的資訊**，導致評估結果過度樂觀、上線後表現崩塌。

### 三種來源

| 類型 | 典型情境 | 症狀 |
|---|---|---|
| **前處理洩漏** | 用**全體資料**去 fit scaler／imputer／PCA／LDA／特徵選擇器，再做交叉驗證 | 驗證分數異常高且穩定 |
| **目標洩漏（Target Leakage）** | 特徵本身含有答案（拿「理賠金額」預測「是否理賠」）；Target Encoding 未做 out-of-fold；早停用測試集 | 某個特徵重要性高得離譜 |
| **時間洩漏（Temporal Leakage）** | 對時間序列做隨機 K-fold，等於用未來預測過去 | 離線好、上線衰退 |

### 官方原題：115Q1 第 44 題

```python
# ✘ 錯誤寫法（官方題目中的程式）
X_new = lda.fit_transform(X, y)            # LDA 已看過「全部樣本的標籤」
scores = cross_val_score(knn, X_new, y, cv=5)   # 每一折的測試資料早已參與降維擬合
# → 準確率 0.9733 有一部分是洩漏來的

# ✔ 正確寫法：用 Pipeline 把前處理綁進每一折
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import cross_val_score, StratifiedKFold

pipe = make_pipeline(StandardScaler(), LDA(n_components=2), KNeighborsClassifier())
scores = cross_val_score(pipe, X, y, cv=StratifiedKFold(n_splits=5, shuffle=True))
# 每一折只以「該折的訓練資料」擬合 scaler 與 LDA，再 transform 測試折
```

**LDA 是監督式降維（要吃標籤），所以它的洩漏比 PCA 更嚴重** —— PCA 至少只偷看了特徵分佈，LDA 連答案都看過了。這也是官方挑 LDA 而非 PCA 來出這題的原因。（順帶記住：Iris 有 3 類，**LDA 最多只能降到 3 − 1 = 2 維**。）

### 哪些步驟必須進 CV 迴圈？

| 必須放進 Pipeline／每折重新 fit | 可以在切分前先做（不依賴資料統計量） |
|---|---|
| 均值／中位數／KNN 填補 | 欄位型別轉換、單位統一 |
| StandardScaler／MinMax／RobustScaler | 去除重複列、修正明顯錯誤輸入 |
| **PCA／LDA／SVD／特徵選擇（SelectKBest、RFE）** | 時間欄位拆解（年／月／星期幾） |
| **Target Encoding**（需 out-of-fold） | 固定函數的轉換（log、sqrt）※ |
| **SMOTE／過採樣（且只對訓練折）** | One-Hot（類別清單須以訓練集為準，不可含測試集才出現的類別） |

> ※ 注意 **Box-Cox 的 λ 是從資料估出來的參數**，因此 Box-Cox／Yeo-Johnson 必須進 Pipeline；單純的 `log(x)` 沒有待估參數，可以先做。

### SMOTE 的位置更容易錯

```
✘ 先對「全體資料」做 SMOTE，再切訓練／測試
   → 合成樣本是由真實樣本內插產生的，親本可能落在測試集
   → 測試集等於看過訓練集的內容，評估完全失真

✔ 先切分 → 只對訓練折做 SMOTE → 驗證／測試折維持原始不平衡分佈
   （評估必須反映真實世界的分佈，真實世界不會幫你補少數類）
```

### 時間序列的洩漏：115Q1 第 27 題

零售銷量模型以第 1～52 週訓練、第 53 週測試，半年後對第 80 週明顯衰退。要「每次訓練皆基於最新時間區間」→ 正解是 **滾動窗口驗證（Rolling Window Validation／TimeSeriesSplit）**。

> **這題的解析直接點名：K-fold 交叉驗證會隨機打散樣本，導致用未來資料預測過去，對時間序列造成資料洩漏。** 分層 K-fold 管的是類別比例不是時間順序；留一法同樣忽略時間先後。

## 48.6 特徵工程策略

### 依任務與模型調整

| 依據 | 原則 |
|---|---|
| **分類任務** | 偏好具離散分群能力的特徵：類別指標、區間編碼、分箱 |
| **迴歸任務** | 偏好與數值趨勢密切相關的連續特徵 |
| **線性模型** | 注意尺度與**多重共線性**（VIF 診斷） |
| **樹模型** | 不需縮放；**避免標籤編碼造成順序誤解** |
| **距離式模型（KNN）** | 必須保證特徵間單位一致 |

### 衍生與聚合

- **合成特徵**：單價 × 數量 = 總價、體重 ÷ 身高² = BMI
- **互動特徵（Interaction Features）**：**114Q2 第 20 題**問「商品價格」與「顧客滿意度」的交互效果，正解是**將兩個或多個特徵相乘或交互組合**。誘答「取平方」只是單一特徵的非線性項、「對數轉換」與「標準化」都只是單變數的尺度調整，**都表達不了特徵之間的關係**。
- **統計聚合**：使用者過去 7 天點擊次數、近 30 日平均消費
- **序列特徵**：lag、rolling mean、時間間隔、事件次數

### 金融領域的標準流程（114Q2 第 25 題）

傳統信用評分卡（邏輯迴歸）的標準步驟是：

```
✔ 特徵選擇 + 多重共線性（Multicollinearity）分析
✔ 分箱（Binning）+ 資訊值（Information Value, IV）檢定
✔ 以 PSI（Population Stability Index）監控模型穩定性
✘ 使用生成式模型進行特徵學習   ← 正解（「不是」常見步驟的那一個）
```

原因很單純：評分卡受監理要求，**可解釋性優先**，生成式模型的特徵學習是黑箱，不符合標準化開發流程。

## 48.8 易錯與陷阱

- [ ] **前處理要在交叉驗證「裡面」做，不是「前面」做** —— 降維、縮放、填補、特徵選擇都必須每一折用該折訓練資料重新 fit，用 `Pipeline` 串接；先用全體資料做就是資料洩漏。
- [ ] **LDA 是監督式降維，PCA 是非監督式** —— LDA 會吃標籤，洩漏更嚴重；且 LDA 最多降到「類別數 − 1」維，PCA 沒有這個上限。
- [ ] **Z-score 是「均值 0、標準差 1」，不是「壓到 0～1」** —— 壓到 0～1 的是 Min-Max；除以 255 也只是線性縮放，**不等於** z-score。
- [ ] **標準化屬於特徵縮放，不是特徵選擇** —— 這是官方直接設過的誘答。
- [ ] **有離群值就用 Robust Scaling** —— Min-Max 與 Z-score 用的 min／max／μ／σ 都會被極端值污染。
- [ ] **Label Encoding 只給有序類別** —— 用在無序類別上，線性與距離模型會讀出「紅 < 藍 < 綠」的虛假順序與虛假間距。
- [ ] **One-Hot 的問題是維度爆炸，Target Encoding 的問題是目標洩漏** —— 兩者風險不同，題目常故意交換。
- [ ] **t-SNE 只能視覺化，不能當模型輸入** —— 它不保留全局結構，也沒有可套用到新樣本的固定轉換函數。
- [ ] **特徵選擇保留原始欄位、降維產生新座標軸** —— 要「向審查單位解釋」時選前者，PCA 的主成分沒有業務意義。
- [ ] **L1 會挑特徵但不穩定，L2 穩定但不挑特徵** —— 共線性下要穩定解釋用 Ridge；要稀疏化用 Lasso，但接受清單會跳動。
- [ ] **log 轉換是給右偏長尾用的，不是萬用** —— 對原本就線性的特徵取 log 反而破壞結構；轉換要逐特徵決定，不是全表一起套。
- [ ] **Box-Cox 只吃正值、λ 要估參數** —— 含 0 或負值改用 Yeo-Johnson；兩者都必須進 Pipeline。
- [ ] **SMOTE 只能對訓練折做** —— 切分前做或對測試折做，合成樣本的親本會跨集，評估完全失真；測試集必須維持真實的不平衡分佈。
- [ ] **資料增強不可改變標籤語意** —— 水平翻轉對貓狗、車型、行人偵測安全，對手寫數字與 b/d/p/q 是災難；而且訓練與驗證同時套用時，**驗證損失完全看不出問題**。
- [ ] **滑動窗口是建立滯後特徵，維度是增加不是減少** —— 它既不是資料增強（沒有新資訊），也不是降噪。
- [ ] **異常值不一定要刪** —— 詐欺、瑕疵、故障這類任務裡，異常值就是答案本身，應標記保留作為特徵。
- [ ] **樹模型不需縮放、樸素貝氏也不需要** —— 需要縮放的是距離型（KNN、SVM、K-means）、線性型與神經網路，以及 PCA／LDA。
