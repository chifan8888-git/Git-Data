47.1

從人工神經元到訓練迴圈

一個神經元只做兩件事：加權求和 Z = w₁x₁ + w₂x₂ + … + b（線性部分），再送進激活函數 Output = A(Z)（非線性部分）。

神經元實驗室：AND 做得到，XOR 做不到

調整權重 w₁、w₂ 與偏置 b，讓輸出符合真值表（輸出 ≥ 0.5 視為 1）。偏置等於調整激活門檻。用「步階函數」就是 1957 年 Rosenblatt 的感知器 —— 試試看 XOR 能不能全對。

感知器只能做二元分類，且只能處理線性可分問題，著名反例就是 XOR。現代人工神經元把步階函數換成 ReLU／Sigmoid／Tanh 等可微分的非線性函數，才讓反向傳播成立。

前向傳播 vs 反向傳播：一個做預測，一個修參數

按「下一步」跟著一筆資料走完一次訓練。注意最後一步：真正更新參數的是誰？

前向傳播 Forward反向傳播 Backpropagation
目的做預測算梯度、修參數
方向輸入層 → 輸出層輸出層 → 輸入層
核心數學加權求和 + 激活函數微積分連鎖律（Chain Rule）
產出預測值 ŷ損失對每個 w、b 的偏導數
常見誤解—反向傳播只負責算梯度，真正更新參數的是優化器

RNN 因為有時間維度，用的是特殊形式的 BPTT（Backpropagation Through Time）：把序列沿時間軸展開成一個無迴圈的深層網路，再從最後一個時間步的損失往回推。

損失函數：誰對離群值最敏感？

四個一般樣本的誤差固定（示意），拖動第五個「極端值」的誤差，看它在三種損失中佔總損失的比例。

任務損失函數關鍵特性
迴歸MSE誤差取平方 → 大誤差懲罰被放大、梯度與誤差成正比，對離群值最敏感
迴歸MAE線性懲罰、梯度近似定值，刻意壓低離群值影響
迴歸Huber Loss小誤差平方、大誤差轉線性，介於 MSE 與 MAE 之間
二元分類Binary Cross-Entropy輸出一個機率
多類別分類Categorical Cross-Entropy衡量預測機率分佈與真實分佈的距離

正則化：Dropout 動起來

按「訓練一步」：每一步隨機把部分隱藏神經元的輸出設為 0（不是設為 1、也不是把權重設為 0），打斷神經元共適應。

技術做法特色
L1（Lasso）損失 += λΣ|W|產生稀疏解，部分權重歸零 → 自動特徵選擇；面對高度相關特徵時會隨機只留一個，重要特徵清單不穩定
L2（Ridge／Weight Decay）損失 += λΣW²壓小權重但不歸零，把相關特徵的權重平均分攤，表現較穩定
Elastic NetL1 + L2兼顧特徵選擇與平滑
Dropout訓練時隨機把部分神經元輸出設為 0打斷神經元共適應，等同集成效果
Early Stopping監控驗證集損失，設 Patience連續多輪未改善才停，避免被單次波動誤判
Batch Normalization對每批次激活值標準化穩定各層輸入分佈、緩解梯度消失與爆炸

激活函數（本知識點最高頻考點）

激活函數觀察台：看形狀，也看導數

實線是函數本身，虛線是導數（梯度）。拖動 x，留意 Sigmoid／Tanh 兩端的飽和區導數趨近 0。

激活函數數學式輸出範圍主要用途主要缺點
Sigmoid1/(1+e⁻ˣ)(0, 1)二元分類輸出層、LSTM 門控兩端飽和導致梯度消失；輸出非零中心
Tanh(eˣ−e⁻ˣ)/(eˣ+e⁻ˣ)(−1, 1)RNN 隱藏狀態仍會飽和，但梯度優於 Sigmoid
ReLUmax(0, x)[0, ∞)隱藏層預設值Dying ReLU：神經元輸出恆為 0、停止更新
Softmaxeᶻⁱ/Σeᶻʲ(0, 1)，總和為 1多類別單標籤輸出層只能用於單標籤，多標籤不適用

CNN 的四種層各司其職

深層網路的梯度傳遞：為什麼需要 ResNet

反向傳播時，梯度每往前傳一層就乘上該層的導數。長條顯示梯度傳回各層時還剩多少（示意：Sigmoid 取其導數最大值 0.25 的理想情況，ReLU 取作用區導數 1）。

115-1 第 17 題：3 層升到 16 層後訓練損失反而更高 → 最佳化失敗（梯度消失），對策是 ResNet 殘差連接；把 ReLU 改 Sigmoid 反而惡化。
115-1 第 49 題：「超過 50 層又怕梯度消失」→ ResNet。VGG 只是單純堆疊、沒有緩解梯度消失的機制；GoogLeNet 的 Inception 是提升參數效率而非治本。

組件功能常考重點
自注意力 Self-Attention每個 token 對序列所有其他 token 算相關性權重Q（我在找什麼）／K（我能提供什麼）／V（被關注時提供什麼）；任意兩位置直接建立關聯，不受距離限制
多頭注意力 Multi-Head拆成 h 個頭在不同表示子空間並行計算目的是同時捕捉多樣化關聯，不是為了減少參數或加速

必備語法二：PyTorch 輸出層（與 Keras 相反的坑）

  

    
Keras
輸出層要明確寫 activation='softmax'，再配 categorical_crossentropy。

    
PyTorch
nn.CrossEntropyLoss() 內部已串接 LogSoftmax + NLLLoss → 輸出層不要再加 softmax，直接輸出 logits，維度 = 類別數。

  

  

    

      
PyTorch 損失函數內建的激活輸出層該給什麼

      
nn.CrossEntropyLoss()內含 LogSoftmax原始 logits，維度 = 類別數，不加 softmax

      
nn.BCEWithLogitsLoss()內含 Sigmoid原始 logits

      
nn.BCELoss()無必須先自己過 sigmoid

      
nn.MSELoss()無連續值
